    Hardware QML Type (Uncreatable)

    The device's keys and knobs, attached to an item: Hardware.onUpPressed, Hardware.onKnobTurned…. More...

    Import Statement: import Ravving.Input 1.0
    In C++: Hardware

    Note: This is an uncreatable type. It cannot be instantiated in QML.

    • List of all members, including inherited members

    Detailed Description

    Each signal of HardwareAttached is a handler here (Hardware.onBigKnobUp: event => …); the HardwareEvent it receives says which key or knob, and is accepted unless the handler sets event.accepted = false.
