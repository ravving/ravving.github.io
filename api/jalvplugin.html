    JalvPlugin Class

    One LV2 plugin running in its own jalv process on the JACK graph: an effect (a reverb, a delay..., audio in and out) or an instrument (MIDI in, audio out; JalvEngine). More...

    Detailed Description

    It runs as jalv -n NAME URI, with controls set on jalv's console. The process is a ConsoleProcess (libzynthbox's ProcessWrapper). Controls are named by their LV2 port symbol; jalv's console wants port indexes, which are read from lv2info together with the audio and MIDI ports' symbols (jalv names its JACK ports after them). lv2info loads every installed bundle's data, which is slow, so its answer is cached on disk (Paths::cache()/lv2-ports.json, queried again only when the plugin's bundle or binary changed) and in memory once per URI. Values set before the start go on jalv's command line, later ones through its console, and all are sent again after a crash restart. GUI thread only.

    void JalvPlugin::setControl(const QString &symbol, double value)

    Sets the control port symbol to value, in the plugin's own units: on the command line before the start, through the console after.

    See also hasControl().

    void JalvPlugin::start()

    Starts jalv with every control set so far. Later calls do nothing, so a plugin needed only sometimes (TrackEffects' DRIVE) is started on first use. started() follows each start and restart.

    void JalvPlugin::stop()

    Stops the process for good (the plugin is being replaced).

    QString JalvPlugin::title() const

    Returns the plugin's own name (its LV2 doap:name, such as "Calf Monosynth"); empty when unknown.
