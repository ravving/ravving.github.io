    Detailed Description

    The device is a touch screen, so start.sh blanks the root window's cursor and ravving's windows inherit it. While a mouse or trackpad is present, an application override cursor (an arrow) makes the pointer visible; it is restored when the mouse goes.

    The devices are those QInputDevice::devices() reports (X11's XInput hierarchy, updated on hot-plug); X11's virtual core and XTEST pointers and the touch screen do not count. The list is polled every two seconds because Qt has no signal for it.

    [explicit] MouseWatcher::MouseWatcher(QObject *parent = nullptr)

    Logs the input devices, starts the two-second poll and checks once, with the given parent.

    [invokable] void MouseWatcher::refresh()

    Checks the input devices now and shows or hides the pointer to match; the poll calls it every two seconds.

    Note: This function can be invoked via the meta-object system and from QML. See Q_INVOKABLE.
