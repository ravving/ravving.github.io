    Detailed Description

    A frameless window gets no shadow from the window manager, so this hands one to it through KWindowShadow: a soft dark blur a little below the window, as eight tiles the compositor draws around the window's edges (KWin does; other compositors may draw their own and ignore it). The tiles reach under the window's rounded corners, which are see-through there. It is taken away while the window is maximised or full screen, and built again when the screen's scale changes.
