    Detailed Description

    The current item is marked, the highlighted one follows the device, and choosing one closes the dialog.

    Optional actions add buttons to the header (SAVE, DELETE) or a band along the bottom (OPEN, EXPORT) that act on the highlighted item through actionTriggered.

    The device while open: the big knob or the arrows move the highlight, SELECT chooses it, BACK closes without choosing. Closing gives the focus back to whatever had it (Dialog).

    An owner that may want to ask first (opening a project over unsaved work) sets closeOnChoose false, closes it itself, and can show a line of notice. A grid with nothing in it says why with an EmptyNote (emptyText). What waits for a confirming second press shows it as everywhere else in ravving: the ArmBar countdown inside that very button, the header action (armedAction) or the item (armedValue).

    With previewable, holding an item previews it (a sample is heard) until it is let go: previewStarted(value) on the hold, previewStopped() on the release or when the dialog closes.

    A type built on it (the app's ChoicePopup: sources, groups, favourites) puts rows of its own between the header and the grid (filters), narrows or orders the list (shownItems), adds to the keys' hint (extraHint), draws a badge in each cell's corner (cellBadge, which reads its loader's cellItem), and takes the device's other inputs through the hooks below: itemHeld(), selectHandled(), knobTurned() and subtitleOf().

    Property Documentation

    accent : color

    The colour of the machine or screen the dialog is for. With none given, the skin's accent, when there is one.

    actions : var

    Header buttons: [{text, enabled}]; a tap emits actionTriggered(index). A {separator: true} entry draws a divider between groups of buttons (it keeps its index). An entry with bottom: true sits on a band along the dialog's bottom instead (the project dialog's OPEN and EXPORT), keeping its index too.

    armedAction : int

    What waits for a confirming second press, its countdown (armedDuration) running out inside its button: the header action's index (−1 none), or an item's value (undefined none).

    armedDuration : int

    What waits for a confirming second press, its countdown (armedDuration) running out inside its button: the header action's index (−1 none), or an item's value (undefined none).

    armedValue : var

    What waits for a confirming second press, its countdown (armedDuration) running out inside its button: the header action's index (−1 none), or an item's value (undefined none).

    cellBadge : Component

    A badge in each cell's top-right corner (a favourite's ★), or null; it reads the cell's item as its loader's cellItem (parent.cellItem).

    cellHeight : int

    A cell's height in pixels (bigger icons want taller cells).

    closeOnChoose : bool

    Close once an item is chosen (false: the owner closes it, e.g. after asking).

    columns : int

    Buttons per row.

    currentValue : var

    The value of the item in use (marked in the grid).

    cursorShown : bool

    Index of the highlighted item (the device's cursor, in shownItems; −1 none), and the item itself. Opened, the cursor's frame sits on the item in use; with none in use it shows only once the device moves it (cursorShown), never on an item merely first in the list.

    emptyText : string

    What the grid says while it lists nothing, as an EmptyNote (why, and what fills it: "nothing here yet · …"); "" for no note.

    extraHint : string

    More of the keys' hint, after the dialog's own (a type built on this).

    filters : alias

    Rows between the header and the grid (a type built on this: sources, groups), set as a list (filters: [ToolBar { … }]): the dialog's children stay its own.

    filtersOpen : bool

    Whether those rows are open: a FILTERS heading above them folds them away (the list gets the room) and back; a type keeps the state where it likes (the app's profile). Folded, filtersSummary says what they are set to ("USB · RAVVING · ROCK · A–Z"), so a list narrowed by them never looks merely short.

    filtersShown : bool

    Whether any of those rows shows: the type says so (a hidden row's own visible cannot, it reads false while the column holding it is hidden).

    filtersSummary : string

    Whether those rows are open: a FILTERS heading above them folds them away (the list gets the room) and back; a type keeps the state where it likes (the app's profile). Folded, filtersSummary says what they are set to ("USB · RAVVING · ROCK · A–Z"), so a list narrowed by them never looks merely short.

An entry with bottom: true sits on a band along the dialog's bottom instead (the project dialog's OPEN and EXPORT), keeping its index too.

    highlighted : int

    Index of the highlighted item (the device's cursor, in shownItems; −1 none), and the item itself. Opened, the cursor's frame sits on the item in use; with none in use it shows only once the device moves it (cursorShown), never on an item merely first in the list.

    highlightedItem : var [read-only]

    Index of the highlighted item (the device's cursor, in shownItems; −1 none), and the item itself. Opened, the cursor's frame sits on the item in use; with none in use it shows only once the device moves it (cursorShown), never on an item merely first in the list.

    iconRole : string

    An item's icon: iconRole names the field holding an image's URL (a pixel glyph), drawn crisp at iconSize pixels straight on the cell, beside the name (centred in the cell when the item has no name); an item without one draws none. "" (the default): no icons.

    iconSize : int

    An item's icon: iconRole names the field holding an image's URL (a pixel glyph), drawn crisp at iconSize pixels straight on the cell, beside the name (centred in the cell when the item has no name); an item without one draws none. "" (the default): no icons.

    items : var

    The items: [{name, <valueRole>…}]; name is shown, valueRole identifies an item, and subtitleRole (if set) is shown small under the name.

    notice : string

    A line shown along the bottom, under the grid (a question, a warning; the full width, where the header's buttons leave it none), "" for none.

    previewable : bool

    A long press previews an item instead of choosing it (see previewStarted).

    previewing : bool

    Whether an item is being previewed (held).

    shownItems : var

    The items on screen, in their order: all of them unless a type built on this narrows them.

    subtitleRole : string

    The items: [{name, <valueRole>…}]; name is shown, valueRole identifies an item, and subtitleRole (if set) is shown small under the name.

    tapPicks : bool

    A tap only picks (highlights) an item, for the header's actions to work on (OPEN, SEND…); a second tap on the picked item, or SELECT, chooses it. The project dialog.

    title : string

    Shown above the grid.

    valueRole : string

    The items: [{name, <valueRole>…}]; name is shown, valueRole identifies an item, and subtitleRole (if set) is shown small under the name.

    Signal Documentation

    actionTriggered(int index)

    A header or bottom action was tapped: index is its place in actions.

    Note: The corresponding handler is onActionTriggered.

    chosen(var value)

    An item was chosen: value is its value (its valueRole).

    Note: The corresponding handler is onChosen.

    previewStarted(var value)

    An item is held to preview it: value is its value. previewStopped() follows when it is let go or the dialog closes.

    Note: The corresponding handler is onPreviewStarted.

    previewStopped()

    The item held to preview it was let go, or the dialog closed.

    Note: The corresponding handler is onPreviewStopped.

    Method Documentation

    choose(index)

    Chooses the item at index in shownItems (chosen()), and closes the dialog unless closeOnChoose is off; an item listed as not enabled is not chosen.

    highlightCurrent()

    Put the (hidden) cursor on the current item, in view; −1 when it is not shown.

    itemHeld(index)

    A long press on cell index: true when the type took it (a favourite marked).

    knobTurned(knob, delta)

    Device knob knob (0–2: knobs 1–3) turned by delta detents while the dialog is up; nothing unless a type built on this answers it.

    moveHighlight(delta)

    Move the highlight by delta items, staying inside the list. The first move only shows the cursor, on the item in use (or the first).

    selectHandled()

    SELECT on the highlighted item: true when the type took it (ALT + SELECT).

    stopPreview()

    Ends a preview (previewStopped()), if one is running.

    subtitleOf(item)

    Returns the small line under item's name: its subtitleRole, as it is.

    tap(index)

    A tap on cell index: picks it (tapPicks, the first time), else chooses it.
