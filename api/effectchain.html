    EffectChain Namespace

    The SOUND EFFECTS chain every machine has, in signal order (easyrave's insert chain): DRIVE, COMPRESSOR, REVERB, EQ, PAN, SIDECHAIN, DELAY, each with its knobs. More...

    Detailed Description

    This is the one definition of the chain: TrackEffects applies it, and QML builds the effect cards from studio.effectChain (toVariant()). Knob values are 0..1 everywhere; what they mean is TrackEffects' and GlobalEffects' business. A shared knob (REVERB SIZE, DELAY TIME and FDBK) belongs to the studio's one reverb or delay, which every machine sends into, so it shows the same value on every machine. Read-only data; thread-safe.
