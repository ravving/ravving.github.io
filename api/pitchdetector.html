    Detailed Description

    The method is guitarix's tuner (src/LV2/gxtuner.lv2/gx_pitch_tracker.cpp, GPL-2.0-or-later, by Hermann Meyer, James Warden, Andreas Degert and Pete Shorthose), itself Philip McLeod's from Tartini: the block is decimated to about 24 kHz, its normalised square difference function (NSDF: the autocorrelation scaled to -1..1 by the energy of both halves) is taken over the lags of the range set, and the period is the first key maximum (the highest peak between two zero crossings) that comes near the highest one, which keeps a string's strong second harmonic from reading an octave up. A parabola through the peak gives the fraction of a sample. At these sizes (a 2048-sample window, lags up to the lowest note set) the direct sum is cheap enough, so no FFT is needed.

    A level gate with hysteresis (on above the set level's mean absolute value, off under 90 % of it) decides when there is a note at all.

    
 PitchDetector ear;
 ear.setSampleRate(48000);
 ear.setRange(30, 1400);
 const float hz = ear.detect(block.data(), int(block.size())); // 0: no note

    Not thread-safe: one caller at a time (it keeps its buffers and the gate's state). detect() allocates only when the window grows.

    Member Function Documentation

    float PitchDetector::detect(const float *samples, int count, float *clarity = nullptr)

    Returns the frequency in Hz of the note in the count samples (the newest at the end), or 0 when the block is too quiet or has no clear period. When clarity is not null it receives the NSDF peak's height, 0..1: how periodic the block is.

    void PitchDetector::reset()

    Forgets the gate's state (a new source).

    void PitchDetector::setOnLevel(float level)

    Sets the gate: the mean absolute value, level, a block must reach to hold a note (0.001 is about -60 dBFS, the default).

    void PitchDetector::setRange(float lowestHz, float highestHz)

    Sets the notes to find, from lowestHz to highestHz; the lowest sets the longest lag looked at. 30 to 1400 Hz by default.

    void PitchDetector::setSampleRate(int rate)

    Sets the rate in Hz of the blocks given to detect(); 48000 by default.

    int PitchDetector::wantedSamples() const

    Returns how many samples, at the sample rate, detect() wants: the window, decimated, plus the longest lag. Fewer is allowed, giving a shorter, less precise window.
