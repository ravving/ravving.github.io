    Detailed Description

    Participants (HistoryParticipant) register once with add() and report each change with record(). A step holds, for each participant it touched, the state before and after, so a step stores only what changed and undoing it restores only what it touched. At most Depth steps are kept.

    What becomes one step:

    • everything recorded within one turn of the event loop, so an action that touches several participants is undone in one go;
    • a participant's changes that follow each other within MergeMs milliseconds (a control being turned);
    • everything between begin() and end().

    There are two ways back:

    • the timeline: undo() and redo() walk the whole project's steps;
    • one participant: undoIn() and redoIn() step through that participant's changes only, leaving the others as they are. This is safe because the participants' states are independent of each other.

    forget() drops a participant's steps when its state is replaced wholesale (a project opened, a section picked); clear() empties the whole history. GUI thread only.

    Member Function Documentation

    [explicit] History::History(QObject *parent = nullptr)

    Constructs an empty history with the given parent.

    void History::add(HistoryParticipant *participant)

    Registers participant. Its state now is where its history starts. The participant must outlive the history or be removed with remove() first.

    [invokable] void History::begin(const QString &label = QString())

    Opens a group: everything recorded until the matching end() becomes one step, named label (else after the participants it touched). Groups nest; the outermost label is used.

    Note: This function can be invoked via the meta-object system and from QML. See Q_INVOKABLE.

    bool History::canRedoIn(const QString &key) const

    Returns whether the participant named key has a change to redo: one undone with undoIn(), or one in the timeline's last undone step.

    bool History::canUndoIn(const QString &key) const

    Returns whether the participant named key has a change in the timeline to undo.

    [signal] void History::changed()

    Emitted when anything about the history changes: the can* and *Text properties, or a participant's own canUndoIn() / canRedoIn().

    Note: Notifier signal for properties canRedo, canUndo, redoText, and undoText.

    [invokable] void History::clear()

    Empties the history; every registered participant starts again from its current state.

    Note: This function can be invoked via the meta-object system and from QML. See Q_INVOKABLE.

    [invokable] void History::end()

    Closes the group begin() opened; the step is complete when the outermost group closes.

    Note: This function can be invoked via the meta-object system and from QML. See Q_INVOKABLE.

    void History::forget(HistoryParticipant *participant)

    Drops every step entry of participant, and the steps left empty by that, and takes its current state as its new starting point. Call it when the participant's state is replaced wholesale.

    void History::record(HistoryParticipant *participant)

    Records a change of participant: its state is compared with the last one known and, when it differs, becomes part of a step (the open one, a merge with the participant's last step, or a new step on top). A new change clears the redo steps. Ignored while the history itself applies a state, and for a participant that is not registered.

    [invokable] void History::redo()

    Redoes the last undone step of the timeline. Emits changed() and redone().

    Note: This function can be invoked via the meta-object system and from QML. See Q_INVOKABLE.

    void History::redoIn(const QString &key)

    Redoes the change of the participant named key that undoIn() undid last, as a new step on top of the timeline. When it has none but the timeline's last undone step touched it, that step is redone (redo()).

    [signal] void History::redone(const QString &what)

    Emitted after redo() went forward over a step; what is its name (redoText before the call).

    void History::remove(HistoryParticipant *participant)

    Forgets participant's steps (forget()) and unregisters it.

    [invokable] void History::undo()

    Undoes the timeline's last step: each participant it touched gets its state from before the step, the last touched first. Closes any open begin() group. Emits changed() and undone().

    Note: This function can be invoked via the meta-object system and from QML. See Q_INVOKABLE.

    void History::undoIn(const QString &key)

    Undoes the latest change of the participant named key, wherever it is in the timeline, and keeps it for redoIn(). The other participants keep their state; the timeline's redo steps are cleared.

    [signal] void History::undone(const QString &what)

    Emitted after undo() went back over a step; what is its name (undoText before the call).

    Member Variable Documentation

    const int History::Depth

    This variable holds the number of steps the timeline keeps (100); the oldest step is dropped past it.

    const int History::MergeMs

    This variable holds the time in milliseconds (500) within which a participant's next change joins its last step.
