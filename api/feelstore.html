    Detailed Description

    The cards of knobs (the SOUND MODIFIERS', the SOUND EFFECTS') show a store's values by card and knob and set them through setValue(). This is that store over Machine::feel: each dial's amount over its most (Machine::feelMax()), under the cards Machine::feelCards() names, so the FEEL opens on the same cards as the rest. Made by its machine (Machine::feelStore); GUI thread.

    Property Documentation

    [read-only] values : QVariantMap

    This property holds the dials' values by card and dial: Machine::feelCards()' title → dial → 0 (as written) to 1 (its most; a choice's index over its last).
