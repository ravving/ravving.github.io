    Detailed Description

    An icon pack file has the preset files' envelope (PresetExchange), so it goes to and from a stick's ravving/presets/icons like a skin set:

    
 {"ravving": "preset", "type": "icons",
  "pack": {"name": "STENCIL", "about": "cut-out shapes", "author": "…", "grid": 12,
           "icons": {"play": "M3 2L10 6L3 10Z", "stop": "M2 2H10V10H2Z", …}}}

    Each icon is one filled path on a square grid of grid cells a side (4 to 16), in straight lines only (M, L, H, V and Z, absolute or relative): the outline Glyphs draws crisp at any size. The names are the built-in sets' (iconNames()); an icon the pack leaves out is drawn from candy, the set that has them all. The pack's key is the file's name without .json; a key the built-in sets use is never read.

    The user's packs are in the library's icons/ (userFolder()), watched: a file copied in shows up without a restart. Each pack read is written out as SVG files under the cache's icons/<key>.<revision>/, the folder Glyphs reads a set from (Glyphs::setPackFolder()): a pack that changes gets a new folder, so the images already drawn, cached by their URL, are drawn again. The set picked (chosen, a built-in set or a pack's key) is drawn as set, which Theme.iconSet follows.

    Member Function Documentation

    [explicit] IconPacks::IconPacks(QObject *parent = nullptr)

    Reads the packs in userFolder() (made if missing) and watches it and every file read, with the given parent. GUI thread only; one at a time.

    [static] QStringList IconPacks::builtInSets()

    Returns the built-in icon sets' names, which no pack key may take.

    [static] QVariantMap IconPacks::checked(const QVariantMap &pack, QStringList *problems = nullptr)

    Returns pack with only the icons that read: a name ravving draws (iconNames()) and a path in straight lines (M, L, H, V, Z), or an empty map for a pack whose grid is out of range (4 to 16) or with no icon that reads. What it leaves out, and why, is added to problems when given.

    [static] QVariantMap IconPacks::document(const QVariantMap &pack)

    Returns the preset document an icon pack file holds for pack: {"ravving": "preset", "type": "icons", "pack": pack}.

    [static] QString IconPacks::fileOf(const QString &key)

    Returns the file of the pack key, or an empty string when there is none.

    [static] QStringList IconPacks::iconNames()

    Returns the names an icon pack can draw: the built-in candy set's, sorted.

    [static] QString IconPacks::importPack(const QVariantMap &given)

    Writes given into userFolder() as an icon pack file, synced, under a name no pack or built-in set has ("STENCIL" → "STENCIL 2"), with only the icons that read (checked()). Returns the name it got, or an empty string for a pack without an icon that reads or a file that cannot be written. The watcher then reloads the packs.

    [static] bool IconPacks::isPackKey(const QString &key)

    Returns whether key can be a pack's (its file's name without .json): lower case letters, digits and dashes (keyOf() leaves it as it is), and no built-in set's name.

    [static] QString IconPacks::keyOf(const QString &name)

    Returns the key and file name a pack called name gets: lower case, every run of other characters than letters and digits a dash ("Night Bus" → night-bus).

    [static] QVariantMap IconPacks::readFile(const QString &path, QStringList *problems = nullptr)

    Returns the pack (name, about, author, grid, icons) of the icon pack file at path, as checked() leaves it, or an empty map for a file that is not a pack. What it leaves out, and why, is added to problems when given, and warned.

    [static] QString IconPacks::userFolder()

    Returns the user's icon packs folder: the library's icons/.

    [static] bool IconPacks::writeSvgs(const QVariantMap &pack, const QString &folder)

    Writes pack's icons into folder as the SVG files Glyphs reads, one per icon, after emptying it. Returns false when a file cannot be written.
