    Detailed Description

    The file is in $ZYNTHIAN_CONFIG_DIR (/zynthian/config), and set_wifi.sh copies it to /etc/wpa_supplicant/ each time Wi-Fi starts (at boot through wifi-setup.service, and on every switch). zynthbox-qml and webconf write it too, one network at a time.

    It keeps the file's settings (country, ctrl_interface...) and every network block as read, so a save changes only what was asked. A block wpa_supplicant would refuse (a psk that is not 8 to 63 characters or 64 hex digits, such as the psk="" zynthbox-qml writes for an open network) makes wpa_supplicant refuse the whole file, so Wi-Fi never starts; such blocks are dropped on load (dropped() lists them) and are gone from the next save. A plain value type.

    void WpaConfig::setNetwork(const QString &ssid, const QString &passphrase, bool open, bool sae)

    Saves ssid as the network to join: with passphrase (8 to 63 characters, or 64 hex digits), or as an open network when open is true and the passphrase is empty, with sae for a WPA3-only network. It takes the highest priority, so it is preferred over the others; an existing block keeps its other settings.
