    Detailed Description

    Every call runs git as a child started without copying ravving (vfork), with ravving as the author and none of the user's configuration read. A snapshot is hash-object, mktree, commit-tree and update-ref (guarded by the parent, so a branch that moved is not written over); the times are stamped by the caller. housekeep() is gc --prune=now, at the lowest CPU and I/O priority. The fallback when libgit2 is not built in.
