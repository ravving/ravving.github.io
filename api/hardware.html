    Hardware Class

    The QML type that carries the Hardware attached property, and the dispatcher that walks the focus chain. More...

    Detailed Description

    QML reaches it as import Ravving and Hardware.on... handlers (HardwareAttached). Ravving calls dispatch() for every event from the device, the keyboard shortcuts and the remote-control fifo.

    Member Function Documentation

    [static] bool Hardware::deliverTo(QObject *item, HardwareEvent *event)

    Delivers event to item's own Hardware handlers only, without bubbling. Returns whether a handler accepted it; false when item is null or has no handlers.

    [static] bool Hardware::dispatch(QQuickWindow *window, HardwareEvent *event)

    Delivers event to window's active focus item (its content item when nothing has the focus), then to each parent item in turn, until a Hardware handler accepts it. Only items that declared Hardware handlers are visited. Returns whether a handler accepted the event, false when window is null.

    [static] HardwareAttached *Hardware::qmlAttachedProperties(QObject *object)

    Returns a new HardwareAttached for object, owned by it. Called by the QML engine.
