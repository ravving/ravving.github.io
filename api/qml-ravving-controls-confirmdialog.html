    Detailed Description

    A Dialog headed by a DialogHeader (title, notice and the ✕), one line saying what the act does (text), and two answers side by side: the safe one first (rejectText, what the ✕ and BACK do too), the act second (acceptText). Neither is the default: the device's cursor (a FocusRing) opens on the safe answer, ◀ ▶ ▲ ▼ or the big knob move it, SELECT answers the ringed one, BACK rejects. Answers are outcome words (KEEP PLAYING / QUIT), never YES / NO or OK / CANCEL (docs/ui-rules.md, "Leaving").

    The owner says when to ask and what the act does: it opens the dialog, and handles accepted (the act) and, where it needs to, rejected. When the reason to ask goes (asking turns false: the music stopped) the dialog closes with no answer.

    For a question that comes from outside ravving's own buttons (the window manager closing the window, another device). A button pressed in ravving asks with a second press instead (ConfirmButton).

    Property Documentation

    acceptText : string

    The act's answer (the trailing button) and the safe answer (the leading one).

    asking : bool

    Whether the question still stands. When it turns false while the dialog is open, the dialog closes with no answer: withdrawn, neither accepted nor rejected.

    destructive : bool

    Whether the act loses something that can't be got back: its answer is drawn in destructiveColor then.

    destructiveColor : color

    The destructive act's colour: the kit's error red.

    notice : string

    The question, in capitals; what the act does, one lower-case line; an optional warning under the title ("" for none).

    rejectText : string

    The act's answer (the trailing button) and the safe answer (the leading one).

    ring : int

    The device's cursor: 0 on the safe answer, 1 on the act.

    text : string

    The question, in capitals; what the act does, one lower-case line; an optional warning under the title ("" for none).

    title : string

    The question, in capitals; what the act does, one lower-case line; an optional warning under the title ("" for none).

    Signal Documentation

    accepted()

    The act was answered; the dialog has closed.

    Note: The corresponding handler is onAccepted.

    rejected()

    The safe answer, the ✕, BACK, Esc or a tap outside; the dialog has closed.

    Note: The corresponding handler is onRejected.

    withdrawn()

    The question went while it was asked (asking turned false); the dialog has closed.

    Note: The corresponding handler is onWithdrawn.

    Method Documentation

    accept()

    Answers the act, as if it were picked: the owner's "asked twice" (the window closed again while the question is up).

    reject()

    Answers the safe answer.
