    WindowControls QML Type

    A frameless window's minimise, maximise (restore) and close buttons, flat (no face until hovered), at the right end of a header, and the header made the window's title bar. More...

    Detailed Description

    Shown only in a window that draws its own frame (Qt.FramelessWindowHint: the desktop window, see WindowFrame); hidden, it takes no room. It also makes band (by default the item it sits in) move the window when dragged with a mouse or touchpad, and maximise or restore it on a double click, where the band's own controls leave the press. Every full-window view's header carries one, so the window can always be moved and closed. Separate it from the header's own ✕ (which leaves the view) with a ToolSeparator.
