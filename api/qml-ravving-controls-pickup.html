    PickUp QML Type

    How the fixed pots (Z2_V5B) take over a value they do not sit on. More...

    Detailed Description

    A pot sitting anywhere must not throw a value to its own position the moment its owner takes the knobs unasked (a brightness pot resting at its minimum would black the screen out as the control center opens). Three ways, the user's choice (Interaction.knobMode, SETTINGS · DEVICE):

    • pickup: the pot changes nothing until it comes within 2 % of the value or crosses it; from then on it drives the value directly.
    • jump: the value goes to the pot's position at once.
    • scale: the value moves toward the pot in proportion to the pot's travel left, and meets it at the end of that travel (no dead zone, no jump); from then on the pot drives it directly.

    One state per knob (count); reset() when the owner takes the knobs again. KnobGroup and the control center share it; a KnobBadge pulses while pickedUp[knob] is false.

    
 PickUp { id: pickUp; count: 2 }
 Hardware.onKnobMoved: event => current = pickUp.take(event.knob, event.value, current, 0, 1)

    Property Documentation

    count : int

    How many knobs it keeps a state for.

    lastPosition : list<real>

    Per knob: driving the value directly yet; which side of the value the pot was last seen on (−1, 0, 1); where the pot was last (0..1, −1 not yet seen).

    mode : string [read-only]

    How the pots take over: pickup, jump or scale (Interaction.knobMode).

    pickedUp : list<bool>

    Per knob: driving the value directly yet; which side of the value the pot was last seen on (−1, 0, 1); where the pot was last (0..1, −1 not yet seen).

    potSide : list<int>

    Per knob: driving the value directly yet; which side of the value the pot was last seen on (−1, 0, 1); where the pot was last (0..1, −1 not yet seen).

    Method Documentation

    reset()

    Forgets every knob's state: call it when the owner takes the knobs again.

    take(knob, position, current, from, to)

    Returns the value pot knob at position (0..1) gives a value now at current, which runs from from to to: the pot's own value once it drives it, else what the mode says (current while a pickup waits).
