    Detailed Description

    ravving draws its text in three families: a regular one for every label, caption and name; a monospaced one for figures that change while watched (readouts, counters, times), whose digits all have the same width; and a display one for branding (the instruments' nameplates), the face of the device's own key legends. Both ship as resources under :/fonts (the files in data/fonts, with their licences), so nothing has to be installed on the device.

    install() registers every font file under :/fonts and makes the regular family the application's font, which the controls and every plain Text then use. QML reads the monospaced and display families through Rave.monospaceFamily and Rave.displayFamily.

    To switch a family: put its files in data/fonts and change the family's name in fonts.cpp (one line each).

    [static] void Fonts::install()

    Registers the font files built into the binary and makes the regular family the application's font, keeping its size. Call it once, after the QGuiApplication is made and before any QML is loaded. A family that didn't register is logged, and Qt's own fallback is used for it.
