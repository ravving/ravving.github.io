    Detailed Description

    The order: the network in use first, then the saved ones, then by signal, then by name. One row per network name, with the strongest of its access points.

    Wifi fills it from wpa_supplicant's scan results and keeps it in step with what is saved and joined. A refresh that keeps the order updates the rows in place, so a view keeps its position and state. While frozen, rows never move or disappear: they are updated in place and new ones are appended; the order catches up when frozen is cleared.

    enum WifiNetworks::Role

    The model's roles; DisplayRole gives the name too.

    ConstantValueDescription
    WifiNetworks::SsidRoleQt::UserRole + 1The network's name.
    WifiNetworks::SignalRole258The signal, 0..100, from the access point's dBm.
    WifiNetworks::SecurityRole259open, wpa (a passphrase), sae (WPA3 only), or one that can only be joined elsewhere (webconf): wep, enterprise.
    WifiNetworks::SupportedRole260Whether ravving can join it: open, wpa and sae, which need a passphrase or nothing.
    WifiNetworks::SavedRole261Whether it is saved in Zynthbox's wpa_supplicant.conf, so joining needs no passphrase.
    WifiNetworks::StatusRole262connected, connecting, failed (the last join did not succeed), or empty.
