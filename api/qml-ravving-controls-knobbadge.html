    Detailed Description

    A tiny knob icon pinned to a control while a device knob drives it. It shows which knob (1–3 for the small ones, a dot for the big one) and, as an arc, where the control's value sits. While a fixed pot still has to be brought to the value before it takes over (pick-up), the badge pulses.

    Set shown rather than visible: nearly every control carries a badge and few show one, so its drawing is only built the first time it is shown (hundreds of them at startup otherwise), and kept from then on.

    shown : bool
