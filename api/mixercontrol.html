    MixerControl Struct

    One of a mixer strip's controls a controller's key, knob or fader can be learned as (MidiInput's MIXER controls, LearnedMixer): a strip's volume, pan, mute, solo, take or pause, or the transport's ❚❚, a bar back or on, the previous or the next machine. Its id, as the settings keep it: MIXER1_VOLUME to MIXER8_PAUSE, MIXER_PAUSE, MIXER_BACK, MIXER_ON, MIXER_PREVIOUS, MIXER_NEXT. More...

    [static] QList<MixerControl> MixerControl::all()

    Returns every control: each strip's six in order, then the transport's five.

    bool MixerControl::continuous() const

    Returns whether the control sets a value (the volume, the pan) rather than flipping one.

    QString MixerControl::id() const

    Returns the control's id: MIXER<strip from 1>_<part>, or MIXER_<part> for the transport's.

    [static] std::optional<MixerControl> MixerControl::parse(const QString &id)

    Returns the control whose id() is id, none for any other id.

    bool MixerControl::transport() const
