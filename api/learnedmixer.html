    LearnedMixer Class

    A plain MIDI controller as the instruments' mixer: its keys, knobs and faders learned as the MIXER controls in SETTINGS · MIDI (MixerControl), linked to the instruments through ControllerMixers like a control surface's strips (MackieSurface). More...

    Detailed Description

    What a learned message does depends on what it is and what it is learned as:

    • a fader or an absolute knob (a CC sending positions, or a pitch bend, 14 bits) on a strip's VOLUME or PAN takes the value over once it reaches it (within PickupWindow, or crossing it), as a surface's fader does: one left elsewhere does not jump the value, and a value changed anywhere else lets go of it until it is reached again; with the pick-up off (setFaderPickup(), the controller's pickup setting) any move sets the value. Near 0 dB is 0 dB, near the middle the middle.
    • an endless knob (a CC repeating a turn's values: EncoderGuess) on VOLUME or PAN turns it from where it is, faster as it turns faster (RelativeEncoder): the volume LevelStep a tick, stopping once at 0 dB, the pan PanStep, stopping once in the middle.
    • a key (a note, or a CC from MidiValues::PressedFrom up) on MUTE, SOLO, REC or PAUSE flips it on its press; on the transport's PAUSE it pauses while playing and goes on while paused; on VOLUME it sets 0 dB, on PAN the middle.

    A learned key's light follows its state (muted, soloed, a take on, paused): its own note or CC goes back to the controller at Lit or Unlit, which lights the pads and buttons of many controllers; setLights() turns that off. Only what changed is sent, together. GUI thread only.

    [static] QByteArray LearnedMixer::light(const QString &message, bool lit)

    Returns the message that lights (lit) or darkens the key learned as message: a note-on or a CC on its own number and channel at MidiValues::Lit or MidiValues::Unlit; nothing for a pitch bend.

    void LearnedMixer::lightsOff()

    Turns every light it lit off, and forgets them: sent again from scratch when it lights them next.

    void LearnedMixer::receive(const QString &control, int status, int data1, int data2)

    The controller sent status (0x90 / 0x80 a note, 0xB0 a CC, 0xE0 a pitch bend; no channel) with data1 and data2, learned as control (a MixerControl id).

    void LearnedMixer::setClock(const std::function<qint64 ()> &now)

    Has the knobs' turns timed by now (milliseconds, monotonic), a clock of the caller's: for tests. Unset, the mixer times them itself.

    void LearnedMixer::setControls(const QHash<QString, QString> &controls)

    The controller's MIXER controls are controls now (a control id to its message, as MidiInput keeps them): a key learned for none of them goes dark, and what the knobs turned out to be is heard anew.

    void LearnedMixer::setFaderPickup(bool pickup)

    Has every fader and absolute knob wait to reach its value before it takes it (pickup on, the default), or set the value on any move (off): FaderPickup::setPickup().

    void LearnedMixer::setKnobs(std::optional<RelativeEncoder::Mode> knobs)

    Has the controller's endless knobs read as knobs (none: told by what they send).

    void LearnedMixer::setLights(bool lights)

    Sends the learned keys' state back to the controller (lights), or not: turned off, the lights it lit go dark.
