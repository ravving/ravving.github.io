    KeySpelling Class

    How the notes and chords of a key are written: with flats in a flat key (C minor's E♭, A♭maj7, B♭), with sharps otherwise. More...

    Detailed Description

    The chords machine names its chords with it, and Machine::usesFlats() answers from it. Rave.qml's usesFlats() is its QML twin, for the note names the rolls and the header show.

    Member Function Documentation

    [static] QString KeySpelling::chordName(const QList<int> &notes, bool flats)

    Returns the name of the chord of notes (lowest first): "Cm7", "E♭", "A♭maj7"…, read from the intervals over its lowest note, spelled with flats when flats. Fewer than three notes read as the notes themselves ("C·G").

    [static] QString KeySpelling::noteName(int note, bool flats)

    Returns the name of note (a MIDI note or a pitch class), without its octave: "E♭" with flats, "D#" without.

    [static] bool KeySpelling::usesFlats(int root, const QList<int> &scale)

    Returns whether the key of root and scale is spelled with flats, by its key signature: the major scale it is a mode of (F, B♭, E♭, A♭, D♭ and their modes; C minor is E♭ major's). A scale that is not a mode of the major (harmonic minor) goes by its third: minor as the relative major, major as its root.
