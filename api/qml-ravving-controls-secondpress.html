    SecondPress QML Type

    What waits for a confirming second press, as ravving asks before anything it cannot take back (opening over unsaved changes, DELETE). More...

    Import Statement: import Ravving.Controls 1.0

    Detailed Description

    Ask(what) says false the first time and keeps what pending, true when the same what is asked again within duration; then the pending one runs out. The owner shows the countdown (ArmBar, a ChoicePopup's armedAction / armedValue) where pending says, and says why in a notice.

    
 SecondPress { id: confirm }
 if (studio.projects.dirty && !confirm.ask(path)) return; // tap again to go on

    Forgets what was asked: the next ask() starts over.
