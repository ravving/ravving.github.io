    Detailed Description

    ControllerDrivers makes one per controller a driver fits, gives it its sender (libravving::Router::sendSysex) and hands it what the controller sends (receiveSysex()). A driver implements start() (its handshake) and handle() (every message in). What the controller can do is a capability interface the driver also implements (ControllerOctave, ControllerScale), which ControllerDrivers offers its hub (a ControllerHub) while the driver runs: the app talks to the hubs, never to a driver.

    State: idle, then whatever the protocol sets (connecting, ready, lost…); facts (its serial, firmware, battery…) for whoever shows them. GUI thread only.

    [signal] void ControllerDriver::midiEmulated(int status, int data1, int data2)

    Emitted for a plain MIDI message the protocol stands in for: a block's buttons reach the host as its own messages once hosted, so the CCs they sent before are made here (status with its channel, data1, data2), for MidiInput's learned controls.

    [static] QByteArray ControllerDriver::pack7(const QByteArray &bytes)

    Returns bytes as 7-bit MIDI data bytes: every 7 bytes become 8, the first holding the high bits of the 7 that follow (the way the MIDI sample dump and many editors pack).

    void ControllerDriver::receiveSysex(const QByteArray &bytes)

    A message bytes (without 0xF0 and 0xF7) came from the controller: the request waiting for it gets it, else the protocol's handle().

    [protected] void ControllerDriver::request(const QByteArray &bytes, const ControllerDriver::Matcher &matches, const ControllerDriver::Reply &onReply, int timeoutMs, const std::function<void ()> &onTimeout = {})

    Sends bytes and waits timeoutMs for the message matches accepts, handed to onReply; past the time, onTimeout (when given). Other messages meanwhile go to handle() as usual.

    [protected] void ControllerDriver::send(const QByteArray &bytes)

    Sends bytes (without 0xF0 and 0xF7) to the controller.

    void ControllerDriver::setSender(const ControllerDriver::Sender &sender)

    Sets sender, what send() hands a message's bytes (without 0xF0 and 0xF7) to.

    [pure virtual] void ControllerDriver::start()

    Starts the conversation: the protocol's handshake. The state says how it goes.

    [virtual] void ControllerDriver::stop()

    Ends the conversation: pending requests and the keep-alive are dropped, the state is idle again. A protocol doing more (a goodbye) calls this last.

    [static] QByteArray ControllerDriver::unpack7(const QByteArray &bytes)

    Returns the bytes pack7() made of bytes: the other way round.
