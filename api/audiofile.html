    Detailed Description

    The functions read whole files into memory, so the longer ones run in a worker thread (QtConcurrent), never on the GUI thread. They are reentrant and touch no shared state. Processed files are written as 32-bit float WAV, so no processing step clips.

    Function Documentation

    QStringList AudioFile::exportFormats()

    Returns the export formats: wav (24-bit PCM), flac (24-bit, compression level 8), ogg (Vorbis, VBR quality 0.9) and mp3 (LAME VBR, quality 0.9).

    QString AudioFile::extensionFor(const QString &format)

    Returns the file extension, with its dot, for the export format; .wav for an unknown one.

    AudioFile::Info AudioFile::info(const QString &path)

    Returns the length, sample rate and channel count of the file at path; all 0 when it cannot be read.

    AudioFile::Take AudioFile::processTake(const QString &source, const QString &target, float highPassHz)

    Makes the recorded take source into a sample at target (a 32-bit float WAV), cleaned up without bringing its noise up:

    • refused when it peaks under -50 dBFS (nothing plugged in, or the gain far too low);
    • high-passed at 12 dB/octave at highPassHz (80 for a mic: rumble and proximity boom; 20 for a line: only DC);
    • gated: the take's own noise floor (its quietest 10 ms stretches) is measured and whatever stays within 12 dB of it is pulled down by up to 30 dB (a 1:3 expander, 2 ms attack, 120 ms release), so the hiss between phrases is not raised;
    • compressed 3:1 above 15 dB under its peak (5 ms attack, 120 ms release);
    • normalised to -1 dBFS.

    The returned trim is the last burst of sound: the last stretch above a gate 30 dB under the peak (gaps under 150 ms bridged), from 10 ms before it to where its tail falls 45 dB under the peak, so a take with several tries keeps the last one. Runs in a worker thread.

    QList<double> AudioFile::transients(const QString &path, qreal start, qreal end, float threshold)

    Returns the onsets inside the window start .. end (fractions of the file) of the file at path, as fractions of the file, found on its 10 ms peak envelope. An onset is a window whose peak jumps above threshold (0..1 of the loudest peak) from the quiet before it; onsets closer than 60 ms count as one. The window's start is not reported. Returns an empty list when the file cannot be read.

    AudioFile::Cut AudioFile::writeCut(const QString &source, const QString &target, qint64 head, qint64 body, qint64 tail, const QString &format = QStringLiteral("wav"))

    Cuts a track out of the raw master recording source and writes it to target in format at the recording's rate: skips head frames (recorded before the first beat), keeps body plus tail frames (padded with silence when the recording is shorter), fades the tail out with a raised cosine over its whole length, and pulls the whole cut down to -0.1 dBFS only when it peaks above full scale. Runs in the exporter's worker thread.

    bool AudioFile::writeReversed(const QString &source, const QString &target)

    Writes source backwards to target, a 32-bit float WAV of the same rate and channels, for a reversed sampler slot or pad. Returns false when either file fails.

    bool AudioFile::writeWindow(const QString &source, const QString &target, qreal start, qreal end, bool normalise)

    Writes the window start .. end (fractions of the file) of source to target, a 32-bit float WAV, normalised to -1 dBFS when normalise is true. Returns false when either file fails.
