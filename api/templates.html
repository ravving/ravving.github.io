    Detailed Description

    A template keeps the tempo, the swing, the key (root and scale) and the live effects' send levels (phaser, echo, heavy); start() creates a new project (Projects::newProject()) with those set. Templates are listed from the user's folder (list) or a USB stick (listFolder()), and saveCurrent() stores the session's settings as one.

    A template is one JSON file, in the same format as the pattern presets, so it is exchanged the same way (PresetExchange; on a stick under ravving/presets/templates/):

    
 {"ravving": "preset", "type": "template",
  "template": {"name": "Black Metal", "genre": "Black Metal", "about": "...",
               "bpm": 180, "swing": 50, "swingEighths": false,
               "root": 4, "scale": "Natural Minor",
               "phaser": 0, "echo": 0.1, "heavy": 0.6}}

    bpm is the tempo in whole BPM; swing is a percentage, 50 (straight) to 75; root is 0 to 11 from C and scale a name of scaleNames(); phaser, echo and heavy are LiveFx's send levels, 0..1. Any of them may be left out; a new project's own value then applies. GUI thread only.

    [invokable] QString Templates::saveCurrent(const QString &name)

    Saves the session's tempo, swing, key and live-effect send levels as a user template under name (tidied, made unique). Returns the name used, or an empty string on failure.

    Note: This function can be invoked via the meta-object system and from QML. See Q_INVOKABLE.

    [static] const QStringList &Templates::scaleNames()
