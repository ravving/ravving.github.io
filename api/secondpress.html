    SecondPress Class

    A key's confirming second press: the first press within the window arms it, the next within the window confirms. More...

    Detailed Description

    The backend's counterpart of the kit's SecondPress and ConfirmButton: the same three-second window ravving asks with everywhere a second press goes on with something (SAVE's AGAIN?, the power row, DELETE). No timer runs: the moment of the first press is kept and compared at the next.

    Registers a press: returns true when it confirms one made within the window (and forgets it), false when it is the first (and keeps it as such).

    Forgets a first press: the next press starts over.
