    Stepper QML Type

    A value stepped one at a time: its caption, then − (an ActionButton), the value and + on one ControlGroup, the badge of the device knob that turns it on the group's corner. More...

    Detailed Description

    The owner keeps the value: it shows valueText and acts on stepped (−1 or +1). The value sits in the monospaced figures, as wide as valueSample, so nothing moves as it changes; pulse() flashes it in the accent (the OCT readout, when the octave changes). Used for EXPORT's BARS, LOOPS and TAIL, the SONG page's LENGTH and REPEATS, the tuner's A4 and the pattern toolbar's OCT.
