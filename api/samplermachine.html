    Detailed Description

    The current bank is the one that plays. Each loaded slot is one ClipAudioSource on the machine's sketchpad track (slot i on sample slot i % 5, row i / 5), set up on its root slice: its key zone and root note are the slot's note (kits.json's baseNote + i), so a pattern note or a live key plays exactly that sample, untransposed. It plays one-shot (a retrigger cuts the previous voice); the slot's pitch is the slice's pitch (±12 semitones); the trim (start as a fraction of the file, length as a fraction of what follows the start) is its start and length; reverse plays a reversed copy of the file, rendered once on a worker thread into the cache folder. The track is sample-trig, so its PatternModel sends its notes to SamplerSynth for the clips the track publishes (SketchpadTrack::setSamples()).

    The step pattern follows DrumMachine's interface: a row per slot, an accent row, and per-row level, mute and solo applied as velocities. Presets (sampler-presets.json) are rhythms over the slots: keys "1" to "8" a row each, "x" a hit and "X" an accented one. The current bank is view state, outside the undo history, and a section keeps the banks' hits, not their samples.
