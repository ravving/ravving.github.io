    Detailed Description

    The bank on screen is the one that plays. Each loaded slot is one ClipAudioSource on the machine's sketchpad track (slot i on sample slot i % 5, row i / 5), set up on its root slice: its key zone and root note are the slot's note (kits.json's baseNote + i), so a pattern note or a live key plays exactly that sample, untransposed. It plays one-shot (a retrigger cuts the voice before, as easyrave's slots choke); PITCH is the slice's pitch (±12 semitones); the trim (start and length, as fractions of the file) is its start and length; REVERSE plays a reversed copy of the file, rendered once in a worker thread into the cache folder. The track is sample-trig, so its PatternModel sends its notes to SamplerSynth for the clips the track publishes (SketchpadTrack::setSamples()).

    The step grid is StepGrid's pattern interface, as DrumMachine's: the rows are the slots, with an ACC row and per-row level, mute and solo kept in the velocities. Presets (sampler-presets.json) are rhythms over the slots: "1" to "8" a row each, "x" a hit and "X" an accented one, so the grid has a groove as soon as sounds are dropped in. The bank on screen is not part of the undo history, and a section keeps the banks' hits, not their samples.
