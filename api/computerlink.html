    Detailed Description

    Computers owns any number of them, each in its own group of the settings file (computers/<id>), all logging in with the one device key.

    setup() takes the computer's host name or address, the user name there and that user's password. The password is used once and never stored: it opens the first connection so the device's own SSH key (created on demand, ~/.config/ravving/ssh/id_ed25519) can be added to the computer's authorized_keys (ssh-copy-id); from then on the key is the credential. If the computer refuses the key (reinstalled, the key removed), status becomes refused and setup() must run again. The computer's host key is kept in a known_hosts of ravving's own: accepted on the first connection, refused if it changes; forget() removes it.

    The password reaches ssh through SSH_ASKPASS (with OpenSSH 8.4's SSH_ASKPASS_REQUIRE=force): a helper script prints it from a file readable only by this user, created for the duration of the set-up and deleted after. No terminal input and no third-party program (sshpass) is needed. All ssh and scp runs are asynchronous QProcesses with timeouts; GUI thread only.

    Member Function Documentation

    [explicit] ComputerLink::ComputerLink(const QString &id, QObject *parent = nullptr)

    Constructs the computer id, reading its settings, with the given parent.

    [invokable] void ComputerLink::check()

    Tries the key and reads the Downloads folder: status becomes ready, unreachable or refused. Does nothing while busy or when nothing is set up.

    Note: This function can be invoked via the meta-object system and from QML. See Q_INVOKABLE.

    [invokable] void ComputerLink::forget()

    Forgets the computer: its settings and its entry of the host keys go; the device key stays. forgotten() follows, and Computers drops the object. Does nothing while busy.

    Note: This function can be invoked via the meta-object system and from QML. See Q_INVOKABLE.

    [signal] void ComputerLink::forgotten(const QString &id)

    Emitted when forget() ran, with the computer's id; the owner then removes the object.

    [signal] void ComputerLink::notify(const QString &text, const QString &color)

    Emitted with a short translated status text and its color (a CSS colour).

    [invokable] void ComputerLink::send(const QStringList &files)

    Copies files (those that exist) into the computer's Downloads folder with scp, one file at a time; sent() ends it. Files sent while a transfer runs join its queue. Without a computer set up, sent() reports a failure at once.

    Note: This function can be invoked via the meta-object system and from QML. See Q_INVOKABLE.

    [signal] void ComputerLink::sent(bool ok, int count, const QString &label)

    Emitted when a transfer ended: ok when every file arrived, count files, to label.

    [invokable] void ComputerLink::setup(const QString &host, const QString &user, const QString &password, int port = 22)

    Sets the computer up at host and port for user: makes the device key if needed, installs it there with password (used once, never stored) and finds the Downloads folder. setupFinished() ends it.

    Note: This function can be invoked via the meta-object system and from QML. See Q_INVOKABLE.

    [signal] void ComputerLink::setupFinished(bool ok, const QString &message)

    Emitted when setup() ended: ok when it worked, with a translated message.
