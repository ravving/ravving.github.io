    Detailed Description

    The machines keep their music in the session; these files are only read, as a project opens (Studio): a drum machine without saved steps takes its clip's notes from them, and every machine its clip's length (Machine::attach()). ravving never writes them.

    Member Function Documentation

    [static] QList<LegacySequence::Clip> LegacySequence::read(const QString &projectDir)

    Returns every clip of the sequence in projectDir that has a pattern file, in track and clip order. A project without one gives none.

    [static] bool LegacySequence::readPattern(const QByteArray &json, LegacySequence::Clip &clip)

    Reads one pattern file's json into clip's pattern and length, as libzynthbox's PatternModel read it: its grid (one row a bar, width steps a row) of compound notes, each subnote with its velocity (below 0 does not play: 0 here; 0 played at 64), duration and delay; its patternLength (or availableBars rows, in older files), the rows taken from bar bankOffset on. Returns false for a file that is not a pattern.
