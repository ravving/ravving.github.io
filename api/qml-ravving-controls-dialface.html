    DialFace QML Type

    A dial's face, drawn in vector so it stays crisp at any size (the theme's SVG dial blurs and breaks up at the 26–40 px the machines use). More...

    Detailed Description

    Flat and simple, every proportion taken from the diameter:

    - a groove: a 270° ring, open at the bottom; - the value: an arc in the accent along the groove, from the start of the travel, or

    
 from the centre (`origin`) for a range around zero (pan, pitch, dB);

    - a body: a dark disc inside the ring; - a pointer: a short rounded line on the body, at the value.

    The ring and the value arc are a Shape (curves stay crisp), made again at each size (see there why); the body and its pointer are a Rectangle and a turned bar (see the body). It only draws: Knob puts it behind a QQC Dial, which keeps the touch handling.

    An owner that dims it (opacity < 1) must render through a layer (layer.enabled): blended item by item, the groove and the arc stack where they overlap and the face looks off-centre.

    Property Documentation

    accent : color

    Colours: the value arc, and the groove/pointer ink (the surface's text colour). With none given, the skin's accent and ink, when there is one.

    diameter : real [read-only]

    The travel: 270°, from the lower left clockwise to the lower right (Shape angles run clockwise from 3 o'clock).

    gap : real [read-only]

    The ring's stroke and the gap between ring and body, both from the diameter (with floors so a small dial keeps a readable ring).

    ink : color

    Colours: the value arc, and the groove/pointer ink (the surface's text colour). With none given, the skin's accent and ink, when there is one.

    originPosition : real

    Where the value sits in its range (0..1), and where its arc starts from (0..1).

    pointerColor : color

    The pointer on the body: light, as the body is dark on every skin.

    position : real

    Where the value sits in its range (0..1), and where its arc starts from (0..1).

    pressed : bool

    Brighter while held.

    ring : real [read-only]

    The ring's stroke and the gap between ring and body, both from the diameter (with floors so a small dial keeps a readable ring).

    ringRadius : real [read-only]

    The ring's stroke and the gap between ring and body, both from the diameter (with floors so a small dial keeps a readable ring).

    startAngle : real [read-only]

    The travel: 270°, from the lower left clockwise to the lower right (Shape angles run clockwise from 3 o'clock).

    sweep : real [read-only]

    The travel: 270°, from the lower left clockwise to the lower right (Shape angles run clockwise from 3 o'clock).

    Method Documentation

    angleAt(position)

    Returns the angle, in degrees clockwise from 3 o'clock, of position (0 to 1) along the dial's travel.
