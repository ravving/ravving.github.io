    ControllerOctave Class

    A controller with an octave of its own, as ControllerOctaves sees it: ravving's octave goes to it (followOctave()) and its own changes come back (requestOctave()), both only while linked (setOctaveLinked()). Whatever talks to the controller implements it (RoliBlocks). More...

    ravving's octave (−2 to 2), for the controller to take.

    int ControllerOctave::octave() const

    Returns the octave the controller plays in now, as it last said (octaveMoved()).

    bool ControllerOctave::octaveLinked() const

    Returns whether the controller's octave is linked to ravving's.

    See also setOctaveLinked().

    [protected] void ControllerOctave::octaveMoved(int octave)

    The controller plays in octave now: its own change, or ravving's it took. Its driver calls this whenever it knows.

    [protected] void ControllerOctave::requestOctave(int octave) const

    The controller moved its own octave to octave: asked of ravving while linked.

    [virtual] void ControllerOctave::setOctaveLinked(bool linked)

    Links the controller's octave to ravving's (linked, the default). An implementation that keeps its own octave when unlinked overrides this and calls it.

    See also octaveLinked().
