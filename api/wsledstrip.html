    Detailed Description

    Each LED bit is sent as one SPI byte at 6.4 MHz (1 as 0b11110000, 0 as 0b11000000), in GRB order, followed by 64 zero bytes (80 µs of low line) that latch the colours.

    Not copyable. Not thread-safe; Leds uses it on the GUI thread.
