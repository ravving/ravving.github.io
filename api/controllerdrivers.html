    Detailed Description

    A driver is registered with addDriver(), as a DriverSpec: its id, which controllers it is for (by a part of their name, DriverSpec::named(); or the ones whose settings name it as their surface, DriverSpec::surface(): a Mackie Control surface, by its profile's defaults or by the user's choice, setSurface()), how its ControllerDriver is made and which settings remake it. The first driver registered that fits a controller hosts it. Hosting can be turned off per controller (setEnabled(): the host setting, ControllerSettingsStore).

    A controller is one device however many connections it has (ConnectionRegistry: a cable's several ports, its radio beside its cable), made for the controller's id; what the controller sends on any of its connections reaches it (its System Exclusive through the ConnectionMultiplexer, its short messages through MidiInput::setSurface() for a control surface), and what it sends goes through the MidiTransport, to whichever connection carries the controller now. The device is remade when its driver changes (another surface chosen) or when a setting its driver remakes on does (DriverSpec::remakeOn: a surface's knobs' encoding and its faders' pick-up), and started or stopped as hosting is turned on or off.

    While a driver runs, every hub (addHub(): studio.octaves, studio.scales…) is offered it and takes it if it has the hub's capability. GUI thread only.

    [invokable] void ControllerDrivers::setEnabled(const QString &id, bool enabled)

    Hosts the controller id (enabled) or leaves it alone: it keeps sending plain MIDI either way. Kept in the controller's settings (host); its device starts or stops with it (refresh()).

    Note: This function can be invoked via the meta-object system and from QML. See Q_INVOKABLE.

    See also enabled().

    [invokable] void ControllerDrivers::setSurface(const QString &id, const QString &type)

    Has the controller id hosted as a control surface by the driver type (mackie), or by none (empty): kept in its settings (surface). Chosen, it is hosted (setEnabled()); none, it is a plain controller again.

    Note: This function can be invoked via the meta-object system and from QML. See Q_INVOKABLE.
