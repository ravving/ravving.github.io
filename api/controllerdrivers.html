    Detailed Description

    A driver is registered with addDriver(): an id, the part of a controller's name that picks it ("BLOCK" for ROLI's), and what makes its ControllerDriver. Hosting a controller can be turned off per controller (setEnabled(), kept in the ravving/midi settings beside MidiInput's). While a driver runs, every hub (addHub(): studio.octaves, studio.scales…) is offered it and takes it if it has the hub's capability. GUI thread only.
