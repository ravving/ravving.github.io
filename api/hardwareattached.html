    Detailed Description

    
 Item {
     focus: true
     Hardware.onKnob1Up: event => level += event.delta
     Hardware.onStepPressed: event => toggle(event.index)
     Hardware.onUpPressed: event => { if (atTop) event.accepted = false }  // bubble up
 }

    deliver() emits the specific signal (knob2Down, leftPressed…) when a handler is connected to it, then the generic one (knobTurned or knobMoved for knobs) and finally pressed() while the event is still not accepted. Buttons are delivered on release, except stepDown(). Only connected signals run, so an item handles only what it declares.

    Created by Hardware::qmlAttachedProperties() for each item that uses Hardware, and owned by that item.

    Property Documentation

    enabled : bool

    This property holds whether the item's handlers receive events. When false every event passes through this item untouched. Defaults to true.

    bool HardwareAttached::deliver(HardwareEvent *event)

    Runs this item's handlers for event in the order the class description gives, and returns whether one of them accepted it. Returns false at once when the object is not enabled. Called on the GUI thread by Hardware::dispatch() and Hardware::deliverTo().
