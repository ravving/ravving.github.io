    Detailed Description

    The one grammar for a learned message, wherever one is kept or read: MidiInput's controls, the known controllers' defaults (data/midi-devices.json), a LearnedMixer's lights. A message hashes by its key() (its kind, channel and number packed), so the controls learned can be looked up as the bytes arrive. Channels are 1 to 16, as the settings show them.

    LearnedMessage::Kind::Bend2a pitch bend (a fader's 14 bits); its number is 0
