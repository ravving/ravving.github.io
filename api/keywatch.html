    Detailed Description

    A controller says nothing of its own key, so its notes are read: of the last Window notes (at least Fewest) a controller played where notes play as notes (pitched()), when three or more fall outside the project's key while all of them fit the same scale a few semitones away (and at least five pitch classes were played, so a pad's few notes say nothing), the issues center gets a warning naming the controller and the key its notes fit, which also pops up as a message. It clears once the controller's notes fit the project's key again, or the key changes. Chromatic playing fits no one key and is left alone. GUI thread only.

    Property Documentation

    pitched : bool

    This property holds whether the page on screen plays a controller's notes as notes (bass, lead, the chords' NOTES): only those are read. Pads and chord keys are not.

    int KeyWatch::shiftOf(const QString &controller) const

    Returns how far (in semitones, -5 to 6) the key controller's last notes fit is from the project's: 0 when they fit the project's key, or no other key better, or too few were heard.
