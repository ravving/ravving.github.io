    ravving C++ Classes

    Every C++ class of the ravving app, its backend library and its setup program. More...

    Namespaces

    AlbumArt

    Cover art drawn for a track, so every export has artwork of its own

    AudioFile

    Audio-file operations on libsndfile (WAV, FLAC, Ogg, AIFF...) for the samplers and the exporter

    AudioGraph

    Audio graph's clock: the sample rate and period PipeWire's JACK graph runs at

    EffectChain

    SOUND EFFECTS chain every machine has, in signal order (easyrave's insert chain): DRIVE, COMPRESSOR, REVERB, EQ, PAN, SIDECHAIN, DELAY, each with its knobs

    FileSuffixes

    File suffixes, lower case and without the dot, each kind of library file comes in; shared by the USB page (UsbLibrary) and the FILES browser (FileBrowser). Declared in filesuffixes.h

    HardwarePorts

    A sound card's ports on the JACK graph, found by the card, never by a fixed JACK name (docs/routing.md, "Hardware port names")

    Issues

    How components report to the issues center

    LastRun

    Whether the run before this one ended cleanly, told to the issues center at start

    ProjectCheck

    What a project names that is missing, noted while it opens (docs/testing.md, "Projects that still resolve")

    Requirements

    What this device lacks for ravving's features, told to the issues center (data/requirements.json, docs/packaging.md "What the device needs")

    SamplerBanks

    Samplers' banks as a section sees them

    SceneInspector

    Logs what the running scene holds, for the remote-control fifo's debugging commands

    SoundFontFile

    What an SF2 or SF3 soundfont says about its presets, read without loading its samples

    SoundPresets

    An LV2 plugin's factory presets, read from its bundle's presets file

    zb

    Helpers for calling into libzynthbox objects through Qt's meta-object system

    Classes

    AlbumArtProvider

    Serves AlbumArt to QML as image://albumart/<title>%09<artist>%09<album>

    AudioFile::Cut

    Result of writeCut(): an export cut from a raw recording

    AudioFile::Info

    A file's length in frames, sample rate and channel count, as info() reads them

    AudioFile::Take

    Result of processTake(): whether it worked, and the take's last burst of sound as a slot trim

    AudioInsert

    Something audio goes through on the JACK graph, with stereo or mono inputs and outputs

    AudioOutputs

    Where the sound goes: the device's jacks, an HDMI screen, or a connected Bluetooth speaker or headphones; published to QML as outputs (the control center's AUDIO OUTPUT)

    AudioTap

    A tap on the master for the video recorder: a JACK client that copies what the speakers get into a ring buffer and feeds it to ffmpeg through a named pipe

    BeatRepeat

    LIVE FX STUTTER and LOOP: a beat repeat on the master, as ravving's own JACK client (ravving-repeat, stereo in and out), the first of the master inserts

    Bluetooth

    The way a phone does it, published to QML as bluetooth: switch it on, find what is around, pair, connect, then send a file to a device or play through it

    Bundle

    Ravving bundle the setup program was started from, and what the device does with it; published to Setup.qml as bundle

    ChordMachine

    CHORDS machine (easyrave's POLY-6): a Machine playing chords on a polyphonic engine (TAL NoiseMaker, six voices, Juno chorus)

    CommandResult

    What a command run by runCommand() ended with

    ComputerLink

    A computer of the user's to send files to over SSH: the laptop or PC whose Downloads folder gets exported tracks, bundles and videos

    Computers

    User's computers over SSH, published to QML as computers (SETTINGS, COMPUTERS): any number of ComputerLinks, each a laptop or PC whose Downloads folder gets exports, bundles and videos

    ConsoleProcess

    A helper process ravving drives through its text console (FluidSynth's shell, jalv's command line), run by libzynthbox's ProcessWrapper

    CuiaFifo

    Remote-control fifo at /tmp/webconf-writes-to-this-fifo: each line written to it is a command for ravving

    DeviceControls

    Device's own settings and vital signs for the control center (the menu drawer), published to QML as device

    Diagnostics

    Issues center, published to QML as issues: what is wrong on this device now, in the user's words, with what to do about it

    DrumKit

    A drum kit read from a soundfont (SF2 or SF3): which key plays which drum

    DrumKit::Row

    One grid row of a kit

    DrumMachine

    One drum machine of the drums page (HOUSE 909, DEEP 808, LinnBeats): a Machine whose steps are drum hits

    EffectChain::Effect

    An effect of the chain: its name and its knobs, in card order

    EngineProfiles

    What each engine lets a page tweak: the profiles of data/engines.json, one per engine (docs/engines.md)

    Exporter

    Project's exports, published to QML as studio.exporter: a track (an audio file) or a bundle (a .ravv zip), both into the library's exports folder (Paths::exports()), where the music player finds them

    FileBrowser

    FILES browser, published to QML as files (the control center's FILES card): everything in ravving's library (Paths), by kind, each entry with SEND... and DELETE

    FileShare

    A small HTTP server inside ravving, published to QML as share: one file offered to a phone (the SEND... dialog's PHONE, QR CODE destination), the ravving page, and the library for a phone to browse

    FluidSynthEngine

    A FluidSynth process playing one soundfont preset (SF2 or SF3), such as a drum machine's kit or a soundfont sound source

    GlobalEffects

    Studio's two send effects, as zynthbox-qml's global FX 1 and 2: one reverb and one delay that every machine sends into, their returns mixed into the master

    Hardware

    QML type that carries the Hardware attached property, and the dispatcher that walks the focus chain

    HardwareAttached

    Hardware attached object: the device's knobs and buttons for one item, the way Keys gives it the keyboard

    HardwareEvent

    One hardware event (a knob turn, a pot move, a button) delivered to QML through the Hardware attached property

    HardwareKnobs

    Polls the device's four knobs (zyncoder's zynpots) and reports them as relative turns or absolute positions

    HardwareSwitches

    Polls the device's buttons (zyncoder's zynswitches) and puts every press and release on MidiRouter's CUIA queue

    History

    Project's undo history, published to QML as studio.history

    HistoryParticipant

    Interface of an object whose changes History can undo

    InputEffects

    Live effects on the device input, published to QML as studio.input.effects: a chain of LV2 plugins (jalv) between the input and both the monitor and the take, so what is heard is what is recorded

    InputRecorder

    Device's audio input (the input jack), recorded into the samplers and the RECORDER; published to QML as studio.input

    JackWiring

    Keeps the JACK graph wired for ravving's tracks, as zynthbox-qml's autoconnect (zynautoconnect/zynthian_autoconnect.py) wires a synth on a sketchpad track

    JalvEngine

    An LV2 instrument as a machine's sound engine, run by jalv (a JalvPlugin), as zynthbox-qml runs its jalv engines

    JalvPlugin

    One LV2 plugin running in its own jalv process on the JACK graph: an effect (a reverb, a delay..., audio in and out) or an instrument (MIDI in, audio out; JalvEngine)

    KeyedListModel

    A list model that applies each new list of maps as the fewest row changes, so QML views keep their delegates

    Leds

    Device's button LEDs by button name, published to QML as leds

    LiveFx

    Header's LIVE FX: performance effects on the whole mix, as easyrave's top bar has them; published to QML as studio.liveFx

    LiveRecordings

    RECORDER's recordings: the takes kept as played (InputRecorder::record(true)), published to QML as studio.input.recordings

    Localization

    Interface's language (KI18n), published to QML as localization (docs/translations.md)

    Machine

    Base of every machine of the studio (a drum machine, the bass, the chords, the samplers): an instrument on one libzynthbox sketchpad track, playing a pattern of steps from its PatternModel through its sound engine

    MidiInput

    External MIDI controllers (keyboards, pads) as an input for LIVE and REC, published to QML as studio.midiIn

    MixRecorder

    Global recording: everything that reaches the speakers (libzynthbox's GlobalPlayback, the master) written to a WAV file, as easyrave's top-bar RECORD exports the song; published to QML as studio.mix

    MonoMachine

    A monophonic line: the BASS (easyrave's AC 303, on DISTRHO Nekobi) and the LEAD (on Calf Monosynth) are both this machine, configured in kits.json

    MouseWatcher

    Shows the pointer only while a mouse is plugged in

    MusicLibrary

    Tracks on the device the music player lists, published to QML as studio.music.library

    MusicPlayer

    Music player, published to QML as studio.music: a queue of the library's tracks (MusicLibrary) played one after the other through Qt Multimedia

    NamedStore

    User's own named entries of one kind, kept in a JSON file of their own ({"presets": [{"name": ..., ...}, ...]})

    OutputWatch

    Checks that the sound sent to another output (AudioOutputs' loopback into a Bluetooth or HDMI sink) comes out of it

    PadKitControls

    PAD SAMPLER's SOUND MODIFIERS: the knobs that belong to the kit rather than to one pad

    PadSamplerMachine

    PAD SAMPLER: an MPC-style sampler (docs/mpc-sampler-plan.md), a Machine playing 16 pads on libzynthbox's SamplerSynth, in four banks (A to D) of 16 pads and steps each

    Paths

    Where ravving keeps its files: one place that decides every folder

    PitchDetector

    Pitch of a plucked string in a block of mono audio: the TUNER's ear (Tuner)

    PresetExchange

    User's presets as files to share on a USB stick: the pattern presets they saved (a machine's PresetLibrary: the toolbar's PRESET), the sounds they saved (a machine's MY SOUNDS) and their project templates

    PresetLibrary

    A machine's pattern presets: the factory ones from its data file and the user's own, kept in a file of their own (NamedStore) so they survive across projects

    Projects

    Saved projects behind the header's SAVE and PROJECT menu, published to QML as studio.projects

    QmlSourceOverride

    A development aid that serves the Ravving module's QML files from a source tree instead of the copies compiled into the binary

    QrCodeItem

    A QML item that draws a QR code of its text (QrCode { text: share.url })

    Ravving

    App-level state the QML shell binds to, and the entry point of the hardware input; published to QML as ravving

    RemovableDrives

    USB sticks, published to QML as drives: what is plugged in, mounted when ravving needs it, and ejected cleanly

    SamplerMachine

    SAMPLER (easyrave's SAMPLE KING): a Machine playing samples on libzynthbox's SamplerSynth, with four banks (A to D) of eight sample slots and steps each

    Sections

    SECTIONS: the parts of a song (an intro, a verse, a bridge), each holding every machine's pattern at once, and the song: the sections in order, each played a number of times (docs/sections-plan.md); published to QML as studio.sections

    Sections::Host

    What Sections needs of the machines; the studio implements it

    Sketchpad

    Sketchpad as libzynthbox sees it: PlayGridManager's zlSketchpad

    SketchpadTrack

    One sketchpad track as libzynthbox's PatternModel sees it

    SoundControls

    A machine's SOUND MODIFIERS: cards of knobs that each drive its engine's own controls (LV2 ports of a jalv engine, FluidSynth's cc: and gen: controls, by symbol)

    SoundControls::Card

    One card: its title and its knobs, in order

    SoundControls::Choice

    One position of a switch knob: its label and the engine controls it sets (symbol to value)

    SoundControls::Knob

    One knob: its name, the engine control it drives (symbol), its range there (minimum, maximum), its defaultValue (0..1), its choices when it is a switch (empty for a continuous knob) and whether it maps exponentially (logarithmic)

    SoundEngine

    A sound engine a machine plays through: a process with a MIDI input and a stereo output on the JACK graph

    SoundPresets::Preset

    One factory preset: its name (without its kind's prefix), title (without its author either), category (what the prefix names: PADS, KEYS...) and controls (the port values, symbol to value)

    StartupSplash

    Startup splash and its life, published to QML as startup (null when none is shown)

    StderrWatch

    Reads everything the process writes to stderr, passes it on to the journal and turns known trouble into issues

    Studio

    Ravving's backend root, published to QML as studio: the machines, the transport and the project

    StyleHost

    What the Zynthbox Quick Controls style expects from its host application, published as the zynqtgui context property

    TakeRecorder

    A machine's REC: a fresh take of what is played LIVE on it, recorded into its pattern as easyrave's per-machine REC does; published to QML as studio.take

    Templates

    Project templates, published to QML as studio.templates: how a project starts out, not what it plays

    TrackEffects

    One machine's SOUND EFFECTS (the EffectChain), on its track's JackPassthrough, the processing every libzynthbox track has; published to QML as machine.effects

    Tuner

    TUNER (the RECORDER's GUITAR tab): the pitch of the string played into the device input, against a tuning's open strings; published to QML as studio.input.tuner

    UnixSignals

    Turns SIGTERM and SIGINT into a Qt signal on the main thread, so systemctl stop and Ctrl+C run ravving's exit steps (the lights off) before the process ends

    UsbLibrary

    What a USB stick holds for ravving, and moving it either way: the USB page's backend, published to QML as usb

    UserProfile

    Who uses the device, published to QML as profile: the names the exports put on every track and bundle, and the device's own settings

    VideoRecorder

    Video recordings of a session (LIVE REC), published to QML as video: the screen or a USB camera with the master's sound, as one MP4 in the library's videos folder (Paths::videos()), or the sound alone

    Wifi

    Wi-Fi for the control center, published to QML as device.wifi: switch it, list the networks in range, join one with its passphrase, leave it, forget it

    WifiNetworks

    Wi-Fi networks in range, as a list model for the network list

    WpaConfig

    Zynthbox's saved Wi-Fi networks: the wpa_supplicant.conf in its config folder

    WpaConfig::Network

    A network block: its ssid (decoded) and its settings in file order (values as written, quotes included)

    WsLedStrip

    A strip of WS2812 ("NeoPixel") LEDs on an SPI bus: the button LEDs of the Zynthbox

    ZipReader

    Reads a zip archive that ZipWriter, or any zip tool, made: stored and deflated entries

    ZipWriter

    A plain zip archive, written without a zip library (zlib does the deflating): what a .ravv project bundle is

    ZynthboxBridge

    Loads libzyncoder and libzynthbox, starts the hardware pollers and forwards their events; published to QML as zynthbox
