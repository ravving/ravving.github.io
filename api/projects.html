    Detailed Description

    A project is one JSON file in the projects folder holding everything the studio keeps (Studio::projectState(): every machine's steps, sounds, kit, effects and levels, the tempo, swing, master, key, live effects...), so it can be copied, backed up or read by hand.

    The current state is always kept by the studio itself (its session, saved after every change and restored at start); a project is a named snapshot of it. save() writes the session over the project it came from (a new one, "RAVE 001", "RAVE 002"..., the first time), saveAsNew() always creates a new one, open() replaces the session with a project, and newProject() starts a clean project (Studio::cleanProjectState()). dirty says whether the session differs from what was last saved or opened: the states are compared, so undoing an edit makes it clean again and notifications that change nothing do not mark it dirty.

    A project may wear an icon: one of the built-in pixel glyphs (Glyphs), kept in its file by the glyph's name under the top-level key icon, and none by default. saveAs() and rename() set it; currentIcon is the current project's. A name that is not a built-in glyph (one a later version removed) reads as no icon.

    The session itself is the caller's (Studio's): a Session of functions reads, restores and replaces it, and sessionModified() reports each change to it.

    The demos ravving ships (data/demos/*.json, installed read-only beside kits.json) are listed after the user's projects, in their own group. A demo opens like any project; save() then keeps the changes as a new user project under the demo's name (the demo itself never changes), and a demo cannot be deleted. The current project and the dirty flag survive restarts (a small marker file in the folder). GUI thread only.

    Member Function Documentation

    Projects::Projects(const Projects::Session &session, const QString &dir, const QString &demosDir = QString(), QObject *parent = nullptr)

    Constructs the projects of the session (what is saved and restored) in the folder dir, with the shipped demos in demosDir (read-only; empty for none), with the given parent.

    QString Projects::addProject(const QString &name, const QVariantMap &state)

    Adds a project file from state, made elsewhere (an imported .ravv bundle), under name (tidied, made unique); it is listed, not opened. Its icon is kept when it names a built-in glyph and dropped otherwise. Returns its path, or an empty string when it could not be written.

    [signal] void Projects::created()

    Emitted when newProject() created a clean project.

    [static] QString Projects::iconOf(const QVariantMap &state)

    Returns the icon state keeps (a project's file, a bundle's project or metadata): its icon when that names a built-in glyph, else an empty string.

    [invokable] bool Projects::isDemo(const QString &path) const

    Returns whether the file path is one of the shipped demos.

    Note: This function can be invoked via the meta-object system and from QML. See Q_INVOKABLE.

    [invokable] void Projects::newProject(const QVariantMap &state = {})

    Replaces the session with a clean project: every machine with an empty pattern, its own engine and the default sound, mix and effects (Studio::cleanProjectState()), with what state holds laid over it (a template's tempo, swing, key and live effects: Templates::start()), and no icon. Emits created().

    Note: This function can be invoked via the meta-object system and from QML. See Q_INVOKABLE.

    [invokable] bool Projects::open(const QString &path)

    Replaces the session with the saved project at path. Returns false when it cannot be read.

    Note: This function can be invoked via the meta-object system and from QML. See Q_INVOKABLE.

    [invokable] void Projects::remove(const QString &path)

    Deletes the saved project at path; the session keeps its contents, unsaved if it was this one. A demo is never deleted.

    Note: This function can be invoked via the meta-object system and from QML. See Q_INVOKABLE.

    [invokable] QString Projects::rename(const QString &wanted, const QString &icon)

    Renames the current project to wanted (tidied, made unique; empty keeps its name) and sets its icon to icon (a built-in glyph's name; anything else, or empty, for none). Only its file's name, name and icon change: what it holds stays as last saved, and unsaved changes stay unsaved. Returns the name used, or an empty string when there is no saved project of the user's open (none, or a demo) or its file cannot be rewritten.

    Note: This function can be invoked via the meta-object system and from QML. See Q_INVOKABLE.

    [invokable] QString Projects::save()

    Saves the session as the current project (a new one when there is none, a copy of the user's when it is a demo). Returns its name.

    Note: This function can be invoked via the meta-object system and from QML. See Q_INVOKABLE.

    [invokable] QString Projects::saveAs(const QString &wanted, const QString &icon = QString())

    Saves the session under the name wanted, wearing the icon icon (a built-in glyph's name; anything else, or empty, for none). The name is tidied (tidyName()) and made unique unless it is the current project's own; an empty name falls back to the next "RAVE nnn". Returns the name used, or an empty string when it could not be written.

    Note: This function can be invoked via the meta-object system and from QML. See Q_INVOKABLE.

    [invokable] QString Projects::saveAsNew()

    Saves the session as a new project, without an icon, which becomes the current one. Returns its name.

    Note: This function can be invoked via the meta-object system and from QML. See Q_INVOKABLE.

    void Projects::sessionModified()

    The session changed: once changes settle (300 ms), dirty says again whether it differs from what was saved.

    [invokable] QString Projects::suggestedName() const

    Returns the name a save gets without one: the next free "RAVE nnn".

    Note: This function can be invoked via the meta-object system and from QML. See Q_INVOKABLE.

    [static] QString Projects::tidyName(const QString &wanted)

    Returns wanted as a project or export file can carry it: trimmed, without path characters (\ / : * ? " < > | and control characters), with single spaces; empty when nothing is left. Inline, so Templates and the exporter name things the same way.
