    MidiValues Namespace

    What a controller's bytes mean, the same wherever they are read (MidiInput, LearnedMixer, MackieSurface): where a CC presses a key (PressedFrom), a pitch bend as a fader's position (faderPosition()), the velocity and pressure curves a controller's settings pick (velocityCurve(), pressureCurve()), a bend scaled to the engines' range (scaledBend()). More...

    Function Documentation

    int MidiValues::bend14(int data1, int data2)

    Returns the 14-bit value of a pitch bend's data1 (the low 7 bits) and data2 (the high 7 bits), 0 to 16383.

    qreal MidiValues::faderPosition(int data1, int data2)

    Returns a pitch bend's data1 and data2 as a fader's position, 0 to 1: BendTop (a 7-bit fader's top) is 1, as is anything above it.

    bool MidiValues::pressed(int value)

    Returns whether a CC at value presses the key it is learned as: from PressedFrom up.

    int MidiValues::pressureCurve(int curve, int pressure)

    Returns channel pressure (0 to 127) through curve: 0 as sent; 1 firm and 2 firmer send less for a light press (a surface that reaches its top halfway); 3 light and 4 lighter send more (one that needs a hard press to reach it). The top stays the top.

    int MidiValues::scaledBend(int bend, int bendRange)

    Returns the 14-bit pitch bend of a controller whose full bend is bendRange semitones, scaled to the engines' EngineBendRange: a controller bending ±48 semitones moves the engines the same semitones, as far as their ±2 go.

    int MidiValues::velocityCurve(int curve, int velocity)

    Returns velocity (1 to 127) through curve: 0 as sent; 1 soft and 2 softer lift light touches; 3 even starts every touch at half (a surface whose slow presses arrive at 1), the strike adding the rest.
