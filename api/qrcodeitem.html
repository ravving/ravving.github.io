    Detailed Description

    The code is generated by Nayuki's QR Code generator (src/backend/thirdparty/qrcodegen, MIT licence) at error-correction level M, which survives a screen photographed at an angle while keeping the code less dense than level H. It is painted crisp: each module is a whole number of pixels (the largest that fits the item with the quiet zone), the code is centred and nothing is antialiased. It is a painted item rather than an image provider, so nothing is cached by URL and a new text is a new drawing.

    Registered in the Ravving QML module as QrCode. Implicit size 360 x 360.
