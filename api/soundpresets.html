    Detailed Description

    The file is Turtle, with pset:Preset entries each listing its port values (lv2:port [ lv2:symbol "cutoff" ; pset:value 0.42 ]). TAL-NoiseMaker ships 256 of them: DISTRHO-Ports' JUCE wrapper writes the port values next to the JUCE state, so a host can load one by setting its ports. TAL's names start with their kind and end with their author ("PD Juno Pad TAL"): the category is read from the prefix, the name keeps the rest, and the title also drops the author ("Juno Pad"). Reentrant.
