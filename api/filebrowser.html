    Detailed Description

    The kinds, in order (key in parentheses): projects (projects), templates (templates), presets (presets: the user's pattern presets and saved sounds, through PresetExchange, each written as one JSON file for sending), samples (samples), sampler takes (takes), input takes kept as played (liveTakes), master recordings (recordings), exported tracks (tracks) and bundles (bundles), soundfonts (soundfonts), MIDI files (midi), videos (videos), and files received over Bluetooth (received). Labels are translated again on a language change. GUI thread only.

    Property Documentation

    [read-only] kinds : QVariantList

    This property holds the kinds, as maps with key, label, about, usbKind (the stick folder a file of this kind is copied to, RemovableDrives::copyFiles()) and count.

    [invokable] QVariantList FileBrowser::entries(const QString &kind) const

    Returns the entries of kind, newest first, as maps with kind, name, detail, path, bytes, modified, and id (a preset's) or folder (a sample's subfolder).

    Note: This function can be invoked via the meta-object system and from QML. See Q_INVOKABLE.

    [invokable] QString FileBrowser::presetFile(const QString &id) const

    Writes the preset id out as a JSON file (under the cache's share/) for sending and returns its path; empty when there is no such preset.

    Note: This function can be invoked via the meta-object system and from QML. See Q_INVOKABLE.

    [invokable] void FileBrowser::refresh()

    Counts the kinds again (a file came or went).

    Note: This function can be invoked via the meta-object system and from QML. See Q_INVOKABLE.

    [invokable] bool FileBrowser::remove(const QVariantMap &entry)

    Deletes entry (as entries() gave it) through its owner (Projects, the preset library, the machine, Templates) or as a file. Returns false when it could not be deleted.

    Note: This function can be invoked via the meta-object system and from QML. See Q_INVOKABLE.
