    Detailed Description

    Each machine kind has one (drum-presets.json, bass-presets.json...); the drum machines share theirs, published to QML as studio.drumPresets. The machines read charts from it and save into it.

    A preset is a chart: one string per row, one character per step, 16 characters per bar, so a 32-character row is a two-bar preset. For the drums a row is a role (KICK to PERC; "x" a hit, "X" an accented hit), so every preset plays on every kit; the other machines define their own rows (Machine subclasses).

    A preset may also keep the sound it was made with, under sound beside its chart: a subset of Machine::soundState() (soundSource, soundPreset, sound, sourceSound; a drum machine's kit). A user preset keeps the parts of the machine's sound that are set (setParts()); a factory one may name only its source or kit. Loading a preset with its sound restores the parts it names (Machine::applySoundParts()); a preset without one is a pattern only. GUI thread only.

    Member Function Documentation

    PresetLibrary::PresetLibrary(const QString &factoryFile, const QString &userFile, QObject *parent = nullptr)

    Reads the factory presets from factoryFile (such as data/drum-presets.json) and the user's from userFile, with the given parent.

    QString PresetLibrary::addUserPreset(const QVariantMap &chart, const QString &name = QString(), const QVariantMap &sound = {})

    Saves chart as a new user preset called name (made unique against the factory's and the user's) or, without one, nextUserName(), keeping sound with it (none when empty). Returns the name it got.

    [static] int PresetLibrary::barsOf(const QVariantMap &chart)

    Returns the length in bars of chart: its longest row, rounded up to whole bars, at least 1.

    QVariantMap PresetLibrary::chart(const QString &name) const

    Returns the chart of the preset called name (row to steps); an empty map when there is none.

    bool PresetLibrary::contains(const QString &name) const

    Returns whether a preset called name exists, factory or user.

    [static] QVariantMap PresetLibrary::entryOf(const QVariantMap &chart, const QString &name, const QVariantMap &sound)

    Returns a preset entry as the library keeps one: chart called name, with sound when it is not empty (a preset file written elsewhere, such as on a USB stick, holds the same).

    QString PresetLibrary::fileName() const

    Returns the library's file name (bass-presets.json): what a shared preset says it belongs to.

    [static] QVariantMap PresetLibrary::fitChart(const QVariantMap &chart, int bars)

    Returns chart laid over bars bars instead of its own length (a preset loaded without its bars): every row repeats from its start to fill them (a shorter pattern loops) or is cut at their end; a row of steps by position (the chords' VOICINGS) follows its steps the same way.

    [static] bool PresetLibrary::hasMods(const QVariantMap &sound)

    Returns whether sound keeps sound-control values: the own engine's (sound), the soundfonts' (sourceSound) or a synth source's (sourceSounds).

    QString PresetLibrary::importUserPreset(const QVariantMap &preset)

    Imports preset, made elsewhere (such as on a USB stick), under its own name made unique against the factory's and the user's. Returns that name, or an empty string for an entry without a chart.

    QString PresetLibrary::nextUserName() const

    Returns the default name of a new user preset: the factory file's userName and the next free number ("My Beat 3", "My Progression 4"...).

    [invokable] void PresetLibrary::removeUserPreset(const QString &name)

    Deletes the user preset name; factory presets cannot be deleted.

    Note: This function can be invoked via the meta-object system and from QML. See Q_INVOKABLE.

    [static] QVariantMap PresetLibrary::setParts(const QVariantMap &sound)

    Returns sound (Machine::soundState()) with only the parts that are set: no factory sound when none is loaded, no sound-control set left at its defaults. A preset keeps this, so loading it leaves alone what it does not name.

    QVariantMap PresetLibrary::sound(const QString &name) const

    Returns the sound the preset called name keeps (a subset of Machine::soundState()); an empty map when it keeps none.

    [static] QVariantMap PresetLibrary::soundFields(const QVariantMap &preset)

    Returns a summary of preset's sound: a map with sound (soundNameOf()), soundKit (its kit's path, empty for none) and soundMods (whether it keeps sound-control values: hasMods()).

    [static] QString PresetLibrary::soundNameOf(const QVariantMap &preset)

    Returns the display name of preset's sound: its kit's name, its factory sound, else its source ("SOUND" when it names none of them); empty without a sound.

    [static] QVariantMap PresetLibrary::soundOf(const QVariantMap &preset)

    Returns the sound the preset entry preset (a map with name, chart, sound...) keeps; an empty map when none.

    [static] QVariantMap PresetLibrary::soundParts(const QVariantMap &sound, bool withSound, bool withMods)

    Returns the parts of sound to restore: the source or kit and the factory sound with withSound, the sound-control values with withMods; an empty map with neither.

    QVariantList PresetLibrary::userPresets() const

    Returns the user's own presets as stored (maps with name, chart...), for export.
