    Detailed Description

    In: a channel strip's fader is pitch bend on its own channel (1 to 8, 14 bits); its V-Pot is CC 16 + the strip on channel 1, a relative change (RelativeEncoder::Mode::SignMagnitude); its buttons are notes on channel 1: record arm 0–7, solo 8–15, mute 16–23, select 24–31, V-Pot press 32–39, fader touch 104–111. The transport (rewind 91 … record 95) and the cursor keys (96–99) are notes too, left to MidiInput's learned keys.

    Out: a button's light is a note-on with velocity 0 (off), 1 (flashing) or 127 (on) on the button's own note, channel 1; a fader's position is pitch bend on its channel, as the fader sends it. A surface without motors shows from that whether the fader agrees with the host.

    Function Documentation

    MackieControl::Event MackieControl::decode(int size, quint8 status, quint8 data1, quint8 data2)

    Returns what the message of size bytes status data1 data2 from the surface is: a fader, a V-Pot, a strip's button, or Other (anything else, for the learned keys).

    QByteArray MackieControl::fader(int strip, int position)

    Returns the pitch bend that tells strip strip's fader (0 to 7) the host's position (14 bits, clamped).

    int MackieControl::faderFromLevel(qreal level)

    Returns the fader position for level (0 to 1, as the MIXER's faders have it): the bottom for silence, the top (FaderTop) for the loudest, in proportion between.

    qreal MackieControl::levelFromFader(int position)

    Returns the level (0 to 1) for the fader position: faderFromLevel() the other way, clamped, so a 7-bit surface's top (FaderTop) is all the way.

    QByteArray MackieControl::light(int note, MackieControl::Light light)

    Returns the note-on that sets the light of the button on note to light.
