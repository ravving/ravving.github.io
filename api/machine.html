    Detailed Description

    Subclasses (DrumMachine, MonoMachine, ChordMachine, SamplerMachine, PadSamplerMachine) define what a step holds and how it sounds through the protected virtual functions declared in machine.h (onAttached(), refresh(), revoice(), clearOwnSteps(), applyChart(), chart(), restoreContent(), placeHit(), liveNotes(), liveVelocity(), sectionHasNotes()). This class provides the rest:

    • the track: level (its gain handler), pan and effects (TrackEffects), mute, pause, and the kick cut (setKickMode());
    • the pattern: length in bars, the viewed bar, the playhead, the step-entry cursor, the bar loop, once, and the track's two clips that alternate on section changes (attachSpare(), cueSectionContent());
    • the sound: the sources it can play through (its own engine, soundfont instruments, other engines), the engine's factory sounds, its sound controls (SoundControls) and the user's saved sounds;
    • pattern presets from a PresetLibrary, the loaded one marked edited after any change;
    • live playing: playLive() and stopLive() sound a key at once, recordLive() writes it at the step nearest the transport, writeAtCursor() at the cursor. A key is whatever the subclass plays: a drum row, a MIDI note, a chord degree;
    • automation: control moves recorded into the pattern per step and played back;
    • undo: the pattern takes part in the project's History as a HistoryParticipant.

    The project file keeps state() for each machine. Without libzynthbox (a desktop run) the same API works on the subclass's own storage. GUI thread only.

    Member Function Documentation

    Machine::Machine(const QVariantMap &config, const QVariantMap &state, PresetLibrary *presets, GlobalEffects *globalEffects, QObject *parent = nullptr)

    Constructs a machine from config, its object in kits.json (key, track, zynthianChannel, engine, the optional sound, sources, soundPresets and defaultPreset...), and state, what the project saved for it (state(); empty for a fresh project). presets is its preset library and globalEffects the studio's send effects, which its TrackEffects feed. parent is the QObject parent. The subclass calls restoreContent() from its own constructor.

    QVariantMap Machine::activeExpressions() const

    Returns the live expressions of the source playing, as a map of name to a map with symbol and max.

    [override virtual] void Machine::applyHistoryState(const QVariantMap &state)

    Restores the pattern part state, keeping the sound and view state.

    void Machine::applyPreset(const QVariantMap &chart, const QString &name, const QVariantMap &sound = {}, bool withBars = true)

    Replaces the pattern with a preset's chart under the name name, after restoring the parts of sound (applySoundParts(); empty: the sound stays), in one history step. With withBars the chart's length is taken too; otherwise it is fitted to the machine's bars.

    void Machine::applySectionContent(const QVariantMap &content)

    Applies a section's content: the pattern becomes it, the sound stays, and the history is cleared. An empty map (no content for this machine yet) empties the pattern.

    [virtual] void Machine::applySoundParts(const QVariantMap &parts)

    Restores only the parts parts has (any subset of soundState()'s keys, such as a pattern preset's sound); the other parts stay. An unknown source (or a drum machine's unknown kit) leaves that part unchanged and logs a line.

    void Machine::applySoundState(const QVariantMap &state)

    Restores the whole sound state (see soundState()); a part it lacks goes to its default. A source change restarts the engine; the sound-control values reach it once it is running.

    void Machine::attach(QObject *pattern, SketchpadTrack *track, QObject *playGridManager, QObject *syncTimer, QObject *gainHandler)

    Connects the machine to libzynthbox: pattern (the PatternModel of this machine's track, clip a) holds the steps from now on, track routes it, playGridManager makes notes, syncTimer plays live notes and gainHandler is the track's level. Calls the subclass's onAttached() and clears the history.

    void Machine::attachSpare(QObject *pattern)

    Gives the machine its track's other clip, pattern (clip b), which alternates with the playing clip on section changes (cueSectionContent()). The clip is cleared.

    [invokable] bool Machine::barHasNotes(int bar) const

    Returns whether bar (from 0) holds any note in the pattern that plays, so removing it would lose something (the pattern toolbar's − asks again then).

    void Machine::cueSectionContent(const QVariantMap &content, int span, bool intoSpare)

    Takes a section's content, span bars long, while the transport plays. With intoSpare the content is written into the clip that is not playing and the two clips swap, so nothing in the playing clip drops or doubles; otherwise it is written into the clip already waiting. The machine's state changes at once; the studio switches the clips, and the pause, on the next bar. Turns loopBar off.

    [invokable] void Machine::loadSoundPreset(const QString &name)

    Loads the factory sound name into the engine: all its ports except those the machine keeps (kits.json soundPresets.keep); sound adopts the new values. It is saved with the project and sent again whenever the engine restarts (soundPresetControls()). An empty name restores the machine's own sound: the plugin's start-up sound (soundPresets.base), the engine's controls from kits.json, and sound at its defaults.

    Note: This function can be invoked via the meta-object system and from QML. See Q_INVOKABLE.
