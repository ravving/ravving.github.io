    Detailed Description

    start() initialises libzyncoder first (init_zynlib(), then the Z2's output amplifier raised to its maximum, which init_zynlib() leaves at 0), then opens libravving.so, takes its engine (libravving/engine.h, through the library's one entry point libravving_engine) and starts it with its QML types under LibRavving. It then starts HardwareSwitches (the buttons, through the router's CUIA queue) and HardwareKnobs, and forwards every CUIA command the router reports as cuiaEvent() and the knobs as knobTurned() and knobMoved().

    Both libraries are opened at run time with RTLD_LOCAL, so ravving builds and runs (with no sound) where they are not installed, and the JUCE symbols libravving carries cannot interpose on libraries loaded later. libzynthbox is never opened: it stays zynthbox-qml's.

    GUI thread only.

    int ZynthboxBridge::outputLevelMax() const

    Returns the number of steps above silence of the Z2's output amplifier (LM4811, the level of the output jacks); 0 without libzyncoder.

    void ZynthboxBridge::setOutputLevel(int step) const

    Sets the output amplifier to step, clamped to 0 (silent) .. outputLevelMax(). Does nothing without libzyncoder.

    bool ZynthboxBridge::start(QQmlEngine *engine)

    Loads and initialises libzyncoder and libravving and registers libravving's QML types in engine; see the class description. Returns false when libravving or its entry point are missing or its engine does not start: status then says why, and a "No sound engine" issue is reported. A missing libzyncoder is only logged (no device keys or knobs).
