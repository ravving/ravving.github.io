    Detailed Description

    start() brings libzynthbox up the way zynthbox-qml's bootstrap does: libzyncoder first (init_zynlib(), then the Z2's output amplifier raised to its maximum, which init_zynlib() leaves at 0), then libzynthbox's Plugin::initialize() and its QML types under io.zynthbox.components. It then starts HardwareSwitches (the buttons, through MidiRouter's CUIA queue) and HardwareKnobs, and forwards every MidiRouter::cuiaEvent as cuiaEvent() and the knobs as knobTurned() and knobMoved().

    libzynthbox installs no headers (and they pull in all of JUCE), so both libraries are opened at run time with RTLD_LOCAL and only a few entry points are resolved by their mangled symbols: Plugin's three, ClipAudioSource's constructor (createClip()), SyncTimer::setMetronomeTicks() and SyncTimer's JACK-frame lookups. Everything else goes through Qt's meta-object system (singleton(), create()). RTLD_GLOBAL is avoided because libzynthbox's bundled JUCE and tracktion symbols would interpose on libraries loaded later.

    All members run on the GUI thread.

    Constructs the bridge, not started, with the given parent.

    QObject *ZynthboxBridge::create(const QString &type, QObject *parent) const

    Returns a new object of libzynthbox's creatable QML type type (such as ProcessWrapper), with C++ ownership, parented to parent; nullptr when libzynthbox is not available or the type cannot be created.

    QObject *ZynthboxBridge::createClip(const QString &file, int track, int slot, int row, bool polyphonic) const

    Returns a new ClipAudioSource (a sample SamplerSynth plays) for file on sketchpad track's sample slot slot (0 to 4) of row (0 or 1), registered for polyphonic playback when polyphonic is true (a sampler slot) and not otherwise (the metronome's clips, track -1). ClipAudioSource has no meta-object factory, so it is built through its exported constructor in a zeroed 256-byte block. The caller owns it and unloads it with retireClip(). Returns nullptr without libzynthbox, for a missing file, or for a format SamplerSynth cannot decode (only WAV, AIFF, FLAC and Ogg are accepted: a file it cannot read would crash the audio thread when a voice plays it).

    [signal] void ZynthboxBridge::cuiaEvent(const QString &cuia)

    Emitted for every CUIA command cuia MidiRouter reports, from any source (the device's buttons, MIDI-mapped controllers).

    quint64 ZynthboxBridge::currentFrame() const

    Returns the JACK frame at the end of the most recent process cycle (SyncTimer::jackPlayheadFrames): "now" on the recording clock. 0 without libzynthbox.

    [signal] void ZynthboxBridge::knobMoved(int knob, qreal value)

    Emitted when the device's fixed pot knob (0 to 2) settled at value, 0..1.

    [signal] void ZynthboxBridge::knobTurned(int knob, int delta)

    Emitted when the device's endless knob (0 to 3) turned by delta detents.

    int ZynthboxBridge::outputLevelMax() const

    Returns the number of steps above silence of the Z2's output amplifier (LM4811, the level of the output jacks); 0 without libzyncoder.

    quint64 ZynthboxBridge::playbackStartFrame() const

    Returns the JACK frame the transport last started playing at (SyncTimer::jackPlayheadAtStart, the clock of AudioLevels' recording frames): where the first beat of a recording lands. 0 without libzynthbox or before the first start.

    void ZynthboxBridge::retireClip(QObject *clip) const

    Unloads clip, made by createClip(), without crashing the audio thread: its voices are told to stop, and the object is deleted once it has reported itself silent for 500 ms (after at least 1 s), or after 60 s regardless. Deleting a ClipAudioSource while SamplerSynth still plays it crashes the audio thread (libzynthbox bug report 15). Does nothing for a null clip.

    bool ZynthboxBridge::setMetronomeSounds(const QString &tickFile, const QString &tockFile)

    Gives SyncTimer its metronome sounds: tickFile on each bar's first beat, tockFile on the other beats, as zynthbox-qml does; without them SyncTimer's metronome and count-in are silent. The two clips live as long as the process. Returns false when a file or a symbol is missing.

    void ZynthboxBridge::setOutputLevel(int step) const

    Sets the output amplifier to step, clamped to 0 (silent) .. outputLevelMax(). Does nothing without libzyncoder.

    QObject *ZynthboxBridge::singleton(const QString &name) const

    Returns libzynthbox's QML singleton name (SyncTimer, PlayGridManager, Plugin, AudioLevels, JackConnectionHandler, MidiRouter...), or nullptr before start().

    bool ZynthboxBridge::start(QQmlEngine *engine)

    Loads and initialises libzyncoder and libzynthbox and registers libzynthbox's QML types in engine; see the class description. Returns false when libzynthbox, its entry points or its MidiRouter are missing: status then says why, and a "No sound engine" issue is reported. A missing libzyncoder is only logged (no device keys or knobs).

    bool ZynthboxBridge::timerTickAtFrame(quint64 frame, quint64 *tick, quint64 *remainder) const

    Finds where the transport was at JACK frame frame (on the jack_frame_time() clock): stores in tick the SyncTimer tick that played at or before it, counted from the playback start, and in remainder how many frames after that tick frame is. Sample accurate, since SyncTimer keeps the frame each tick played at. Returns false while the transport is stopped or without libzynthbox; the outputs are then untouched.
