    Detailed Description

    Knobs 0 to 2 are the small knobs, knob 3 the big one. Every 20 ms each knob whose value changed is read through libzyncoder's zynpot functions:

    • an endless encoder (every knob on the older kits, the big knob on all of them) emits turned() with the detents moved, and is recentred near the ends of its range so it never runs out;
    • a fixed-end pot (the three small knobs of the Z2_V5B kit) emits moved() with its position 0..1. Readings within 2 raw steps of the recent average are ignored as jitter, and the last 16 raw steps at either end snap to the end, so a control's minimum and maximum are always reached.

    The kit comes from ZYNTHIAN_WIRING_LAYOUT; Z2_V5 and Z2_V5B mount the small knobs reversed, which an inverted range compensates for. MidiRouter's CUIA queue carries no value, so the knobs are signalled directly rather than as CUIA commands.

    Member Function Documentation

    [explicit] HardwareKnobs::HardwareKnobs(void *zyncoder, QObject *parent = nullptr)

    Looks up the zynpot functions in zyncoder, the dlopen() handle of an initialised libzyncoder (init_zynlib called), sets up the four knobs' ranges and starts polling. When the functions are missing (a desktop) it logs a warning, reports a "No device knobs" issue (Issues) and does not poll. parent is the QObject parent.

    bool HardwareKnobs::isAbsolute(int knob) const

    Returns whether knob (0 to 3) is a fixed-end pot rather than an endless encoder; false for an index out of range.

    bool HardwareKnobs::isPolling() const

    Returns whether the zynpot functions were found and polling runs.

    [signal] void HardwareKnobs::moved(int knob, qreal value)

    Emitted when the fixed pot knob (0 to 2) settled at value, 0.0 (fully left) to 1.0 (fully right).

    [signal] void HardwareKnobs::turned(int knob, int delta)

    Emitted when the endless knob (0 to 3) moved by delta detents; positive is clockwise.
