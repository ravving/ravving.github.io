    Detailed Description

    Each step holds at most one voicing; a run of steps holding the same voicing is one chord held for the whole run, so a bar of "I" is one long chord and "I . I ." two short ones.

    A voicing is either a diatonic chord, a scale degree (I to VII) stacked in thirds from the scale with three or four notes as the chord set defines per degree (Classic, Triads, Sevenths), or a custom set of notes (scale degrees, or semitones from the chord base for a note outside the key). Voicings are stored as scale degrees from kits.json's baseNote (48, C3, by default) plus the key's root, shifted by octave, so a change of key (root, scale), chord set or octave revoices every chord at once.

    Three interfaces edit the same steps:

    • chords: whole chords per step (setChord());
    • notes: single notes per step (noteSets, toggleNote()); changing a step's notes makes its voicing custom;
    • slots: four chord slots (up to eight) played in order, each lasting 1, 2, 4 or 8 bars; editing a slot rebuilds the steps from all of them. A slot is filled by arming it (armedSlot) and playing a chord key; the next slot is then armed.

    Presets (chord-presets.json) are charts: CHORDS, one character per step, "1" to "7" a degree, "x" a custom voicing (its degrees in VOICINGS, by step) and "." nothing. A live key below 1000 is a chord degree (0 to 6) and plays the whole chord; from 1000 it is a single scale degree (noteKey()); from 100000 it is a chromatic MIDI note (100000 + note), played as is. A MIDI keyboard note plays the chord on its scale degree (degreeForNote()). Machine::OnlyKick silences the machine.

    [invokable] QVariantList ChordMachine::shiftChords(const QVariantList &picked, int steps)

    Moves the picked chords (a list of positions, a held chord as one) steps steps later (positive) or earlier. A step holds one chord, so a chord landing on another replaces it; a chord that would leave the pattern stays. Returns the picks as they are after the move.

    Note: This function can be invoked via the meta-object system and from QML. See Q_INVOKABLE.

    [invokable] QVariantList ChordMachine::shiftNotes(const QVariantList &picked, int steps)

    Moves the picked notes (a list of [position, note] pairs, across the held chord each is in) steps steps later or earlier; a note joins the notes already on the step it lands on, and a note that would leave the pattern stays. Returns the picks.

    Note: This function can be invoked via the meta-object system and from QML. See Q_INVOKABLE.
