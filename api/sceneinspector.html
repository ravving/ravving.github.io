    SceneInspector Namespace

    Logs what the running scene holds, for the remote-control fifo's debugging commands. More...

    Header: #include <sceneinspector.h>

    Detailed Description

    Both functions walk the window's root objects and content item depth first, through QObject children (animations, timers) and child items (a Repeater's delegates are visual children only), and write a line per match to the log (ravving: item ..., ravving: running ...). tools/device.sh items and tools/device.sh animations call them through CuiaFifo.

    Function Documentation

    int SceneInspector::logAnimations(QQuickWindow *window)

    Logs every running animation of window (the outermost of a group) and every repeating Timer, with the item it belongs to, whether that item is visible, its QML file and its position. A running animation makes the window draw every frame, even on a hidden item. Returns how many were found; 0 when window is null.

    int SceneInspector::logItems(QQuickWindow *window, const QString &pattern)

    Logs every item of window whose QML type name contains pattern (such as DialFace): its position and size in the window, implicit size, visibility and parent type. Returns how many matched; 0 when window is null.
