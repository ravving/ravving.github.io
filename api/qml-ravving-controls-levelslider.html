    Detailed Description

    The pill fills from the left as the value grows, its glyph sits at the start and the value at the end. A drag anywhere moves the value by how far the finger travels (no jump to where it lands), so a small adjustment is easy on a touch screen.

    It is a KnobGroup target like Knob (value, from, to, knobStep, fineStep, knobBadge, knobPending): a device knob can drive it, its badge at the end.
