    Detailed Description

    The machines' engines are never touched (a source change restarts one, and the music would drop out). A soundfont source or a drum kit is rendered once, offline, by FluidSynth into a WAV in the cache (previews/, by its soundfont, bank, program and phrase), at the lowest priority on one core and only while the transport is stopped; the WAV then plays as a sample preview does (Studio::previewSample(): a one-shot clip straight to the master). A cached preview plays at once, the music running or not.

    The phrases are in C: a chord for the chords, a line for the lead, root, fifth and octave for the bass, a bar of kick, snare and hat (on the kit's own keys) for a drum kit.

    [static] QString SoundPreviews::cacheName(const QString &soundfont, int bank, int program, const QString &kind)

    Returns the cache file of the preview of soundfont's bank and program played as a kind machine's phrase.

    [invokable] bool SoundPreviews::hold(const QString &machineKey, const QString &value)

    Starts the preview of value on machineKey's machine: a soundfont source's name (the chords, bass and lead) or a drum kit's path (a drum machine). Plays it at once when it is cached, else renders it first (only with the transport stopped). Returns false, with the reason in status, when the sound has no preview (a synth's own sounds) or cannot be rendered now.

    Note: This function can be invoked via the meta-object system and from QML. See Q_INVOKABLE.

    [static] QByteArray SoundPreviews::phrase(const QString &kind, const QList<int> &drumNotes = {})

    Returns a short phrase in C for a machine of kind (chords, bass, lead or drums) as a type-0 MIDI file at 120 BPM; a drum phrase plays drumNotes, the kit's KICK, SNARE and HAT keys.

    [invokable] void SoundPreviews::release()

    Stops the preview playing (a let-go hold), and drops the one being prepared from playing once it is ready (it is still cached).

    Note: This function can be invoked via the meta-object system and from QML. See Q_INVOKABLE.
