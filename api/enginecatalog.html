    Detailed Description

    data/kits.json names every engine as a Zynthbox has it. Another system (a desktop) may lack a plugin or a soundfont, so an engine may come with others to play in its place, in order, as or beside it:

    
 {"name": "TAL NoiseMaker",
  "engine": {"type": "jalv", "uri": "http://kunz.corrupt.ch/products/tal-noisemaker"},
  "or": [{"name": "Polysynth", "type": "fluidsynth",
          "soundfont": "/zynthian/zynthian-data/soundfonts/SF2 Instruments/FluidR3Mono_GM.sf3",
          "bank": 0, "program": 90}]}

    resolved() gives a machine's config with the first engine that can run in the place of each (chosen()), before EngineProfiles reads it: the MODS are those of the engine that plays. An or entry is an engine object that may bring the name its sound is listed by. Where the first choice runs (a Zynthbox) nothing changes.

    An engine can run when lacking() finds nothing missing: its program (fluidsynth, jalv), its plugin (a jalv engine's uri among the installed ones) and its soundfont (where Paths::relocated() finds it). The installed plugins are what lv2ls lists, kept in Paths::cache()/lv2-plugins.json until a folder of pluginFolders() or a bundle in one changes; without lv2ls, and on the Zynthbox (which ships them all), the plugins are unknown and every one is taken as installed. shared() is the one the app asks; a test makes its own and says what is installed (setPrograms(), setPlugins()). GUI thread only.

    Member Function Documentation

    [static] QString EngineCatalog::bundleFile(const QString &path)

    Returns where the file path of an LV2 bundle (/usr/local/lib/lv2/X.lv2/presets.ttl) is on this system: the path itself when it exists, else the same file of the bundle of that name in one of pluginFolders(), else the path unchanged.

    QVariantMap EngineCatalog::chosen(const QVariantMap &engine, const QVariantList &alternatives) const

    Returns the one to play of engine and its alternatives (the or beside it): the first that lacks nothing (lacking()), as it is listed (an alternative with its name); engine itself when none can run, so what is missing is the first choice.

    void EngineCatalog::forgetPlugins()

    Forgets the installed plugins: they are read again when next asked (one was installed).

    bool EngineCatalog::hasPlugin(const QString &uri) const

    Returns whether the LV2 plugin uri is installed; true when the plugins are unknown (knowsPlugins()), so a system without lv2ls starts every engine kits.json names.

    bool EngineCatalog::hasProgram(const QString &program) const

    Returns whether program is on PATH (or among those setPrograms() gave).

    bool EngineCatalog::knowsPlugins() const

    Returns whether the installed plugins could be listed; without that hasPlugin() answers true for every plugin.

    QString EngineCatalog::lacking(const QVariantMap &engine) const

    Returns what this system lacks to run engine (a kits.json engine object): the program's name, the plugin's URI or the soundfont's path, the first one missing; empty when it can run, and for an object without a type (a machine with no engine of its own) or of a type unknown here.

    [static] QStringList EngineCatalog::parsePluginList(const QByteArray &output)

    Returns the plugin URIs in output, what lv2ls prints: one URI a line.

    [static] QStringList EngineCatalog::pluginFolders()

    Returns the folders LV2 plugins are installed in, whether they exist or not: those of LV2_PATH when it is set, else the usual ones (~/.lv2, /usr/local/lib/lv2, /usr/lib/lv2 and their lib64 and multiarch kin).

    QVariantMap EngineCatalog::resolved(QVariantMap machine) const

    Returns the kits.json config machine as this system plays it: its own engine and each of its sources' the one chosen() picks, the or lists gone. An alternative in the place of the machine's own engine brings its name as the sourceName and drops the soundPresets (the first choice's factory sounds, otherwise read from where this system has the plugin's bundle: bundleFile()); one in the place of a source's renames the source when it has a name. A source none of whose engines can run is left out: its sound cannot be picked. The machine's own engine stays even when it cannot run, and SoundEngine::createEngine() reports it.

    void EngineCatalog::setPlugins(const QStringList &uris)

    Makes uris the LV2 plugins installed, in place of asking lv2ls.

    void EngineCatalog::setPrograms(const QStringList &programs)

    Makes programs the only programs this catalog finds, in place of looking on PATH.

    [static] EngineCatalog &EngineCatalog::shared()

    Returns the catalog of this system, read when first asked.
