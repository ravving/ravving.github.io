    ToolStrip QML Type

    A row of a page's buttons on its grouping strip. More...

    Detailed Description

    The darker rounded band the pattern toolbars, the SONG page's rows and the RECORDER's and the player's groups sit on, a little darker on a dark finish than on a light one. What is put inside (content) is laid out in a row, its buttons at the standard height (Theme.controlHeight, or buttonHeight).

    
 ToolStrip { finish: Rave.machines.bass; StripButton { text: "CLEAR" } … }

    finish is the screen's (only its dark is read); none counts as a dark one.

    Property Documentation

    buttonHeight : real

    The height its buttons stand at (the strip is a little taller).

    content : list<QtObject> [default]

    The row (its spacing, its margins).

    finish : var

    The screen's finish: only its dark is read (none counts as a dark one). With none given, the skin it sits in.

    flat : bool

    No band of its own: the group sits on what is under it, as the dashboard header's deck groups sit on the header (a full page's deck, in its PageHeader).

    row : RowLayout [read-only]

    The row (its spacing, its margins).
