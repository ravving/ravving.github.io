    Glyph QML Type

    A small line icon drawn in vector (no icon theme or emoji font needed on the device), for the control center and the mixer. More...

    Import Statement: import Ravving.Controls 1.0

    Detailed Description

    "wifi", "bluetooth", "sun", "speaker", "power", "mixer", "midi", "cpu", "lock", "eye", "refresh", "music", "export", "settings", "alert", "check", "video", "computer", "folder". Drawn on a 24-unit grid scaled to size, in color.

    Property Documentation
