    KindList QML Type

    The kinds down a browsing dialog's left (FILES, USB, GET MORE): a row per kind with its name and how many it holds, the one shown on a tint with the accent's edge. More...

    Import Statement: import Ravving.Controls 1.0

    Detailed Description

    model lists the kinds (maps with key, label and count, as the browsers' backends publish them), current the key shown; a tap says picked. The column keeps its width (240 px) beside the dialog's list; what is put inside it (a line on the list's age, what waits) goes under the kinds, at the foot.
