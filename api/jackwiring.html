    JackWiring Class

    Keeps the JACK graph wired for ravving's tracks, with the topology libzynthbox's tracks expect (the one zynthbox-qml's autoconnect produces for a synth on a sketchpad track). More...

    Detailed Description

    
 ZLRouter:Zynthian-Channel{z}  ->  engine MIDI in
 engine out  ->  SynthPassthrough:Synth{z+1}  ->  TrackPassthrough:Channel{t+1}-lane1
             ->  AudioLevels:Channel{t+1}  ->  GlobalPlayback  ->  system:playback

    Here z is the Zynthian channel and t the sketchpad track. PipeWire also links every new engine straight to the speakers; those links are removed, so all sound goes through the track (level, mute, effects).

    A synth can have an insert (TrackEffects' DRIVE): while active it sits between the engine and its SynthPassthrough, otherwise the engine connects straight to it. The master can run through inserts before the speakers (setMasterInserts(), LiveFx::masterInserts()), and the device input through its own chain (setInputChain()).

    The wiring is declarative: every wanted and unwanted port pair is kept, and each change requests them all through libzynthbox's JackConnectionHandler, retried until every port exists, since engines and passthrough ports appear a moment after they are requested (the startup mark wired is set once everything is connected). GUI thread only.

    Mixes the outputs of the send effect into the master, rewired whenever it restarts.

    Routes SamplerSynth's global outputs to the master, where clips played on no track sound (the metronome's ticks).

    void JackWiring::addSends(int track, const QStringList &fx1Inputs, const QStringList &fx2Inputs)

    Sends sketchpad track's effect sends (its lane's wet outputs 1 and 2) into the reverb's inputs fx1Inputs and the delay's inputs fx2Inputs.

    void JackWiring::addSynth(SoundEngine *engine, int zynthianChannel, int track, AudioInsert *insert = nullptr)

    Routes engine as the synth on Zynthian channel zynthianChannel of sketchpad track, with insert (or none) ready to go between it and the track (setInsertActive()). The track's lane is wired to the master too.

    void JackWiring::addTrackLane(int track)

    Wires sketchpad track's lane on the way to the master (lane, AudioLevels, GlobalPlayback); addSynth() does it for a synth's track.

    QStringList JackWiring::masterOutputPorts() const

    Returns the master's last two output ports, after its inserts: what feeds the speakers.

    void JackWiring::removeSynth(SoundEngine *engine)

    Forgets the connections of engine, which is being replaced by another on the same track.

    void JackWiring::setCaptureMeter(const QStringList &inputs)

    Feeds AudioLevels' capture meter (captureA and captureB) from the device's real inputs; libzynthbox connects it to the first system: outputs, which under PipeWire are the speakers' monitor.

    void JackWiring::setInputChain(int track, const QList<QStringList> &sources, const QList<AudioInsert *> &inserts, bool monitor, bool record, const QStringList &listeners = {})

    Wires the device input's path, replacing the one wired before: sources (the capture ports feeding the left side, then the right; several on a side are summed by JACK) through inserts in order (the input effects), and from there, with monitor, into sketchpad track's lane (its level is the monitor's; addTrackLane() wires it to the master) and, with record, into AudioLevels' port recorder (its meter and takes). A mono plugin takes both sides summed and feeds both sides of what follows. listeners (left, right) are fed by the chain's end too (AudioTap's mic inputs). Empty sources wire nothing.

    void JackWiring::setInsertActive(AudioInsert *insert, bool active)

    Puts insert into its synth's signal path (engine, insert, track) when active is true, or takes it out (engine, track).

    void JackWiring::setMasterInserts(const QList<AudioInsert *> &inserts)

    Runs the master through inserts, in order, before the speakers, instead of GlobalPlayback straight to them; the meter keeps reading GlobalPlayback.

    void JackWiring::setSampleOutputs(int track, const QList<int> &samples, int laneTrack = -1)

    Wires the sampler's loaded slots on track, SamplerSynth's sample ports samples (1 to 10), into a lane, replacing the ones wired before: the track's own lane, or with laneTrack 0 or more that track's (PadSamplerMachine's second track plays through the first's lane, so one level and one set of effects cover all its pads). SamplerSynth creates a slot's ports only while a sample is in it.

    void JackWiring::setSpeakers(const QStringList &ports)

    Uses ports (left, right; HardwarePorts::playbackOf()) for the speakers, in place of system:playback_1 and system:playback_2 wherever the master and the engines are wired to them; an empty list leaves them as they are.

    void JackWiring::setSpeakersEnabled(bool enabled)

    Keeps the master's links to the speakers when enabled is true, or drops them while AudioOutputs routes the master elsewhere (its loopback links are made with pw-link: the loopback's input ports have no JACK names).

    QObject *JackWiring::trackLane(int track) const

    Returns the JackPassthrough a synth on sketchpad track plays through (its lane 1, where settings such as pan live), or nullptr.
