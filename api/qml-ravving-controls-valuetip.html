    ValueTip QML Type

    What the value bubble shows: the control being changed, its name and its value. More...

    Detailed Description

    A control shows its value by calling ValueTip.show(item, label, text, accent) on every change made by hand (a touch, a device knob); the one ValueBubble in the window draws it above item and lets it go a moment after the last change (hideDelay). Only one control shows at a time: the last one changed.

    Property Documentation

    accent : color

    The border's colour: the machine's accent.

    hideDelay : int

    How long the bubble stays after the last change, in ms.

    hideTimer : Timer

    The wait before the bubble goes (hideDelay), restarted by each show().

    label : string

    The control's name ("CUTOFF").

    shown : bool

    Whether the bubble is up.

    target : Item

    The control the bubble points at, null when none.

    text : string

    Its value as it reads ("71 %").

    Method Documentation

    hide()

    Takes the bubble down at once.

    show(item, label, text, accent)

    Shows text, named label, above item, in accent; again on every change.
