    Detailed Description

    Each preset is one JSON file under a stick's ravving/presets folder:

    
 <group>/patterns/<name>.json   {"ravving": "preset", "type": "pattern",
                                 "library": "bass-presets.json",
                                 "preset": {name, chart, sound (optional)...}}
 <machine>/sounds/<name>.json   {"ravving": "preset", "type": "sound",
                                 "machine": "chords", "sound": {name, state}}
 templates/<name>.json          {"ravving": "preset", "type": "template",
                                 "template": {name, bpm, swing, root, scale...}}
 skins/<key>.json               {"ravving": "preset", "type": "skin",
                                 "skin": {name, about, machines}}   (SkinFiles)

    where <group> is the library's name (drum for the drum machines' shared one, bass...). An imported preset keeps its name, made unique against what the device has. A preset is identified by an id: pattern::<library file>::<name>, sound::<machine>::<name> or template::templates::<name> or skin::skins::<key> (every skin set, shipped ones included; only the user's own can be removed). A plain object over the studio; GUI thread only.

    Member Function Documentation

    [explicit] PresetExchange::PresetExchange(Studio *studio)

    Constructs the exchange over the presets of studio's machines and templates.

    QVariantMap PresetExchange::describe(const QString &path) const

    Returns a summary of the preset file at path: a map with name, label and onDevice (a preset of its name is on the device); an empty map for a file that is not a ravving preset.

    QVariantList PresetExchange::devicePresets() const

    Returns the user's presets of every machine, and the templates, as maps with id, name, label (such as "BASS · PATTERN") and file (where it goes under ravving/presets).

    bool PresetExchange::loadStickPattern(const QString &path, const QString &machineKey, bool withSound = false, bool withMods = false, bool withBars = true) const

    Loads the stick's pattern preset at path into the machine machineKey (Machine::applyPreset()), with the source or kit it keeps when withSound is true, its sound-control values when withMods is true and its length when withBars is true. Returns false when the file is not a pattern of that machine's library.

    QString PresetExchange::patternLibrary(const QString &machineKey) const

    Returns the file of the pattern library the machine machineKey plays (bass-presets.json; the drum machines share drum-presets.json), or an empty string for an unknown machine or one without pattern presets.

    bool PresetExchange::remove(const QString &id) const

    Deletes the preset id from where it lives (the library, the machine's sounds, the templates). Returns false when there is no such preset.

    QVariantList PresetExchange::stickPatterns(const QString &folder, const QString &machineKey) const

    Returns the pattern presets in a stick's folder (its ravving/presets) for the machine machineKey, to play from there without importing them: maps with name, genre, sound, soundKit (PresetLibrary::soundFields()) and path, sorted by name.

    [static] QVariantList PresetExchange::stickTemplates(const QString &folder)

    Returns the project templates in a stick's folder (its ravving/presets), to start a project from there without importing them, as Templates::list() lists them.

    QString PresetExchange::take(const QString &path, QString *error) const

    Imports the preset file at path. Returns the name it got, or an empty string with error (when not null) saying why.

    QString PresetExchange::write(const QString &id, const QString &folder) const

    Writes the preset id under folder (a stick's ravving/presets). Returns the path written, or an empty string on failure.

    QString PresetExchange::writeStickPattern(const QString &machineKey, const QString &name, bool withSound, bool withMods, const QString &folder) const

    Writes the pattern on screen of the machine machineKey as a preset called name under folder (a stick's ravving/presets), where write() puts the device's, with its sound as Machine::saveAsPreset() keeps it (withSound, withMods), without storing it on the device. A name the stick already holds gets a number ("Name 2"). Returns the path written, or an empty string on failure.
