    FaderPickup Class

    A fader (or an absolute knob) with no motor, on a value it does not show: it takes the value over once it reaches it (within a window, or crossing it), so one left elsewhere does not jump the value; a value changed anywhere else lets go of it until it is reached again. The value it asked for coming back is not a change (asked()). With the pick-up off (setPickup()) it takes the value on any move instead: the fader always wins. More...

    Member Function Documentation

    void FaderPickup::asked(qreal value)

    The fader asked for value: when it comes back (valueChanged()), the fader keeps it.

    void FaderPickup::heard(qreal position)

    The fader was heard at position with no value to take (no instrument on its strip).

    bool FaderPickup::pickup() const

    Returns whether the fader waits to reach the value (setPickup()).

    See also setPickup().

    void FaderPickup::reset()

    Forgets the fader: where it was and what it held (a controller connecting again).

    void FaderPickup::setPickup(bool pickup)

    Has the fader wait to reach the value before it takes it (pickup on, the default), or take it on any move (off). Turning the pick-up on lets go of the value until it is reached.

    See also pickup().

    bool FaderPickup::take(qreal position, qreal target, qreal window)

    The fader moved to position; the value is at target, in the same units. Returns whether the fader holds the value now: it held it already, or it is within window of it, or it went past it since it was last heard; with the pick-up off, always.

    bool FaderPickup::valueChanged(qreal value)

    The value changed to value. Returns whether that let go of the fader: a change it did not ask for (from the screen, a project opened…). Its own coming back changes nothing.
