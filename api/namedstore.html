    Detailed Description

    Used for the pattern presets a PresetLibrary adds to its factory ones and the sounds a machine saves. Every entry is a map with a unique name; the rest is the owner's. Each change is written at once (the entries are few and small). A file that cannot be read is moved aside (<file>.unreadable-<date>) and reported as an issue, never written over. A plain value type; not thread-safe.
