    Functions through which components report issues to Diagnostics. More...

    Header: #include <diagnostics.h>
    • Issues is part of Device, network and files.

    Detailed Description

    The functions forward to the Diagnostics instance main() created; before it exists, report() prints the issue to the log instead. Callable from any thread.
