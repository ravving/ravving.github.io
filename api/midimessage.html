    MidiMessage Struct

    A short MIDI message from a controller as the ConnectionMultiplexer hands it on: the controller it is from (ConnectionRegistry::idOf()), the connection it came on, its bytes and when it came. More...

    Header: #include <connectionmultiplexer.h>

    Member Function Documentation

    int MidiMessage::channel() const

    Returns the channel, 1 to 16.

    int MidiMessage::packed() const

    Returns the three bytes packed into one number: the same message is the same number.

    quint8 MidiMessage::status() const

    Returns the status with no channel: 0x90 a note-on, 0x80 a note-off, 0xB0 a CC, 0xD0 pressure, 0xE0 pitch bend.
