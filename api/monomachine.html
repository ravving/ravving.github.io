    Detailed Description

    Each step holds at most one note, with two step flags:

    • accent: the note plays at the accent velocity (kits.json velocities; 127 by default) instead of the plain one (80 by default);
    • slide: the note lasts half a step longer, so it overlaps the next one, which a mono engine in legato mode glides into;

    and a length in steps (1 unless set). A note may also have its own velocity (1 to 127, overriding the plain or accent one; toggling the accent clears it) and a nudge (Machine's per-note timing offset); adjustNotes() sets the three. The line is the machine's own data (saved with it); the PatternModel is written from it, one subnote per note. A live key is a MIDI note (degreeNote() turns scale degrees into notes). Machine::OnlyKick silences it.

    The key (root and scale) places the presets, which are written in scale degrees from kits.json's baseNote plus the root: bass-presets.json and lead-presets.json chart NOTES "1" to "7" or ".", OCTAVE "+" or "-", ACCENT and SLIDE "x", and when needed HOLD "x" on the steps a long note lasts through and ALTER, the semitones a note outside the key sits above its degree. The key also places degreeNote() and randomize(). octave shifts degreeNote(), not the notes already written.

    The QML piano roll uses notes, accents, slides, lengths, holds, velocities, octave, setNote(), toggleAccent(), toggleSlide() and audition(), with Machine's playhead, cursor, bars and presets.

    Member Function Documentation

    MonoMachine::MonoMachine(const QVariantMap &config, const QVariantMap &state, PresetLibrary *presets, GlobalEffects *globalEffects, QObject *parent = nullptr)

    Constructs a mono machine from config (its kits.json object: baseNote, velocities and the engine) and the project's state, which also carries line (a list of [position, note, accent, slide, length] entries), root and scale: the key the line was written in, so restoring it snaps nothing. presets, globalEffects and parent are as for Machine.

    [invokable] void MonoMachine::adjustNotes(const QVariantList &picked, const QString &setting, int delta)

    Changes setting of the picked notes by delta: length by delta steps (1 to 64), velocity by 4 per unit (1 to 127), nudge by a 16th of a step per unit (at most half a step either way). An undoable edit.

    Note: This function can be invoked via the meta-object system and from QML. See Q_INVOKABLE.

    [invokable] QVariantList MonoMachine::moveNotes(const QVariantList &picked, int steps, bool chromatic)

    Moves the picked notes (a list of [position, note] pairs, absolute positions) steps notes of the key up or down (semitones when chromatic is true), keeping their length, accent and slide. Returns the picks as they are after the move; a pick whose note is gone is dropped. One undo step.

    Note: This function can be invoked via the meta-object system and from QML. See Q_INVOKABLE.

    [invokable] QVariantMap MonoMachine::noteSettings(const QVariantList &picked) const

    Returns the settings of the first of the picked notes still present: a map with length, velocity, nudge (in % of a step), count and nudgeUnit (one nudge unit in % of a step); an empty map when none is left.

    Note: This function can be invoked via the meta-object system and from QML. See Q_INVOKABLE.

    Emitted when octave changed.

    [invokable] void MonoMachine::randomize()

    Writes a fresh in-key line over the whole pattern, leaning on the root: most steps play, about a third of them on the root, some accented, a few sliding.

    Note: This function can be invoked via the meta-object system and from QML. See Q_INVOKABLE.

    [invokable] void MonoMachine::setNote(int step, int note)

    Puts note on step of the viewed bar and sounds it, or clears the step when it already holds that note.

    Note: This function can be invoked via the meta-object system and from QML. See Q_INVOKABLE.

    [invokable] void MonoMachine::setNoteLength(int step, int steps)

    Sets how many steps the note on step of the viewed bar lasts (1 to 64; it may reach into the next bars); does nothing on a step without a note.

    Note: This function can be invoked via the meta-object system and from QML. See Q_INVOKABLE.

    [invokable] QVariantList MonoMachine::shiftNotes(const QVariantList &picked, int steps)

    Moves the picked notes steps steps later (positive) or earlier, with their length, accent and slide. A step holds one note, so a note landing on another replaces it, and a note that would leave the pattern stays. Returns the picks as they are after the move. One undo step.

    Note: This function can be invoked via the meta-object system and from QML. See Q_INVOKABLE.
