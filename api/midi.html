    Type Documentation

    enum class Midi::ControlGroup

    Which of the learnable controls (MidiInput::controls) a control is one of.

    ConstantValueDescription
    Midi::ControlGroup::Keys0the device's keys (PLAY, the step keys…) and ravving's own actions
    Midi::ControlGroup::Knobs1the device's knobs
    Midi::ControlGroup::Mixer2the instruments' mixer and the transport (MixerControl)

    enum class Midi::DriverState

    Where a controller's driver (ControllerDriver) is with it.

    ConstantValueDescription
    Midi::DriverState::Idle0not started, or stopped
    Midi::DriverState::Connecting1started, waiting for the controller's answer
    Midi::DriverState::Ready2talking to the controller
    Midi::DriverState::Lost3the controller stopped answering

    enum class Midi::LearnTarget

    What MidiInput takes a controller's next message as, while learning.

    ConstantValueDescription
    Midi::LearnTarget::Nothing0not learning: the messages play
    Midi::LearnTarget::Hit1a drum key: the note that plays a drum row or pad
    Midi::LearnTarget::Control2a control: the note, CC or pitch bend that works one of the device's keys or knobs, or a mixer control
