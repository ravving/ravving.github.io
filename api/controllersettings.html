    ControllerSettings Struct

    One controller's settings, as the user set them over its profile's defaults: what its messages become (MidiInput), whether its driver hosts it (ControllerDrivers), whether its octave follows ravving's (ControllerOctaves). More...

    Detailed Description

    A value type: ControllerSettingsStore keeps one per controller and writes it to the file. The scalar fields are named (Field, fieldName()) the same wherever they are read or written: the INI key, toMap()'s key for QML, MidiInput::setOption()'s option.

    enum class ControllerSettings::Field

    The scalar settings, by the name they are kept and shown under.

    ConstantValueDescription
    ControllerSettings::Field::Channel0channel, the channel the controller is heard on (1 to 16; 0 all)
    ControllerSettings::Field::Transpose1transpose, semitones its notes move (−48 to 48)
    ControllerSettings::Field::Velocity2velocity, the velocity every note plays at (1 to 127; 0 as sent)
    ControllerSettings::Field::Curve3curve, the velocity curve (0 as sent, 1 soft, 2 softer, 3 even)

    ControllerSettings::Field::Expression6expression, its bend, pressure and slides reach the machine it plays (0 or 1)
    ControllerSettings::Field::Lights7lights, the learned MIXER keys' state sent back to it (0 or 1)
    ControllerSettings::Field::Pickup8pickup, its faders take a level over once they reach it (1), or on any move (0)
    ControllerSettings::Field::Host9host, its driver hosts it (0 or 1)
    ControllerSettings::Field::OctaveLinked10octaveLinked, its own octave follows ravving's (0 or 1)

    Member Function Documentation

    void ControllerSettings::clamp()

    Keeps every field in range, whichever way it came (the user's taps, a file edited by hand, a profile): the channel 0 to 16, the transpose ±48, the velocity 0 to 127, the curves within MidiValues' tables, the bend range 1 to 96; a drum key's note 0 to 127; a control's message one LearnedMessage reads (the others go).

    [static] QString ControllerSettings::fieldName(ControllerSettings::Field field)

    Returns the name field is kept and shown under.

    [static] std::optional<ControllerSettings::Field> ControllerSettings::fieldNamed(const QString &name)

    Returns the field kept and shown as name (channel, bendRange…), none for a name that is no field.

    void ControllerSettings::set(ControllerSettings::Field field, int value)

    Sets field to value (a boolean field to whether it is not 0), then keeps every field in range (clamp()).

    QVariantMap ControllerSettings::toMap() const

    Returns the settings for QML: each Field by its name (expression, lights, pickup, host and octaveLinked as booleans), label, surface, knobs, hits (note as text → slot) and controls (control id → message).

    int ControllerSettings::value(ControllerSettings::Field field) const

    Returns field's value; a boolean field as 0 or 1.

    bool ControllerSettings::operator!=(const ControllerSettings &other) const

    Returns whether any setting differs from other's.

    bool ControllerSettings::operator==(const ControllerSettings &other) const

    Returns whether every setting is the same as other's.
