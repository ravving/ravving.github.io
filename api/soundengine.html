    Detailed Description

    Machines only see this interface, so swapping a machine's engine is a change in data/kits.json, and a new kind of engine is one more subclass created by createEngine(). FluidSynthEngine and JalvEngine are the two kinds. GUI thread only.

    Member Function Documentation

    [pure virtual] QStringList SoundEngine::audioOutputPorts() const

    Returns the full JACK names of the engine's audio outputs, left then right.

    [static] SoundEngine *SoundEngine::createEngine(const QVariantMap &config, const QString &name, ZynthboxBridge *bridge, QObject *parent)

    Builds the engine config describes (an engine object of kits.json: type is fluidsynth or jalv), named name on the JACK graph, run through libzynthbox's bridge and parented to parent. Returns nullptr for a config without a type (the samplers play through SamplerSynth) and, after reporting an issue, for an unknown type.

    [virtual] bool SoundEngine::hasControl(const QString &symbol) const

    Returns whether symbol reaches one of the engine's controls (a sound control on a port the engine lacks does nothing). The default returns true: the engine cannot tell.

    [pure virtual] QString SoundEngine::midiInputPort() const

    Returns the full JACK name of the engine's MIDI input, such as ravving-drums1-midi:midi_00.

    [pure virtual] void SoundEngine::reconfigure(const QVariantMap &config)

    Loads another sound described by config (the keys of the kits.json engine object, such as a new soundfont); started() follows again once the engine is back.

    [virtual] void SoundEngine::setControl(const QString &symbol, double value)

    Sets the engine's own control symbol (in the engine's terms, such as an LV2 port symbol) to value. The default ignores it.

    See also hasControl().

    [pure virtual] void SoundEngine::start()

    Starts the engine and loads its sound; started() follows once it takes commands.

    [signal] void SoundEngine::started()

    Emitted when the engine is up; its ports may still take a moment to appear on the graph.

    [pure virtual] void SoundEngine::stop()

    Stops the engine's process for good (the machine switches to another sound source); the object is deleted afterwards.

    [virtual] QString SoundEngine::title() const

    Returns the name of what the engine plays (an LV2 synth's own name); the default returns an empty string.
