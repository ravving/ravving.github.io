    Detailed Description

    • Mode: mic, guitar or line. Each mode sets the input card's gain (the ADC's PGA, -12 to +40 dB, kept per mode) and its mic bias (on for mic). mic and guitar are mono, taken from whichever input jack carries the signal (activeJack: jack 4 is the left channel, jack 5 the right) and sent to both sides; the jack is switched while nothing records, when one is 10 dB louder than the other and above -45 dBFS. line is stereo. The mode is a device setting, stored in QSettings, not in the project.
    • Level: while armed, the input feeds libzynthbox's port recorder (AudioLevels' SystemRecorder), whose meter gives level.
    • Monitor: the input heard through the master. It goes through a sketchpad track of its own (kits.json's input track, one no machine uses), whose level is monitorLevel. It starts off.
    • Effects: the input effects (effects, an InputEffects) sit between the input and both the monitor and the take, so what is heard is what is recorded.
    • Takes: record() starts the port recorder on the input, after its effects (a 16-bit WAV in the cache); stop() or autoStop ends it. A sampler take is then processed on a worker thread (AudioFile::processTake()), written to the samples folder and announced with takeReady(), with its last burst of sound as the trim. An as-played take (record(true)) is kept unprocessed (LiveRecordings) and announced with recordingReady().

    AudioLevels runs one recording at a time for all its recorders, so a take is refused while the mix recording (MixRecorder) runs, and the other way round. GUI thread only.

    Member Function Documentation

    InputRecorder::InputRecorder(const QVariantMap &config, QObject *audioLevels, JackWiring *wiring, InputEffects *effects, Tuner *tuner, QObject *parent = nullptr)

    Constructs the input from config, kits.json's input object: card (the ALSA card), portsCard (the PipeWire port alias its capture ports are found by, HardwarePorts), left and right (the JACK names to fall back on) and track (the monitor's sketchpad track). audioLevels is libzynthbox's AudioLevels (null on a desktop), wiring wires the monitor (null on a desktop), effects and tuner are owned by the caller. With an empty config or no AudioLevels the input is not available. parent is the QObject parent.

    [invokable] bool InputRecorder::record(bool asPlayed = false)

    Starts a take. A sampler take (asPlayed false, the default) is processed for a slot and may end by itself (autoStop), then takeReady() is emitted; an as-played take (asPlayed true) is kept as recorded, runs until stop() and is stored where keepIn says, then recordingReady() is emitted. Returns false when refused: not available, the mix recording runs, or a take is in progress.

    Note: This function can be invoked via the meta-object system and from QML. See Q_INVOKABLE.

    [signal] void InputRecorder::recordingReady(const QString &file)

    Emitted when an as-played take is kept at file (where keepIn says).

    void InputRecorder::setListener(const QStringList &ports)

    Feeds ports (left, right) with the input as heard (the jack in use, the gain, the effects), besides the monitor and the takes; VideoRecorder uses it for its mic. An empty list feeds none. The input counts as in use while ports are set.

    [invokable] void InputRecorder::stop()

    Ends the take; once the recorder has closed its file it is processed or kept, and takeReady(), recordingReady() or takeFailed() follows.

    Note: This function can be invoked via the meta-object system and from QML. See Q_INVOKABLE.

    [signal] void InputRecorder::takeFailed(const QString &reason)

    Emitted when a take could not be made or processed, with a translated reason.

    [signal] void InputRecorder::takeReady(const QString &file, qreal start, qreal length)

    Emitted when a sampler take is ready at file, with its last burst of sound as a slot's trim: start, and length as a fraction of what follows the start (SamplerMachine::setSlotTrim()).
