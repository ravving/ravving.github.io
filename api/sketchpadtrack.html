    Detailed Description

    A PatternModel takes its routing from the track object set as its zlChannel, through these properties, and configures MidiRouter itself (chainedSounds into MidiRouter::setZynthianChannels()). This class provides only the properties and signals PatternModel reads. The track's number is the pattern's (PatternModel::sketchpadTrack), not stored here.

    [read-only] samples : QVariantList

    This property holds the ten sample slots (two rows of five; null for an empty one). PatternModel indexes every one, so the list always holds ten entries; each filled one is an object whose cppObjId must be its ClipAudioSource's id, which PatternModel looks the clip up by.
