    ControllerMixer Class

    A controller with mixer strips, a control surface: each strip follows an instrument (followStrip()), the transport buttons the transport (followTransport()), and the strips' controls come back as requests (askStrip(), askTransport()). Its driver implements it (MackieSurface). More...

    enum class ControllerMixer::StripRequest

    What a strip's control asks of its instrument.

    ConstantValueDescription
    ControllerMixer::StripRequest::Level0its level, to a value 0 to 1
    ControllerMixer::StripRequest::Pan1its pan, to a value −1 to 1
    ControllerMixer::StripRequest::Mute2its mute, flipped
    ControllerMixer::StripRequest::Solo3its solo, flipped
    ControllerMixer::StripRequest::Record4its take, started or ended
    ControllerMixer::StripRequest::Stop5its written pattern, paused or played again

    ControllerMixer::TransportRequest::Page1the screen's next or previous instrument page, the value's sign

    [static] qreal ControllerMixer::turnedLevel(qreal level, qreal unity, int ticks, qreal step)

    Returns level turned by ticks of step, within 0 and 1: a turn going through 0 dB (unity, -1 when not known) stops there once, and the next tick goes on.

    [static] qreal ControllerMixer::turnedPan(qreal pan, int ticks, qreal step)

    Returns pan turned by ticks of step, within −1 and 1: a turn going through the middle stops there once, and the next tick goes on.
