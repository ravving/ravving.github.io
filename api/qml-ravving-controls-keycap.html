    Detailed Description

    A raised cap in the machine's finish with an LED strip along its top edge. Used for the step keys, the chord keys and the sampler banks.

    Property Documentation

    alternate : bool

    Use the alternate cap colour (every other group of four steps).

    finish : var

    The machine finish the cap is drawn in (an entry of Rave.machines); with none given, the skin it sits in.

    fontSize : int

    Small second line under the text (e.g. "II · 2" on chord keys).

    ledColor : color

    Use the alternate cap colour (every other group of four steps).

    lit : bool

    LED on: the step is set / the key is selected.

    playhead : bool

    The transport is on this key's step.

    subText : string

    Small second line under the text (e.g. "II · 2" on chord keys).
