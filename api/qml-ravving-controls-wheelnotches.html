    WheelNotches QML Type

    A mouse wheel or a touchpad over a value, counted in whole notches: what turns a Knob or a LedDisplay on a desktop. More...

    Import Statement: import Ravving.Controls 1.0
    • List of all members, including inherited members

    Signals

    • notched(int notches)

    Detailed Description

    Declared inside the control it turns, it reports the wheel's turns under the pointer as whole notches (notched), a notch a device knob's detent to its owner. A touchpad's small steps add up to a notch; turned the other way, what was left over goes. A touchpad's natural scrolling turns the value the way the fingers go.

    It works only where there is a wheel (Interaction::wheel: on a desktop), and not while a dialog is up over the control. A control inside the dialog on top still turns (Interaction::onTopLayer()).

    
 // inside the control: a notch a detent
 WheelNotches { onNotched: notches => control.value += notches * control.knobStep }

    Signal Documentation

    notched(int notches)

    The wheel turned notches whole notches: up (away from the user), positive.
