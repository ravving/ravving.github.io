    Detailed Description

    The values the style (Ravving.Style), the UI kit and the app's QML read, so a size, a colour or a duration is defined once. One look, set in code: nothing here is read from a theme or a setting. QML reads it as the Theme singleton of Ravving.Theme; C++ reads the same values through the static getters (ThemeColors::accent()). The font families come from the app (setFontFamilies()).
