    Detailed Description

    A soundfont carries no family or genre of its own (most are converted SFZ sets with an empty INFO block), so ravving tells the pickers what a font is from two places:

    • Its folder. The library (Paths::soundfonts()), the soundfont cache and a stick's ravving/soundfonts keep one folder per family, as the sound browsers and the soundfont archives do (soundfonts/kits/Roland TR-909.sf2, soundfonts/keys/…): the first folder under the root, when it is a family's folder, is the family (folderFamily()). A font loose at the root has none from its place.
    • The table. soundfonts.json, beside kits.json, names the family, the genre and the maker of every font ravving knows by its file name: the device's built-in fonts (Zynthian's folders are not ravving's to rearrange) and the fonts the test stick and the catalog carry. It also lists the families and the genres in the order the pickers show them.

    familyOf() takes the folder first, then the table, else other(), the group a picker shows the rest under. The genre is the table's (a filter in the pickers: a Rhodes is soul, pop and hip hop at once, so no folder holds it). The maker is the table's, else the first word of the file name when it reads as one (Roland, Akai, Korg…: makerFromName()). placeOf() says where a font is kept under a soundfonts root: its family's folder, its own folders below that, its file name.

    The families are KITS, PERCUSSION, BASS, KEYS, SYNTH, STRINGS, ORCHESTRAL, GUITAR, VOCAL, SFX and GM (the General MIDI banks); a family's folder is its name in lower case (familyFolder()), and other() has no folder: it is the root. The genres are ravving's broad groups: HIP HOP · TRAP, SOUL · R&B, HOUSE · TECHNO, BASS · BREAKS, POP, ROCK · PUNK, METAL, JAZZ · BLUES, LATIN, WORLD · REGGAE, FOLK · COUNTRY, CLASSICAL · CINEMATIC, AMBIENT · DOWNTEMPO, GENERAL for the General MIDI banks and NOVELTY for animals, toys and memes.

    Member Function Documentation

    [static] QStringList SoundfontTags::families()

    Returns the families in the order the pickers show them (the table's families).

    [static] QString SoundfontTags::familyFolder(const QString &family)

    Returns the folder a font of family is kept in under a soundfonts root: the family in lower case ("keys"), or empty (the root) for other() or anything the table does not list as a family (a catalog's say-so never makes a folder).

    [static] QString SoundfontTags::familyForProgram(const QString &family, int bank, int program)

    Returns the family a sound of a font of family is listed under when the font is a GM bank (GM): what General MIDI makes of program (0–23 keys, 24–31 guitar, 32–39 bass, 40–47 strings, 48–51 and 55–79 orchestral, 52–54 vocal, 80–103 synth, 104–111 strings, 112–119 percussion, 120–127 sfx; bank KitBank or Gm2KitBank kits), so a bank's Rhodes sits with the keys and its choir with the voices; any other family as it is.

    [static] QString SoundfontTags::familyOf(const QString &path, const QString &root = QString())

    Returns the family of the soundfont file path, under the soundfonts folder root when known (tagsOf()).

    [static] QString SoundfontTags::folderBelow(const QString &path, const QString &root)

    Returns the folder path sits in below its family folder under root: "roland" for <root>/kits/roland/x.sf2, "rhodes/soft" for <root>/keys/rhodes/soft/x.sf2; empty for a file right in its family folder, at the root, in no family folder, or not under root.

    [static] QString SoundfontTags::folderFamily(const QString &path, const QString &root)

    Returns the family path sits in under root: the first folder below it when it is a family's folder ("KEYS" for <root>/keys/Wurlitzer EP200.sf2, any case), empty for a file at the root, in some other folder, not under root, or with no root given.

    [static] QString SoundfontTags::genreOf(const QString &path)

    Returns the genre of the soundfont file path (tagsOf()).

    [static] QStringList SoundfontTags::genres()

    Returns the genres in the order the pickers show them (the table's genres).

    [static] void SoundfontTags::load(const QString &file)

    Reads the table file (data/soundfonts.json: families and genres in their order and fonts by file name, each {"family", "genre", "maker"}). Missing or unreadable, the table is empty and every font is other() with the maker read off its name.

    [static] QString SoundfontTags::makerFromName(const QString &name)

    Returns the maker read off a font's name: its first word when the name has more than one, the word is three letters or more and is not a number ("Roland TR808" → Roland, "HS Linn Drums" → HS); empty for a single-word name (DrumFire, Lab) or an odd one (E Ave, SP 12).

    [static] QString SoundfontTags::makerOf(const QString &path)

    Returns the maker of the soundfont file path (tagsOf()).

    [static] QString SoundfontTags::other()

    Returns the group of the fonts nothing is known for: "OTHER", as the choice lists already call what falls outside their groups.

    [static] QString SoundfontTags::placeOf(const QString &path, const QString &root = QString())

    Returns where the soundfont path is kept under a soundfonts root, relative to it: its family's folder (familyFolder() of its family: the folder it sits in under root, or in its own path without one, else the table's), its own folders below that (a stick's kits/roland), then its file name; the file name alone for a font of no family (other()). The library, the cache and a stick agree on it: a stick's kits/roland/x.sf2 lands in the cache's kits/roland/x.sf2.

    [static] QString SoundfontTags::placedFamily(const QString &path)

    Returns the family path is placed under without a root to go by: the folder right after a soundfonts folder in it, when that folder is a family's (a stick's ravving/soundfonts/keys/x.sf2, the library's soundfonts/keys/x.sf2); empty otherwise (Zynthian's soundfonts/SF2 Instruments/ is no family).

    [static] QString SoundfontTags::placedFolder(const QString &path)

    Returns the folder path sits in below its family folder, without a root to go by (as placedFamily() finds the family): "roland" for …/soundfonts/kits/roland/x.sf2, empty for a file right in the family folder or in no family folder.

    [static] QVariantMap SoundfontTags::rowsOf(const QString &path)

    Returns the names the table gives the keys of the kit file path ({"36": "BARK"}): for a font whose sample names say only a drum's role. Empty for every other font.

    [static] SoundfontTags::Tags SoundfontTags::tagsOf(const QString &path, const QString &root = QString())

    Returns the tags of the soundfont file path: its family (the family folder it sits in under root, the soundfonts folder it is under when known, or in its own path without one; else the table's; else other()), its genre (the table's, else other()), its maker (the table's, empty when the table says the font has none, else makerFromName()) and its folder below the family folder (folderBelow(); without a root, placedFolder()).
