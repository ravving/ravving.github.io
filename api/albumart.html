    Detailed Description

    A cover is one of the glitch artworks (glitches/ in the artworks folder, 1000 px JPEGs), at most one die-cut sticker (stickers/) turned a little and stuck along the art's edge, and the track's title in the display family (Fonts, theme/tokens.json fonts.display), in one of two looks (Variant) the seed picks:

    • The sidebar (two covers in three): a black column down the left quarter, the artwork filling the rest. Down the column: the title's words, one a line (at most four), each as large as fills its width; justified small print of the real facts; a thin box with bracket ticks holding the project's icon at a large whole scale (else the cover's one sticker, none then on the art; else RAVV); the title's last line; a four-pointed star; taglines under dot ticks (the author, the tempo and key, the date); and the foot's strip, the RAVV mark between the tempo's figures. What does not fit is left out, the least needed first.
    • The corner: the artwork filling the square, the title over its foot on a dark fade with a VHS fringe in ARU's pink and mint (art.cover), a label block in the bottom-right corner and a spine of small capitals up the left edge (the author, else the title). The label block is the sleeve's panel of format logos: a black plate in a thin white frame with bracket ticks at its corners; along its top, ruled apart, the project's icon (a built-in glyph, Glyphs) and ravving's short wordmark RAVV (marks/ravv.png, made from notes/brand/logo/ravv-ink.svg); under them a framed box with the track's credits: its tempo and key in ARU's pink, the plate's one accent, and the sounds that play. The icon is scaled by a whole number (iconRect() says where); without an icon, or with a name that is no built-in glyph, RAVV stands alone; without credits there is no box. The title keeps to the left of the block, its foot level with the block's.

    Everything written on a cover is real (Credits: who made it, the sounds that play, the tempo, the key, the date) or the title; an empty title is drawn as "Untitled".

    Which artwork, which look, which stickers and where they sit all come from a seed, so one seed always draws the same art and the title and the credits can change over it: newSeed() picks a fresh one at random for each export, and the export's sidecar keeps it. layout() says where every part lands, render() draws it, write() saves it as a PNG beside a track and png() gives the bytes that go into a file's tag. AlbumArtProvider serves the same drawing to QML.

    The artworks folder is the data folder's artworks/ (data/artworks in the source, installed with the rest of the data), set once with setFolder() before the first cover. A folder that is missing, or a part of it, is logged, and the cover is drawn without what is missing: the title, the sidebar or the label block on the dark ground (RAVV set in the display family when its picture is missing).

    The functions are reentrant (the folder's listing is read once, behind a lock; the images on each call); the exporter calls them from its worker thread.

    Function Documentation

    QString AlbumArt::artworkName(quint32 seed)

    Returns the name of the artwork seed picks (its file's name without the folder and the extension, glitch-record-store); empty when there is none.

    QStringList AlbumArt::artworks()

    Returns the artworks (the folder's glitches/), by name.

    QString AlbumArt::folder()

    Returns the artworks folder setFolder() read; empty before it is called.

    See also setFolder().

    QRect AlbumArt::iconRect(int size = 1000)

    Returns where a project's icon lands on art size pixels square: the glyph's own pixels (32 times a whole number of them), at whole-pixel coordinates in the label block's plate, in the bottom-right corner.

    AlbumArt::Layout AlbumArt::layout(const QString &title, const QString &icon, quint32 seed, int size = 1000, const AlbumArt::Credits &credits = {}, AlbumArt::Style style = Style::Random)

    Returns where the parts of the cover for title, wearing the glyph icon (empty, or a name that is no built-in glyph, for none), land with seed on art size pixels square, with credits in the label block and up the spine, in the look style asks for (the seed's when Style::Random).

    The label block sits in the bottom-right corner, the title to its left at the foot, as large as fits that width on one line down to two thirds of its largest size, else in up to three lines. The seed picks the artwork, then at most one sticker (none when the sidebar's box holds it, for want of an icon), about a quarter of the cover across, turned 4 to 13 degrees either way, at spots along the edges taken in an order of its own; a sticker that would touch the title, the sidebar, the label block, the spine or the cover's edge is made smaller, or left off.

    quint32 AlbumArt::newSeed()

    Returns a fresh seed, at random: a cover no export has had yet, most likely.

    QByteArray AlbumArt::png(const QString &title, const QString &icon, quint32 seed, int size = 1000, const AlbumArt::Credits &credits = {}, AlbumArt::Style style = Style::Random)

    Returns the cover for title, wearing the glyph icon (empty for none), drawn with seed and carrying credits in the look style asks for, size pixels square, as PNG bytes (what goes into an audio file's cover tag).

    QImage AlbumArt::render(const QString &title, const QString &icon, quint32 seed, int size = 1000, const AlbumArt::Credits &credits = {}, AlbumArt::Style style = Style::Random)

    Returns the cover for title wearing the glyph icon (empty, or a name that is no built-in glyph, for none), drawn with seed (layout() says where its parts go) and carrying credits in the look style asks for, as a square image size pixels wide (1000 for an export, smaller for a preview).

    void AlbumArt::setFolder(const QString &folder)

    Reads the artworks folder folder: its glitches/*.jpg, stickers/*.png and marks/ravv.png. Call it once at the start, before the first cover (main.cpp passes the data folder's artworks/). A folder or a file that is missing is logged, and the covers are drawn without it.

    See also folder().

    QStringList AlbumArt::stickers()

    Returns the stickers (the folder's stickers/), by name.

    AlbumArt::Style AlbumArt::styleFromName(const QString &name)

    Returns the style named name: sidebar, corner, else Style::Random.

    QString AlbumArt::styleName(AlbumArt::Style style)

    Returns style's name: random, sidebar or corner (what styleFromName() reads).

    bool AlbumArt::write(const QString &path, const QString &title, const QString &icon, quint32 seed, int size = 1000, const AlbumArt::Credits &credits = {}, AlbumArt::Style style = Style::Random)

    Saves the cover for title, wearing the glyph icon (empty for none), drawn with seed and carrying credits in the look style asks for, size pixels square, as a PNG at path. Returns false when it could not be written.
