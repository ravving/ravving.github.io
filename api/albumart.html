    AlbumArt Namespace

    Cover art drawn for a track, so every export has artwork of its own. More...

    Detailed Description

    The art is a rounded card on a dark sleeve, filled with a gradient whose colours are seeded from the title and the artist (the same names always give the same art), with soft lights, a faint big-knob ring in a corner, the title in large type (shrunk to fit), the artist under it, the album or mixtape in small capitals, and "MADE WITH" with ravving's wordmark (data/branding/ravving-wordmark.svg) at the bottom. An empty title is drawn as "Untitled".

    render() draws it, write() saves it as a PNG beside a track and png() gives the bytes that go into a file's tag. AlbumArtProvider serves the same drawing to QML. The functions are reentrant; the exporter calls them from its worker thread.

    QByteArray AlbumArt::png(const QString &title, const QString &artist, const QString &album, int size = 1000)

    Returns the art for title, artist and album, size pixels square, as PNG bytes (what goes into an audio file's cover tag).

    QImage AlbumArt::render(const QString &title, const QString &artist, const QString &album, int size = 1000)

    Returns the art for title, artist and album as a square image size pixels wide (1000 for an export, smaller for a preview).

    bool AlbumArt::write(const QString &path, const QString &title, const QString &artist, const QString &album, int size = 1000)

    Saves the art for title, artist and album, size pixels square, as a PNG at path. Returns false when it could not be written.
