    Detailed Description

    A machine plays a controller's expression on its engine's live channel (Machine::sendLive()): pitch bend, channel and key pressure, and the performance controllers (the mod wheel, breath, expression, the pedals, an MPE slide's CC 74, the sound controllers). The controllers that set the channel's own state are not expression and never go there: what they set outlives the gesture, nothing in ravving shows it, and some of it survives a Reset All Controllers.

    • Bank select (CC 0 and 32): ravving alone picks an engine's presets.
    • Data entry, increment and decrement, NRPN and RPN select (CC 6, 38, 96 to 101): a FluidSynth channel keeps its SoundFont NRPN armed after ravving's generator offsets (FluidSynthEngine), so a stray data entry writes a generator; a SoundFont 2 sample start offset moved forward silences every sample shorter than the offset. A controller's own pitch bend range (RPN 0) is read by MidiInput before this.
    • Channel volume, balance and pan (CC 7, 8, 10 and their LSBs 39, 40, 42): the machine's level and pan are the track's (its mixer strip, or a fader learned as a MIXER control); on the engine's channel they would be a second level nothing shows, kept by a Reset All Controllers.
    • The channel mode messages (CC 120 to 127): all sound off, reset all controllers, local control, all notes off, omni and mono / poly modes.

    Pure functions, no state.

    Function Documentation

    bool EngineMidi::isChannelState(int controller)

    Returns whether the control change controller (0 to 127) sets the engine channel's own state (bank, data entry, parameter select, volume, balance, pan, the channel modes) rather than playing expression.

    bool EngineMidi::isExpression(int status, int data1)

    Returns whether the channel message status (its high half or the whole status byte) with first data byte data1 is expression a controller may play on an engine's channel: pitch bend, channel or key pressure, or a control change that is not channel state (isChannelState()). Notes, program changes and the system messages are not.
