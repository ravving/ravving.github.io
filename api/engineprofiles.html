    Detailed Description

    A profile holds the engine's sound-control cards (SoundControls) and its expressions (the live controls, such as vibrato, Machine::setExpression()). It is matched by the engine itself: its kits.json engine object's type and, for jalv, its plugin uri. So every source that plays an engine gets that engine's controls, whichever machine it is on: two machines' sources on the same synth share one profile, and every soundfont shares the fluidsynth one.

    
 {"engines": [{"id": "calf-monosynth", "type": "jalv",
               "uri": "http://calf.sourceforge.net/plugins/Monosynth",
               "sound": [cards...], "expressions": {"vibrato": {"symbol": "lfo2pitch", "max": 60}}},
              {"id": "fluidsynth", "type": "fluidsynth", "sound": [cards...]}]}

    A machine or source that brings its own sound in kits.json keeps it; an engine with no profile has no sound controls. The studio checks the symbols against the engine's ports when it starts. A plain value type.

    Member Function Documentation

    QStringList EngineProfiles::ids() const

    Returns the profiles' ids, in the file's order.

    bool EngineProfiles::load(const QString &file)

    Reads the profiles from file. Returns false, leaving no profiles, when it cannot be read.

    QVariantMap EngineProfiles::profileFor(const QVariantMap &engine) const

    Returns the profile of engine (a kits.json engine object), matched by type and, for jalv, uri; an empty map when it has none.

    QVariantMap EngineProfiles::resolve(QVariantMap machine) const

    Returns the kits.json config machine with its profiles filled in: the own engine's sound and expressions, every other jalv source's on that source, and the soundfont sources' as sourceSound and sourceExpressions. What the config brings itself stays.

    QVariantMap EngineProfiles::resolveKit(QVariantMap machine) const

    Returns a drum machine's kits.json config machine with its engine profile's kitSound as its sound (a kit is one soundfont on one channel, so its sound controls act on the whole kit); a sound it brings itself stays.

    void EngineProfiles::setProfiles(const QVariantList &profiles)

    Sets the profiles as read (engines.json's engines list); for tests and tools.
