    Detailed Description

    Read by QML as Theme.type.label and by C++ through the static getters. Sizes are pixels on the MIKO's 1280 × 800 panel.

    Member Function Documentation

    [static] QFont ThemeType::step(ThemeType::Family family, int pixelSize, int weight, qreal trackingEm, bool upper)

    Returns a font of family at pixelSize, weight (100–900), with trackingEm of letter spacing (a fraction of the size) and, when upper, in capitals.
