    Detailed Description

    The optional second part is the ink as six hex digits (Glyphs::image()'s near-black when it is left out). The image is drawn at the largest whole multiple of 32 pixels that fits the requested size (32 when none is asked), so an Image with smooth: false shows it crisp. An unknown name gives a null image. Registered on the QML engine as glyph.
