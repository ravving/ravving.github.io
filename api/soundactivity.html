    SoundActivity Class

    Which tracks are sounding, or would be if they were not muted: what lights a machine's lamp (SoundLamp.qml) whatever its fader, mute, solo or pause. More...

    Detailed Description

    A track sounds when its level before the fader (libravving::Meters::tracksIn, what its machine makes) is over HeardDb, or when its pattern runs muted and came to a note it did not play (the sequencer counts those, libravving::Sequencer::silentHits()). Either keeps the track sounding for HoldMs, so a pattern's hits read as one steady light rather than a flicker. Read with sounding() as often as the meters are; GUI thread only.

    void SoundActivity::setClock(const SoundActivity::Clock &now)

    Times the readings by now (milliseconds, monotonic), a clock of the caller's: for the tests. Unset, it keeps its own.

    QList<bool> SoundActivity::sounding(const QList<float> &sourcesDb)

    Returns, for each track, whether it sounded within HoldMs: sourcesDb is each track's level before its fader now (dBFS; a track beyond it reads as silent). Call it from one place at a steady rate: each call is a reading.
