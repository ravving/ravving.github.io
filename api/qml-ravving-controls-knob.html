    Detailed Description

    The dial is a QQC Dial for the touch handling (a vertical drag), drawn by a DialFace: vector, so it stays crisp at the small sizes the machines use, in the machine's accent; a range around zero (pan, pitch, dB) fills from its centre. The caption, readout and the optional end markers (e.g. L and R on a pan knob, beside the dial's lower corners) follow the machine's ink.

    It is also a KnobGroup target: a group sets knobBadge while a device knob drives it, and the KnobBadge appears on the dial's shoulder.

    Property Documentation

    accent : color

    Caption, groove and pointer colour (match the surface the knob sits on), and the value arc's colour (the machine's accent). With none given, the skin's ink and accent, when there is one.

    captionHeight : real [read-only]

    What the knob adds to its dial, measured from its texts: below it the label and the value, beside it the L / R labels. An owner sizing the dial to its room subtracts them.

    fineStep : real

    KnobGroup target API: value change per knob detent and per big-knob (fine) detent, the device knob driving it (-1 none), and whether a fixed pot still awaits pick-up.

    from : real

    The dial's value and range (a Zynthbox-styled QQC Dial underneath).

    fromLabel : string

    Small markers at the start and the end of the dial's travel (empty: none).

    ink : color

    Caption, groove and pointer colour (match the surface the knob sits on), and the value arc's colour (the machine's accent). With none given, the skin's ink and accent, when there is one.

    knobBadge : int

    KnobGroup target API: value change per knob detent and per big-knob (fine) detent, the device knob driving it (-1 none), and whether a fixed pot still awaits pick-up.

    knobPending : bool

    KnobGroup target API: value change per knob detent and per big-knob (fine) detent, the device knob driving it (-1 none), and whether a fixed pot still awaits pick-up.

    knobStep : real

    KnobGroup target API: value change per knob detent and per big-knob (fine) detent, the device knob driving it (-1 none), and whether a fixed pot still awaits pick-up.

    label : string

    Caption under the dial, and an optional formatted readout under that.

    labelSwitches : bool

    A knob whose caption names a mode (SWING 8 / 16) switches it by a tap on the caption: labelSwitches turns the tap on, labelTapped() reports it. Only on a page or the header: under a dialog it is off (Interaction.inputBlocked), so not in a dialog either.

    size : int

    Dial diameter in pixels.

    to : real

    The dial's value and range (a Zynthbox-styled QQC Dial underneath).

    toLabel : string

    Small markers at the start and the end of the dial's travel (empty: none).

    value : real

    The dial's value and range (a Zynthbox-styled QQC Dial underneath).

    valueSample : string

    The widest text valueText takes ("-60.0 dB"): the readout keeps its width, so the knob and what sits beside it stay put while the digits change. Empty: the readout's own width.

    valueText : string

    Caption under the dial, and an optional formatted readout under that.

    Signal Documentation

    labelTapped()

    The caption was tapped (only with labelSwitches): the owner switches what the knob drives.

    Note: The corresponding handler is onLabelTapped.

    moved()

    The user turned the dial by touch (not emitted for programmatic changes). A drag replaces a binding on value; owners that bind it restore the binding here.

    Note: The corresponding handler is onMoved.
