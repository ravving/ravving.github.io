    ControllerOctaves Class

    The controllers with an octave of their own (studio.octaves), linked to the current machine's octave: setOctave() goes to each linked one, and their own changes come back as octaveRequested(). Each controller can be unlinked by name (setLinked(), kept in the ravving/midi settings beside MidiInput's); unlinked, its octave buttons shift its own notes only. ControllerDrivers attaches each driver while it runs (a ControllerHub); add() links any other ControllerOctave. GUI thread only. More...
