    Detailed Description

    The file is {"devices": [ … ]}, each entry a profile: match, a part of the controller's port name (case does not matter); usb, the "vendor:product" its chip reports, for a name many controllers share ("USB Composite Device"); label, the name the controller is shown and kept under, its ControllerId on every connection it has; and the settings it starts with (ControllerSettings): the numbers channel, transpose, velocity, curve, pressure and bendRange, the booleans expression and lights, the texts surface (a driver's id) and knobs (a RelativeEncoder mode's name), hits (an object: a note's number → a drum row or pad) and controls (an object: a control id → the message that works it, LearnedMessage::text()). The first profile in file order that a controller fits is its (match()).

    What a profile says that is none of these, or not of that type, is dropped and said in the log (problems()); a profile with neither match nor usb is dropped whole. A controller's USB id comes from the sound cards' list (setSoundCardsDir(); /proc/asound): the card whose name its port name starts with, the longest when several do. No file, or one that is not JSON, is no known controller, said once in the log.

    Member Function Documentation

    [explicit] ControllerProfiles::ControllerProfiles(const QString &file = QString())

    Reads the profiles in file (none for an empty name).

    QVariantMap ControllerProfiles::byLabel(const QString &label) const

    Returns the profile labelled label (a known controller named by its label, plugged in or not); empty when none is.

    QString ControllerProfiles::labelOf(const QString &name) const

    Returns the label of the profile the controller name fits: the name it is shown and kept under, the same for every connection it has; empty for a controller with none.

    QVariantMap ControllerProfiles::match(const QString &name) const

    Returns the first profile the controller name fits (its match a part of the name and, when it has a usb id, that of the card the controller is on), as the file has it; empty when none does.

    QStringList ControllerProfiles::problems() const

    Returns what the file said that no profile may (a key that is no setting, one of the wrong type, an entry naming no controller), one sentence each; empty for a clean file.

    void ControllerProfiles::setSoundCardsDir(const QString &dir)

    Reads the sound cards from dir (cards and cardN/usbid in it) instead of /proc/asound.

    int ControllerProfiles::size() const

    Returns how many profiles there are.

    QString ControllerProfiles::usbIdOf(const QString &name) const

    Returns the USB id ("vendor:product") of the sound card the controller name is on: the card whose name the controller's port name starts with (the longest when several do); empty when none is.
