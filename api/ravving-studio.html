    Studio and projects

    History

    Project's undo history, published to QML as studio.history

    HistoryParticipant

    Interface of an object whose changes History can undo

    Localization

    Interface's language (KI18n), published to QML as localization

    NamedStore

    User's own named entries of one kind, kept in a JSON file of their own ({"presets": [{"name": ..., ...}, ...]})

    PresetExchange

    User's presets as files for exchange on a USB stick: the pattern presets they saved (a machine's PresetLibrary), the sounds they saved (Machine::saveSound()) and their project templates

    PresetLibrary

    A machine's pattern presets: the factory ones from its data file and the user's own, kept in a file of their own (NamedStore) so they survive across projects

    ProjectCheck

    Collects what a project names that is missing, while it opens

    Projects

    Saved projects, published to QML as studio.projects

    Sections

    Song's sections, each holding every machine's pattern, and the song: the sections in order, each played a number of times; published to QML as studio.sections

    Sections::Host

    What Sections needs of the machines; the studio implements it

    Sketchpad

    Sketchpad object libzynthbox talks to: PlayGridManager's zlSketchpad

    SketchpadTrack

    One sketchpad track as libzynthbox's PatternModel sees it

    Studio

    Ravving's backend root, published to QML as studio: the machines, the transport and the project

    TakeRecorder

    Records what is played live on a machine into its pattern as a fresh take; published to QML as studio.take

    Templates

    Project templates, published to QML as studio.templates: the settings a new project starts with, not its patterns

    UserProfile

    Device user's profile, published to QML as profile: the names exports put on every track and bundle, and device-wide preferences
