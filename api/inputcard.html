    Detailed Description

    The card is one: whoever holds the input line (InputRecorder, or the live recording's LiveRecMic) sets its PGA gain and mic bias through apply(); the ranges and defaults are the same for both, so a gain kept by one is valid for the other.

    Function Documentation

    void InputCard::apply(const QString &card, qreal gainDb, const QString &mode)

    Sets the ALSA card's PGA gain on both channels to gainDb (one of its half-dB steps) and its mic bias on for the mic mode, off otherwise, through amixer (detached: a knob turns fast). An empty card does nothing.

    qreal InputCard::clampGain(qreal gain)

    Returns gain rounded to the PGA's half-dB steps and kept within minGain() and maxGain().

    qreal InputCard::defaultGain(const QString &mode)

    Returns the gain a fresh mode starts with, in dB: 30 for a mic, 10 for a guitar, 0 for a line.

    bool InputCard::isMono(const QString &mode)

    Returns whether mode records one channel (the jack's tip): mic and guitar do, line keeps left and right.

    qreal InputCard::maxGain()

    Returns the highest gain the card's PGA takes: +40 dB.

    qreal InputCard::minGain()

    Returns the lowest gain the card's PGA takes: -12 dB.

    const QStringList &InputCard::modes()

    Returns the input modes: mic, guitar and line.

    QVariantMap InputCard::readGains(const QVariantMap &saved)

    Returns every mode's gain: the defaults, with the gains in saved (a settings map of mode to dB) over them, clamped; unknown modes are dropped.
