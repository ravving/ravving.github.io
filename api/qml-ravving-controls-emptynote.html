    Detailed Description

    Centred in the view, dim, why it is empty and what fills it ("no recordings yet · ● REC records the input as played"), with ARU, ravving's mascot, above it as a pixel glyph in the same ink when the view has room (the brand's "ARU in empty views", notes/brand/design-system.md B4). Which of ARU's forms shows follows the text, so a view keeps its own. Put it in the view (it fills it) with shown bound to the view being empty. See docs/ui-rules.md.

    
 ListView { id: list; EmptyNote { shown: list.count === 0; text: "nothing here yet · …" } }

    Property Documentation

    ink : color

    The view is empty, and the note's colour (with none given, the skin's dim colour, when there is one).

    mascot : string

    The glyph of ARU above the text (image://glyph), or empty for none. With none given, one of ARU's three forms, picked by the text.

    shown : bool

    The view is empty, and the note's colour (with none given, the skin's dim colour, when there is one).

    text : string

    Why the view is empty, and what fills it ("no X yet · how to get some").

    Method Documentation

    inkHex()

    Returns the ink as the glyph provider's rrggbb.
