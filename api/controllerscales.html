    bool ControllerScales::inKey(int note) const

    Returns whether note is in the project's key (setKey()); every note is, before a key is set.

    int ControllerScales::lightpadPad(int note) const

    Returns the pad of a Lightpad's layout on the page (pads()) that note is, counted from 36: the first nine, or all sixteen for the 4×4 layout; -1 for a note outside it or no layout.

    [invokable] void ControllerScales::setKey(int root, const QList<int> &steps)

    The project's key, root (0 to 11) and the scale's steps, for every controller that plays in one.

    Note: This function can be invoked via the meta-object system and from QML. See Q_INVOKABLE.

    [invokable] void ControllerScales::setPads(int pads)

    What the page on screen plays from pads, pads (ControllerScale::Pads), for every controller that plays in a key.

    Note: This function can be invoked via the meta-object system and from QML. See Q_INVOKABLE.
