    Detailed Description

    The snapshots live in a SnapshotStore in the projects folder (.timeline, a bare git repository whichever backend writes it), one branch per project (branchFor(): by the project's id, or its name until it has one) and one for the session never saved (unsavedBranch()); each snapshot holds the project's JSON, so the folder can be read with git itself. Projects drives it: switchTo() follows the project open, restart() begins a trail afresh (NEW), snapshot() adds a version (a SAVE's is kept even when unchanged), carry() continues the trail under a new key (the first SAVE, SAVE AS NEW), rename() and remove() follow the project's file, sweep() drops the trails of files that are gone, tidy() holds a trail to its limit and packs the store. Going back is Projects::restore(): the state read by stateAt() replaces the session. Older trails may hold snapshots of every change (kinds change, open, new, restore); they are listed and restored as the versions are.

    Every write runs on a worker thread, one after the other, with the store held under a lock; entries lists the branch's newest snapshots (Shown at most) and follows each write. Without a backend that can work here (SnapshotStore::create()) nothing is kept: available is false and entries stays empty. stateAt() and timeOf() are read on the calling thread.

    Member Function Documentation

    [explicit] ProjectHistory::ProjectHistory(const QString &dir, QObject *parent = nullptr)

    Constructs the timeline kept in the repository folder dir (made now, when there is none), with the given parent. The store is SnapshotStore::create()'s: without one that opens, available is false.

    QString ProjectHistory::branch() const

    Returns the branch the snapshots go to: the project open's (branchFor()), or unsavedBranch().

    [static] QString ProjectHistory::branchFor(const QString &id, const QString &name, bool demo)

    Returns the branch of a project: d/<name> for one of the shipped demos (demo), p/<id> for one with the id id, n/<name> for one named name without an id yet, and unsavedBranch() with neither. Names and ids are percent-encoded, so any is a valid branch.

    void ProjectHistory::carry(const QString &to)

    Continues the current trail under the branch to (which takes the current tip; a branch of that name is written over) and switches to it: the first SAVE of a session, SAVE AS NEW, a demo saved as the user's, the current project removed.

    [static] QStringList ProjectHistory::changedKeys(const QVariantMap &before, const QVariantMap &after)

    Returns what differs between the states before and after, as keys for label(): each machine's key, then tempo, swing, master, metronome, livefx, sends, sections, key (the root or scale), mix (mutes and solos) and other; what only says what is on screen (the page, the machines shown, the LIVE FX bank, the section on screen) is no change.

    void ProjectHistory::holdHousekeeping(bool held)

    Holds the housekeeping back while held (Studio holds it while the transport plays): a tidy asked for meanwhile (tidy()) runs once it is let go; one under way is not stopped.

    [signal] void ProjectHistory::housekept()

    Emitted when a tidy ran: after a manual SAVE (tidy()), and at start after the sweep.

    [static] QString ProjectHistory::label(const QString &kind, const QStringList &changed)

    Returns the text a snapshot is listed with, translated: for a kind change, what changed (the machines' names, TEMPO, SWING…, " · " between), SAVED (then what changed), OPENED, NEW PROJECT, or BACK TO and the time gone back to.

    [signal] void ProjectHistory::notify(const QString &text, const QString &color)

    Emitted with a short translated status text, such as "TIMELINE · KEEPING CHANGES AGAIN" once snapshots are written again after a failure, and its color (a CSS colour). The failures themselves go to the issues center (Issues::report()): timeline (the store did not open), timeline-write (a snapshot not written, cleared by the next one written), timeline-trail (a trail not carried or renamed with its project) and timeline-tidy (an old trail not removed, a notice).

    void ProjectHistory::remove(const QString &branch)

    Deletes the branch branch and its snapshots (a project deleted).

    void ProjectHistory::rename(const QString &from, const QString &to)

    Renames the branch from to to (RENAME); the current branch follows.

    void ProjectHistory::restart(const QString &branch)

    Makes branch the one snapshots go to, as a new trail: what it held is dropped (NEW).

    void ProjectHistory::setEnabled(bool enabled)

    Switches the timeline on or off (enabled; main() follows UserProfile::timeline): off, entries empties and nothing is written; on again, the branch open is listed.

    See also enabled().

    void ProjectHistory::setLimits(const ProjectHistory::Limits &limits)

    Sets the limits a tidy keeps to (limits; the defaults otherwise), for the tests.

    void ProjectHistory::snapshot(const QVariantMap &state, const QString &kind, const QStringList &changed, const QString &title = QString())

    Adds state as a snapshot of the current branch, of the kind change (what settled after an edit), save, open, new or restore, with changed naming what changed (changedKeys(); for a restore, the time gone back to in seconds since the epoch), and the user's title for it (a named SAVE; tidyTitle()), kept as a line of its own in the message. A change, open or new whose state equals the last snapshot's is not written. Asynchronous: the snapshot reaches entries when written.

    [signal] void ProjectHistory::snapshotted(const QVariantMap &entry)

    Emitted when a snapshot was written, with its entry as entries carries it.

    QVariantMap ProjectHistory::stateAt(const QString &id) const

    Returns the state the snapshot id holds, read now on the calling thread (it waits for a write under way); empty when there is no such snapshot.

    void ProjectHistory::sweep(const QStringList &keep)

    Drops the trails of projects that are gone: every branch of a project (p/ or n/) not among keep (the branches of the files there are, Projects' at start); the demos' and the unsaved session's stay. The store is tidied after a sweep that dropped something.

    void ProjectHistory::switchTo(const QString &branch)

    Makes branch the one snapshots go to, and lists its snapshots (entries follows, from the worker).

    void ProjectHistory::tidy()

    Tidies the current branch's trail after a manual SAVE (Projects): held to the limit (the newest Limits::kept snapshots, every SAVE and named one before them), and the store packed when it cut something or past Limits::loose loose objects, in process at idle priority. While the transport plays (holdHousekeeping()) it waits for the stop.

    [static] QString ProjectHistory::tidyTitle(const QString &title)

    Returns title as a snapshot keeps it: on one line, the spaces around it trimmed, at most 40 characters.

    [invokable] qint64 ProjectHistory::timeOf(const QString &id) const

    Returns when the snapshot id among entries was taken (seconds since the epoch), or 0 when it is not listed.

    Note: This function can be invoked via the meta-object system and from QML. See Q_INVOKABLE.

    [static] QString ProjectHistory::unsavedBranch()

    Returns the branch of the session never saved.

    [static] QString ProjectHistory::when(qint64 time)

    Returns time (seconds since the epoch) as the timeline shows it: the time of day today (hh:mm:ss), the date before it on another day.
