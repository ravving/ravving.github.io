    Detailed Description

    The style's ComboBox (Ravving.Style: Button's background, font, colour and margins, so it looks like every other button, a down-arrow at its end) whose list opens as one of ravving's dialogs, and which does not move the focus away for good when opened. The style's plain list stays empty while this dialog is the popup in use.

    The list is a popup centred on the screen, on the dialog card (Dialog's look), headed by title and the key hint like ChoicePopup, with rows tall enough for a finger (rowHeight) and large text; the item in use is marked in the accent, the highlighted one (the hardware cursor) carries the accent tint, and it scrolls when the list is long (the scales).

    A tap leaves the focus where it was (a page, the header) until the list opens; the list then takes it, so while open ▲ ▼ ◀ ▶ and the big knob move the highlight, SELECT picks the highlighted item (activated, as a tap on it would) and closes the list, and BACK closes it without a change. Closing it, either way, gives the focus back to whatever had it. The page behind dims while it is open, as behind every dialog (a ModalDim under the list).

    Property Documentation

    accent : color

    The accent of the marks in the list (the item in use, the cursor). With none given, the skin's accent, when there is one.

    focusBefore : Item

    What had the focus before the list opened, to get it back on close.

    listWidth : int

    The list's width (the dialog is wider than the button, so long names fit).

    rowFontSize : int

    Height of a row in the list, and its text size.

    rowHeight : int

    Height of a row in the list, and its text size.

    title : string

    The list's heading (what is being chosen: ROOT, SCALE…), "" for none.

    Method Documentation

    chooseHighlighted()

    Pick the highlighted item, as a tap on it does, and close the list.

    moveHighlight(delta)

    Move the highlight in the open list by delta items (staying inside it).
