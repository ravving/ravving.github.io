    Detailed Description

    A black glass tile with the instrument's name (BASS, DRUMS 1) lit in the machine's colour, in the display face (Theme.displayFamily, the device's key-legend face), and under it, small, what it plays now: the kit, the soundfont or the engine (subtitle). Drawn in QML (no image assets), with the glow faked by a stack of offset copies so it needs no effects module. The name keeps to one line and shrinks to fit; without a subtitle it may take two. When clickable, a tap emits clicked and a double tap doubleClicked (the drums open their kit picker, and go back to the default kit). A single tap waits out the double-tap interval, so a double tap never also counts as a tap.

    Property Documentation

    clickable : bool

    Whether the plate reacts to taps.

    neon : color

    The neon colour. With none given, the skin's accent, when there is one.

    subtitle : string

    What the instrument plays now, small under the name (a kit, a soundfont, an engine); "" for none.

    text : string

    The instrument's name ("BASS", "DRUMS 1"). Without a subtitle, a "\n" forces a line break, otherwise the last word goes below.

    Signal Documentation

    clicked()

    Tapped (only when clickable).

    Note: The corresponding handler is onClicked.

    doubleClicked()

    Double tapped (only when clickable).

    Note: The corresponding handler is onDoubleClicked.
