    Detailed Description

    A modal popup centred on the window (lifted above the on-screen keyboard while it is up) over the darkened page (ModalDim), on ravving's dialog card (a dark gradient, a hairline border, round corners). While open its contentItem has the focus, so it takes the device keys; closing gives the focus back to whatever had it.

    A dialog sets its size and contentItem (a FocusScope holding its Hardware handlers, headed by a DialogHeader), and may add its own onAboutToShow / onClosed: these run after the base's.

    While the on-screen keyboard is up the dialog is modeless: a modal popup's overlay takes every press outside the popup before it reaches the keyboard (QQuickOverlay blocks input to anything but the popup's own children, the InputPanel included, which sits in the same overlay), so keys needed several taps. Modeless, the keyboard's keys get each tap; the dimmer (the style's) still covers the page and swallows the presses on it.

    Property Documentation

    focusBefore : Item

    What had the focus before it opened, to get it back on close.

    hint : string

    What the device keys do here, shown along the dialog's bottom edge.

    Method Documentation

    canBeSeen(item)

    Returns whether item and all its ancestors are visible (a hidden drawer's child is not).
