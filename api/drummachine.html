    Detailed Description

    data/kits.json gives it its track, Zynthian channel, engine and default preset; its presets are the drum PresetLibrary the drum machines share, written per role so any preset plays on any kit. Its rows come from its kit, a soundfont read by DrumKit: eight roles (KICK to PERC), each with the kit's note for it. loadKit() switches kits and moves every hit to the new kit's note for the same role, so a pattern survives any kit change. A hit is a subnote with the row's note on that step; without libzynthbox (a desktop run) the steps are kept in memory.

    Each row has a level, a mute and a solo, kept per role so they survive kit changes. They are applied through the hits' velocities: a row's level and a step's accent give the velocity every hit of that row is written with, and -1 (PatternModel's "do not play") marks a muted row, an unsoloed one while any row is soloed, or one the kick cut silences (Machine::setKickMode()). Accents are kept by the machine, not read back from velocities. A live key is a row.

    The QML step grid uses rows, steps, accents, the per-row mix, toggleStep(), toggleAccent(), setRowLevel(), setRowMuted(), setRowSoloed() and audition(), with Machine's playhead, bars, presets and clear().

    DrumMachine::DrumMachine(const QVariantMap &config, const QVariantMap &state, PresetLibrary *presets, GlobalEffects *globalEffects, QObject *parent = nullptr)
