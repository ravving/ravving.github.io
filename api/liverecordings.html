    Detailed Description

    They are kept in one of two places (InputRecorder::keepIn): samples (Paths::liveRecordings(), in the sample library) or tracks (Paths::recordings(), beside the master's recordings in the music library). Both folders are watched, so a file copied in from elsewhere appears. rename(), remove(), move() (to the other place) and edit() (the window of a recording, normalised or not, written as a new recording beside it on a worker thread: AudioFile::writeWindow()) are here; playing one is Studio::previewSample().

    Member Function Documentation

    [explicit] LiveRecordings::LiveRecordings(QObject *parent = nullptr)

    Reads both folders and starts watching them, with the given parent.

    [invokable] void LiveRecordings::edit(const QString &path, qreal start, qreal end, bool normalise)

    Writes start .. end (fractions of the file) of the recording at path as a new one, "<name> edit" beside it, normalised to -1 dBFS when normalise is true, in a worker thread; edited() follows.

    Note: This function can be invoked via the meta-object system and from QML. See Q_INVOKABLE.

    [signal] void LiveRecordings::edited(const QString &file)

    Emitted when edit() wrote the new recording file; empty on failure.

    [static] QString LiveRecordings::folderOf(const QString &place)

    Returns the folder of place; empty for an unknown place.

    [invokable] QString LiveRecordings::move(const QString &path, const QString &place)

    Moves the recording at path to place (samples or tracks). Returns the new path, or an empty string on failure.

    Note: This function can be invoked via the meta-object system and from QML. See Q_INVOKABLE.

    [static] QStringList LiveRecordings::places()

    Returns the places a recording is kept: samples and tracks.

    [invokable] void LiveRecordings::refresh()

    Reads the folders again; the watcher does it on its own, so this is for scripts.

    Note: This function can be invoked via the meta-object system and from QML. See Q_INVOKABLE.

    [invokable] bool LiveRecordings::remove(const QString &path)

    Deletes the recording at path. Returns false when it is not a recording or cannot be deleted.

    Note: This function can be invoked via the meta-object system and from QML. See Q_INVOKABLE.

    [invokable] QString LiveRecordings::rename(const QString &path, const QString &name)

    Gives the recording at path the new name (it keeps its folder and type). Returns the new path, or an empty string when the name is empty or taken, the file is not a recording or it cannot be moved.

    Note: This function can be invoked via the meta-object system and from QML. See Q_INVOKABLE.
