    Detailed Description

    Published to QML as machine.sound, with the same store interface as TrackEffects (values and setValue()). The cards are data: each engine's profile in data/engines.json (EngineProfiles):

    
 "sound": [ { "title": "FILTER", "knobs": [
     { "name": "CUTOFF", "symbol": "cutoff", "min": 0, "max": 100, "default": 0.3 } ] },
   { "title": "WAVE", "knobs": [ { "name": "WAVE", "default": 0, "choices": [
     { "label": "SAW", "controls": { "osc1waveform": 0, "osc1pw": 0.5 } },
     { "label": "SQR", "controls": { "osc1waveform": 0.5, "osc1pw": 0.5 } } ] } ] } ]

    Knob values are 0..1 everywhere. A knob maps its value onto min .. max of its symbol, linearly, or with "curve": "log" exponentially (min × (max / min)^value, for ports an engine treats as logarithmic, such as Calf's cutoff, envelope times and portamento; min must be above 0). A knob with choices is a switch (a waveform, a mode): its value snaps to choice i of n at i / (n - 1), and each choice sets its controls (several ports at once; every choice should name the same ports), or just its value on the knob's symbol. The values are saved with the machine and sent to the engine on every change (controlChanged()) and whenever it starts (engineControls()). GUI thread only.

    Member Function Documentation

    [explicit] SoundControls::SoundControls(const QVariantList &config, const QVariantMap &startControls = {}, QObject *parent = nullptr)

    Builds the cards from config, the cards of an engine's profile, with the given parent. A knob on one of the source's own engine controls, startControls (kits.json's engine.controls), starts where the source puts it, read back through its mapping as adopt() does; any other starts at the profile's default.

    void SoundControls::adopt(const QVariantMap &engineValues)

    Adopts the values the engine took, engineValues (symbol to value, as when a sound preset is loaded): each knob reads them back through its mapping (a switch takes the nearest choice). Nothing is sent to the engine. Values outside a knob's range are clamped to its ends.

    [signal] void SoundControls::controlChanged(const QString &symbol, double value)

    Emitted with the engine control symbol's new value, in the engine's units.

    QVariantMap SoundControls::engineControls() const

    Returns every control at its current value, in the engine's units (symbol to value).

    bool SoundControls::has(const QString &cardKnob) const

    Returns whether it has the knob cardKnob, written CARD/KNOB (an automation lane's, a saved value's).

    QStringList SoundControls::restore(const QVariantMap &state)

    Restores the saved state, replacing the current values (missing knobs return to their defaults), and sends every control to the engine again (controlChanged()). Returns the saved knobs that do not exist; they are dropped.

    [invokable] void SoundControls::setValue(const QString &card, const QString &knob, double value)

    Sets knob of card to value (clamped to 0..1, snapped to a choice for a switch) and sends what it drives to the engine (controlChanged()). Unknown knobs are ignored.

    Note: This function can be invoked via the meta-object system and from QML. See Q_INVOKABLE.

    QVariantMap SoundControls::state() const

    Returns what the project keeps: CARD/KNOB to 0..1.

    QStringList SoundControls::symbols() const

    Returns every engine control a knob drives (a switch's choices' too), sorted, for checking against the engine's ports.

    [signal] void SoundControls::valueSet(const QString &card, const QString &knob, double value)

    Emitted when knob of card was set to value (0..1) through setValue(), by the user or by automation.
