    Detailed Description

    It is fed the notes sent (expect(): when, on which channel, how loud) and the track's meter readings (level(): libravving's per-track peak, about 20 a second). A note is heard when the meter reaches HeardDb (-70 dBFS) from LeadMs before it until WindowMs after it: the step the note was told of may lag the audio, and a sample's sound may start late. A note under AudibleVelocity is not counted. Sound that shows while notes wait clears them all: a track's meter cannot tell its notes apart, so only notes nothing else covers can be found silent.

    SilentNotes notes (2) whose windows pass in silence within SilentWithinMs (4 s), with nothing heard between, are a silent engine: level() says Silent once, with the channels those notes were on (channels()), and at most once every RepairGapMs (30 s) while it stays silent. The next note heard after that says Sounding. One silent note proves little (a sample that starts with silence, a quiet hit between two meter readings); two in a row at audible velocities, with a meter that shows -70 dBFS, are what an engine with a broken channel does.

    Plain logic with times in milliseconds from any clock that only goes forward; no engine, no meter, no timer of its own (EngineWatch feeds it).

    Member Function Documentation

    QList<int> SilenceWatch::channels() const

    Returns the channels of the silent notes behind the last Silent, in order.

    void SilenceWatch::expect(qint64 ms, int channel, int velocity)

    Counts a note sent at ms on channel at velocity: one under AudibleVelocity is ignored, and one whose sound already showed (LeadMs before it) is heard at once.

    SilenceWatch::Verdict SilenceWatch::level(qint64 ms, float peakDb)

    Takes the track's meter reading peakDb (dBFS, -200 for silence) at ms and returns what it tells: Sounding when it is sound, notes wait and the engine was found silent; Silent when the notes whose windows ended in silence add up to SilentNotes within SilentWithinMs and the last Silent is RepairGapMs back; else Nothing.

    int SilenceWatch::repairs() const

    Returns how many Silent verdicts came since a note was last heard after one: 1 for the first, more when a reload did not bring the sound back.

    bool SilenceWatch::silent() const

    Returns whether the engine was found silent (Silent) and no note was heard since.

    bool SilenceWatch::waiting() const

    Returns whether notes wait for their sound: the meter needs reading until they are heard or their window passes.
