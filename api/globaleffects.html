    Detailed Description

    TrackEffects sets how much each machine sends. One of each for the whole studio saves CPU for the machines, so their own knobs (REVERB SIZE, DELAY TIME and FDBK, the chain's shared knobs, EffectChain) are the same on every machine:

    • reverb: Dragonfly Room Reverb (wet only); SIZE sets the room size and the decay;
    • delay: TAP Stereo Echo (wet only); TIME picks a note length that follows the tempo (1/16, 1/8, dotted 1/8, 1/4, dotted 1/4, 1/2), FDBK the feedback.

    Each runs in jalv (JalvPlugin). Without libzynthbox (a desktop run) no process starts and the knobs only keep their values. GUI thread only.
