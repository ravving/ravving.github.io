    Member Function Documentation

    [virtual constexpr noexcept default] Host::~Host()

    Destroys the instance of Host. This destructor is virtual.

    [pure virtual] bool Host::applyMachines(const QVariantMap &machines, int bars)

    Gives the machines their content from machines (a machine left out gets an empty pattern) in a section bars long (the length a machine with Machine::once plays, then rests through): at once when stopped, else on the next bar. Returns true when it waits for the bar; Sections::switchLanded() then reports the arrival.

    [pure virtual] int Host::barsOf(const QVariantMap &machines) const

    Returns the longest pattern among the machines that sound in machines; 1 when none does.

    [pure virtual] QVariantMap Host::captureMachines() const

    Returns every machine's section content as it is now, as a map of machine key to content.

    [pure virtual] void Host::setSpan(int bars)

    Tells the machines the current section is now bars long (its length set, or its automatic length measured again); machines with Machine::once play that long from now.

    [pure virtual] QStringList Host::soundingIn(const QVariantMap &machines) const

    Returns the keys of the machines that sound in machines.

    [pure virtual] void Host::startPlayback()

    Starts the transport, the song from the top.

    [pure virtual] void Host::stopAtBarEnd()

    Stops the transport at the end of the bar playing: every clip silent from the next bar, then the transport stopped.
