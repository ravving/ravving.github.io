    Detailed Description

    It has the same store interface as SoundControls and TrackEffects (cards, values, setValue()):

    CardKnobs
    KITVOLUME (the kit's level, Machine::level), SEMI and FINE (a tune added to every pad: ±24 semitones, ±90 cents)
    16 LEVELSTYPE: VELOCITY (the pads play the source pad softer to harder), TUNE (a semitone per pad, the original pitch on pad 4) or SCALE (the pads follow the key, pad 4 the root); and LEVELS, the switch itself

    Every value is 0..1 (switch knobs snap to their choices); PadSamplerMachine maps them. The values are the machine's: it saves them, and this object only holds the cards and reports what changed.
