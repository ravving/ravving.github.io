    Detailed Description

    Lights in onColor when checked; dimmed while disabled (an option that doesn't apply now).

    Property Documentation

    fontSize : int

    Show the LED dot before the text.

    held : bool

    The device key this chip stands for is held (ravving.heldKeys): shown pressed.

    ink : color

    Text colour when unchecked (match the surface the chip sits on). With none given, the skin's ink, when there is one.

    knobBadge : int

    The device knob driving this chip (0–2 small, 3 big), or -1: shows the KnobBadge.

    navHighlighted : bool

    KnobGroup nav item API: highlighted by the group's nav knob (navKnob, set by the group), its place in the list (0..1).

    navKnob : int

    KnobGroup nav item API: highlighted by the group's nav knob (navKnob, set by the group), its place in the list (0..1).

    navPosition : real

    The device knob driving this chip (0–2 small, 3 big), or -1: shows the KnobBadge.

    offFill : color

    Fill when unchecked.

    onColor : color

    Fill when checked. With none given, the skin's accent, when there is one.

    showLed : bool

    Show the LED dot before the text.

    Method Documentation

    activate()

    SELECT on the highlighted chip: the same as a tap. (A chip whose checked is bound to outside state should set checkable: false and change that state in onClicked.)
