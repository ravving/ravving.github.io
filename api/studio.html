    Detailed Description

    It builds every machine from data/kits.json (with the kit the project last chose for it, and its sound controls from EngineProfiles) and gives each its sketchpad track (a SketchpadTrack), its PatternModels (clips a and b of that track in libzynthbox's global sequence), its sound engine (SoundEngine) and its wiring (JackWiring). It owns the objects QML reaches through it: the take recorder, the mix recorder, the input, the MIDI input, the live effects, the sections, the projects, the templates, the history, the exporter and the music player.

    The session is everything projectState() returns: every machine's steps, sound, kit, effects and level, the send effects, tempo, swing, master, metronome, the live effects, the sections, and the UI's values (uiValue()). It is written to session.json in the project folder 1.5 s after the last change and restored at start. Projects saves and opens named copies of it.

    Transport: play() and stop() drive libzynthbox's sequence (SyncTimer underneath); the tempo is SyncTimer's; swing is applied to every machine's pattern. The studio is the Sections::Host: on the bar line it switches the machines' clips to the cued section. Without libzynthbox (a desktop run) a timer stands in for the clock, with no sound. GUI thread only.

    Member Function Documentation

    Studio::Studio(ZynthboxBridge *zynthbox, const QString &kitsFile, const QString &projectDir, const QString &projectsDir, QObject *parent = nullptr)

    Builds the studio from kitsFile (kits.json) over zynthbox, the libzynthbox bridge (already started, or unavailable), restoring the session saved in projectDir (which holds the session and libzynthbox's sequence) and keeping named projects in projectsDir (Projects). parent is the QObject parent.

    [invokable] void Studio::allNotesOff()

    Silences every machine's engine (Machine::silence()), to end stuck notes.

    Note: This function can be invoked via the meta-object system and from QML. See Q_INVOKABLE.

    void Studio::applyProjectState(const QVariantMap &state)

    Replaces the session with state while running (an empty map restores the defaults); the history is cleared and uiRestored() is emitted. What the project names but this device lacks is reported as one issue (ProjectCheck).

    QVariantMap Studio::cleanProjectState(const QVariantMap &settings) const

    Returns the state of a new project: settings (a template's tempo, swing, key and live effects, or nothing) with every machine marked clean, so each starts with an empty pattern, its own engine and the default sound, mix and effects.

    QString Studio::inputPortsCard() const

    Returns the sound card whose capture ports are the input jacks (kits.json's input portsCard, found by HardwarePorts::captureOf()); empty without an input.

    [signal] void Studio::loadingChanged()

    Emitted when loadingEngines, loadingDone or loadingTotal changed.

    Note: Notifier signal for properties loadingDone, loadingEngines, and loadingTotal.

    QList<Machine *> Studio::machineList() const

    Returns every machine, in kits.json's order.

    QStringList Studio::masterOutputPorts() const

    Returns the master's own output ports, after its inserts.

    [invokable] QVariantMap Studio::meters() const

    Returns the current peak meters: tracks, each sketchpad track's peak in dB (10 of them, -200 for silence), and master. Read on demand from libzynthbox's AudioLevels.

    Note: This function can be invoked via the meta-object system and from QML. See Q_INVOKABLE.

    [signal] void Studio::modified()

    Emitted when something the session keeps changes; the session is saved shortly after.

    [invokable] void Studio::play()

    Starts the transport; does nothing while it runs. In Song mode the first entry's section is put in place first (Sections::songStarting()).

    Note: This function can be invoked via the meta-object system and from QML. See Q_INVOKABLE.

    [invokable] void Studio::previewSample(const QString &path)

    Plays the sample file at path once, on the global sampler lane straight to the master; a new preview stops the one playing.

    Note: This function can be invoked via the meta-object system and from QML. See Q_INVOKABLE.

    QVariantMap Studio::projectState() const

    Returns everything the session keeps, as one map: a project file's contents.

    [invokable] QString Studio::randomName() const

    Returns a random "adjective-noun" name from libzynthbox's AdjectiveNoun, for an unnamed project or recording.

    Note: This function can be invoked via the meta-object system and from QML. See Q_INVOKABLE.

    [invokable] void Studio::refreshImported()

    Rescans the library's soundfonts: those that look like drum kits join availableKits (marked imported), and every font's presets become sources ("<font> · <preset>", grouped by font) of the machines that take imported sources (Machine::setImportedSources()).

    Note: This function can be invoked via the meta-object system and from QML. See Q_INVOKABLE.

    [invokable] QVariantList Studio::sampleFiles() const

    Returns the sample files the sampler can load: every audio file under kits.json's sampleFolders, as maps with name, path and folder, sorted by folder then name.

    Note: This function can be invoked via the meta-object system and from QML. See Q_INVOKABLE.

    void Studio::saveNow()

    Writes the session now, without waiting for the delayed save; called at shutdown.

    QVariantMap Studio::savedSession() const

    Returns the session file's contents as the last run left it; a legacy machines.json is read the same way.

    void Studio::setSpeakersEnabled(bool enabled)

    Keeps the master's links to the speakers when enabled is true, or removes them (JackWiring::setSpeakersEnabled()), so AudioOutputs can route the master to another sink.

    [invokable] void Studio::setUiValue(const QString &key, const QVariant &value)

    Sets the UI value key to value; it is saved with the session and with a project.

    Note: This function can be invoked via the meta-object system and from QML. See Q_INVOKABLE.

    [invokable] void Studio::stop()

    [invokable] void Studio::stopPreview()

    Templates *Studio::templateLibrary() const

    [invokable] void Studio::togglePlay()

    [signal] void Studio::uiRestored()

    [invokable] QVariant Studio::uiValue(const QString &key, const QVariant &fallback = {}) const

    Returns the UI value key saved with the session, or fallback when it has none. From QML, supply the fallback with ?? instead: a JS object does not convert to it.
