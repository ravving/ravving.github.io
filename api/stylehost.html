    Detailed Description

    qml-style-zynthbox reads a global context property named zynqtgui and uses three of its members: displayHeightRatio, the base size unit, and pushDialog() / popDialog(), the stack of open dialogs, so the hardware keys reach the topmost one (openedDialog).

    Property Documentation

    [read-only] displayHeightRatio : const qreal

    This property holds the base size unit in pixels: the primary screen's height times 24/800 (24 px on the 800 px-high screen); 24 without a screen.

    Access functions:

    qreal displayHeightRatio() const

    [read-only] openedDialog : QObject*

    This property holds the topmost open dialog, or null when none is open.

    [invokable] void StyleHost::popDialog(QObject *dialog)

    Removes dialog from the dialog stack (a warning is logged when it was not the topmost), along with entries whose dialogs were destroyed; the one under it becomes openedDialog. Ignored when dialog is not on the stack.

    Note: This function can be invoked via the meta-object system and from QML. See Q_INVOKABLE.

    [invokable] void StyleHost::pushDialog(QObject *dialog)

    Puts dialog on top of the dialog stack; ignored when null.

    Note: This function can be invoked via the meta-object system and from QML. See Q_INVOKABLE.
