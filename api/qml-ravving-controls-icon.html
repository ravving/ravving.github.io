    Icon QML Type

    One of ravving's UI icons: a 1-bit pixel drawing from the icon set picked (Theme.iconSet: a built-in set or a user's icon pack), crisp at any size, in any colour. More...

    Import Statement: import Ravving.Controls 1.0
    • List of all members, including inherited members

    Properties

    • color : color
    • name : string
    • size : int

    Detailed Description

    The sets are SVG files in assets/icons/<set>/<name>.svg (tools/icons/make-icons.py writes them), drawn by IconProvider at the largest whole scale that fits size and centred, so a pixel never blurs. Names: play, pause, stop, record, skip-back, skip-next, metronome, metronome-tock, loop, follow, undo, redo, plus, minus, close, clear, check, refresh, more, favourite, dot, radio, alert, chevron-left/right, caret-up/down/left/right, dropdown, arrow-up/down/left/right, key-star, note, note-on, the waves (wave-saw, wave-square, wave-triangle, wave-sine), busy-1 to busy-4, the system's (wifi, bluetooth, brightness, volume, mixer, midi, cpu, lock, unlock, eye, usb, get-more, settings, video, folder, computer, power, info, fx, mic, keys, profile, phone, headphones), the actions' (delete, save, rename, send, import, export), the pages' (drums, chords, bass, lead, sampler, song, player) and sun, moon, menu, globe, heart. A button shows one with icon.source: Interaction.icon(name); a hint names the device's keys with Interaction.withIcons().

    Property Documentation

    color : color

    The icon's name (one of those listed above), its colour (with none given, the skin's ink, when there is one), and its square's side in pixels: 16 shows a 16-pixel set at its own size, 32 at twice.
