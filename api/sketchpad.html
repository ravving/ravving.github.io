    Detailed Description

    Starting playback resets every clip to stopped, so startPlayback() launches the clip each playing track uses before the transport starts (Studio::play()).

    A track plays clip a or clip b: Sections writes the coming section into the one that is not playing and has the two swap on the next bar (switchClips()), which the playfield does on the bar's first tick, before any pattern schedules a note of it.

    void Sketchpad::setTrackPaused(int track, bool paused)

    Leaves track's clip out of playback when paused is true (it stops now and is not launched on a start), or brings it back from the next bar; Machine::paused uses it.

    void Sketchpad::startPlayback()

    Launches the clip each playing track uses from the first bar, unless the track is paused; called before the transport starts.

    void Sketchpad::stopAllAtNextBar()

    Stops every playing track's clip on the next bar (at a song's end: nothing of the following bar sounds, then the transport stops).

    int Sketchpad::switchClips(const QList<Sketchpad::TrackCue> &cues)

    Cues cues together: from the next bar each track plays its cue's clip (nothing when the cue is paused) and its other clip stops. The set is applied on the clock's own thread in one step, on the first bar line it has not processed yet, and clipSwitchLanded() reports it; the returned id names it (0 for an empty set).

    int Sketchpad::trackClip(int track) const

    Returns the clip track plays from: 0 for clip a, 1 for clip b.
