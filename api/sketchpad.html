    Detailed Description

    SyncTimer calls into this object whenever the transport starts and stops (it reads clipToRecord and isRecording, and calls startPlayback(), stopAllPlayback() and stopRecording()), and PlayGridManager follows selectedTrackId. This class provides only the members libzynthbox uses.

    Starting playback resets every clip to stopped, so startPlayback() launches the clip each playing track uses (PlayfieldManager::setClipPlaystate()).

    A track plays clip a or clip b: Sections writes the coming section into the one that is not playing and has the two swap on the next bar (cueTrackClip()), which the playfield does on the bar's first tick, before any pattern schedules a note of it. The paused tracks and the tracks on clip b are kept in atomics, since startPlayback() reads them on the audio thread.

    [signal] void Sketchpad::isLoadingChanged()

    Emitted around project loads; PlayfieldManager listens.

    void Sketchpad::setPlayingTracks(const QList<int> &tracks)

    Sets the sketchpad tracks whose clip plays whenever the transport starts.

    void Sketchpad::setTrackPaused(int track, bool paused)

    Leaves track's clip out of playback when paused is true (it stops now and is not launched on a start), or brings it back from the next bar; Machine::paused uses it.

    [invokable] void Sketchpad::startPlayback()

    SyncTimer's start hook, called on the audio thread: launches the clip each playing track uses, unless the track is paused. Reads only atomics.

    Note: This function can be invoked via the meta-object system and from QML. See Q_INVOKABLE.

    void Sketchpad::stopAllAtNextBar()

    Stops every playing track's clip on the next bar (at a song's end: nothing of the following bar sounds, then the transport stops).

    [invokable] void Sketchpad::stopAllPlayback()

    SyncTimer's stop hook.

    Note: This function can be invoked via the meta-object system and from QML. See Q_INVOKABLE.

    [invokable] void Sketchpad::stopRecording()

    SyncTimer's hook for ending a clip recording; nothing to do.

    Note: This function can be invoked via the meta-object system and from QML. See Q_INVOKABLE.

    int Sketchpad::trackClip(int track) const

    Returns the clip track plays from: 0 for clip a, 1 for clip b.
