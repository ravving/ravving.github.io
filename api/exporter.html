    Detailed Description

    A track is the whole production as it sounds through the speakers. The master (GlobalPlayback: every machine, its effects, the sends and the master inserts) is recorded through libzynthbox's AudioLevels while the transport plays the project from its first beat for bars × loops bars, plus a tail in seconds for the echoes to die away (in Song mode, the whole song). The recording is cut sample-accurately: it starts at a known frame of the audio clock (LiveFx::audioFrame(), the beat repeat's JACK client) a moment before playback, the frame SyncTimer began playback at is where the track starts, it lasts exactly the bars at the project's tempo, and the tail is faded (AudioFile::writeCut()). It is written at the engine's sample rate in the chosen format with nothing else done to it, except that a peak over full scale pulls the file down to -0.1 dBFS. The file carries its metadata as tags (ID3v2 and RIFF INFO for WAV; title, artist, album or mixtape, genre, composer, comment, date, BPM) and its cover (AlbumArt, also saved as a PNG beside it), plus a JSON sidecar with the same and the project's name, tempo, key and length. The music player is stopped first and the metronome switched off for the recording, then restored.

    A bundle is the project as another device can play it: project.json (the session state, Studio::projectState(), with every sample it refers to rewritten to samples/<file> inside the bundle), the samples themselves (whatever is not part of every Zynthbox image, so not under /zynthian/zynthian-data or /usr), metadata.json (the user metadata, the ravving version, the date) and cover.png, in one zip (ZipWriter). importProject() unpacks a bundle (its samples into samples/imported/<name>/) into a new project.

    exportAudio(), finishRecording() and exportProject() take the metadata as a map, or as JSON text for scripts, with the keys name (the file name, the project's by default), format (one of formats: wav 24-bit PCM, the default, flac, ogg or mp3), title, artist, album, genre, composer, comment, bars, loops, tail, usb (a stick's partition to copy the files to) and computer (a computer's id to send them to). They run in the background (the file work in a worker thread): busy, phase and progress say where they are, and finished() or failed() end them.

    Exporter::Exporter(Studio *studio, ZynthboxBridge *zynthbox, QObject *parent = nullptr)

    Constructs the exporter of studio, recording through zynthbox's AudioLevels, with the given parent.

    [invokable] void Exporter::cancel()

    Stops a track export while it prepares or records; nothing is written and failed() reports cancelled.

    Note: This function can be invoked via the meta-object system and from QML. See Q_INVOKABLE.

    [signal] void Exporter::copied(const QString &kind, const QString &label, bool ok)

    Emitted when an export's files of kind reached the USB stick named label (ok), or could not be copied there.

    [invokable] qreal Exporter::durationSeconds(int bars, int loops, qreal tail) const

    Returns the length in seconds of a track of bars × loops bars plus tail seconds at the current tempo.

    Note: This function can be invoked via the meta-object system and from QML. See Q_INVOKABLE.

    [invokable] bool Exporter::exportAudio(const QVariant &metadata)

    Starts a track export described by metadata (see the class description). Returns false, after emitting failed(), when it cannot start (busy, no audio engine, the transport unavailable).

    Note: This function can be invoked via the meta-object system and from QML. See Q_INVOKABLE.

    [invokable] bool Exporter::exportProject(const QVariant &metadata)

    Writes the session as a .ravv bundle described by metadata. Returns false, after emitting failed(), when it cannot start.

    Note: This function can be invoked via the meta-object system and from QML. See Q_INVOKABLE.

    [invokable] bool Exporter::exportProjectFile(const QString &projectPath, const QVariant &metadata)

    Writes the saved project at projectPath (its file, not the session) as a .ravv bundle described by metadata: to the stick its usb names, else into the exports folder. Returns false, after emitting failed(), when it cannot start.

    Note: This function can be invoked via the meta-object system and from QML. See Q_INVOKABLE.

    [signal] void Exporter::failed(const QString &kind, const QString &reason)

    Emitted when an export of kind failed, with a translated reason (cancelled for cancel()).

    [invokable] bool Exporter::finishRecording(const QString &rawFile, const QVariant &metadata)

    Finishes an existing recording, rawFile (a WAV), as a track export: written whole in metadata's format under its name in the exports folder (the raw file is removed), tagged, with its cover and sidecar, and copied or sent as the metadata says. busy, phase and finished() work as for exportAudio(), with kind track. Returns false, after emitting failed(), when it cannot start.

    Note: This function can be invoked via the meta-object system and from QML. See Q_INVOKABLE.

    [signal] void Exporter::finished(const QString &kind, const QString &path)

    Emitted when an export of kind ended with its file at path (for an import, the new project's path).

    [invokable] QString Exporter::importProject(const QString &file)

    Unpacks the bundle file into a new project and returns the project's path; returns an empty string, after emitting failed(), on error.

    Note: This function can be invoked via the meta-object system and from QML. See Q_INVOKABLE.

    [invokable] QVariantList Exporter::importable() const

    Returns the .ravv bundles found in the exports folder, the library's root (where received files land) and on every mounted USB stick (its ravving/projects folder and its root), as maps with name, path, title, artist, modified and location (device or the stick's label).

    Note: This function can be invoked via the meta-object system and from QML. See Q_INVOKABLE.

    void Exporter::setComputers(Computers *computers)

    Sets the user's computers: with computer in the metadata, the files are sent to that computer's Downloads folder once written (ComputerLink::sent() reports the result).

    void Exporter::setDrives(RemovableDrives *drives)

    Sets the USB sticks, drives: a destination for exports (usb in the metadata: the files are copied to the stick's ravving/exports or ravving/projects folder once written) and a source of bundles for importable().

    void Exporter::setPlayer(MusicPlayer *player)

    Sets the music player, which is stopped before a recording so its sound does not end up in the track.

    [signal] void Exporter::started(const QString &kind)

    Emitted when an export of kind (track, bundle or import) began.

    [invokable] QString Exporter::suggestedName() const

    Returns the name an export gets without one: the current project's, else "ravving track".

    Note: This function can be invoked via the meta-object system and from QML. See Q_INVOKABLE.
