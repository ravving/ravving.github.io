    LastRun Namespace

    Whether the previous run ended cleanly, reported as an issue at start. More...

    Detailed Description

    ravving leaves a marker while it runs (Paths::state()/running, holding the time it started) and removes it when it leaves cleanly (SIGTERM from systemctl stop, or a normal return); data/start.sh writes how the process ended (Paths::state()/last-exit: <exit code> <time>). A marker found at start means the run before ended some other way:

    • an exit code from a signal (128 + n): it crashed (segmentation fault, abort...) or was killed;
    • another non-zero code: it failed (Qt leaves with 1 when the display server went away);
    • no exit written after the marker: the session around it ended first and start.sh never got to write (the display server stopped).

    The service restarts ravving (Restart=always), so the issue is the only visible trace.

    Function Documentation

    void LastRun::checkAndMark()

    Reports, as the unexpected-exit issue, how the run before ended when it did not end cleanly, then leaves the marker for this run. Called once at start, after Diagnostics exists.

    void LastRun::clean()

    Removes the marker: this run ends cleanly.
