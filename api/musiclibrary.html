    Detailed Description

    They are every exported track in the exports folder (Paths::exports(): WAV, FLAC, Ogg, MP3) and the master's recordings (Paths::recordings(); they carry no tags and are listed under the album "Recordings"). Each track is read once for its tags (TagLib: title, artist, album, genre, composer, year, BPM, length) and its cover (the PNG the export saved beside it, else the picture in its tags, copied once into the cache), with the export's sidecar JSON adding the project it came from. Scans run on a worker thread. The folders are watched, so a new export, or a file copied in from elsewhere, appears without a rescan call.
