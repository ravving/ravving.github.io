    Detailed Description

    A machine edits the notes of its clip through this object, which keeps them as plain values (libravving::Pattern) and answers what is where without asking the library. The edits of one turn of the event loop go out together, in one libravving::Sequencer::setPattern() call, which rewrites only the steps that changed; publish() sends them at once (the studio does before a clip switch and before playing, so the sequencer has them by the bar).

    Positions count steps from the pattern's start, 16 a bar. GUI thread only.
