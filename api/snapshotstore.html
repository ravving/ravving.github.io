    Detailed Description

    A store is a set of named branches, each a chain of snapshots; a snapshot is one file (FileName, a project's JSON) with a message and a time, pointing at the snapshot before it. That is a git repository's shape, and both backends write one, in the same format, so the same folder is read by either and by git itself: LibGit2SnapshotStore (through libgit2, the default when built in) and GitCommandSnapshotStore (through git processes). create() picks one; the variable RAVVING_SNAPSHOT_STORE (libgit2 or git) overrides the choice.

    The contract every backend keeps:

    • open() makes the store (an empty folder becomes a repository) or finds it; every other call needs it to have succeeded.
    • Branch names are the caller's (ProjectHistory::branchFor() keeps them valid); refName() is their full form.
    • write() adds a snapshot on top of parent (the branch's tip as the caller last saw it, empty for a branch that does not exist yet) and moves the branch to it. When the branch is not where parent says, nothing is written and it fails: the caller reads the tip again. No other reference is touched.
    • list() and tip() give the newest first; read() gives the file of one snapshot by its id (a full id, or a unique prefix).
    • point(), rename() and remove() move, rename and delete a branch; a branch that does not exist is a failure for rename(), nothing for remove(). branches() names them all.
    • A store is used by one thread at a time; the caller serialises (ProjectHistory's worker holds a lock around every call).
    • A failing call leaves the store as it was and says why in lastError(); nothing throws.

    Returns the store for the repository folder dir, with the backend named backend (backends()), else the one RAVVING_SNAPSHOT_STORE names, else the first of backends() that can work here (libgit2 when built in, git when the program is on the PATH). Not yet opened. Null when none can.

    [pure virtual] QString SnapshotStore::directory() const

    Returns the repository folder.

    [virtual] void SnapshotStore::housekeep()

    Tidies the store: packs what is loose, drops what no branch reaches. Nothing by default; a backend that can does. The caller decides when (ProjectHistory: past a number of loose objects, with the device quiet).

    QString SnapshotStore::lastError() const

    Returns why the last call failed; empty when it did not.

    Returns the newest limit snapshots of branch, newest first; empty when the branch does not exist.

    [pure virtual] QByteArray SnapshotStore::read(const QString &id)

    Returns the file the snapshot id holds; empty when there is no such snapshot.

    [static] QString SnapshotStore::refName(const QString &branch)

    Returns the full reference name of branch (refs/heads/<branch>).

    [virtual] bool SnapshotStore::relink(const QString &branch, const QList<Snapshot> &kept, const QString &tip)

    Makes branch the chain of the snapshots kept (oldest first), each with its own file, message and time, the others left out (ProjectHistory's limit), if the branch is still at tip. Returns whether it did; the snapshots left out reach nothing after, for housekeep() to drop. This one writes each kept snapshot again through write() on a branch of its own, then points branch at the last; a backend that can link the snapshots as they are does so instead.

    [pure virtual] bool SnapshotStore::remove(const QString &branch)

    Deletes branch (its snapshots stay in the store until housekeeping drops what no branch reaches). Returns whether it did, or the branch did not exist.

    [pure virtual] bool SnapshotStore::rename(const QString &from, const QString &to)

    Renames the branch from to to (written over). Returns whether it did.

    [pure virtual] std::optional<Snapshot> SnapshotStore::tip(const QString &branch)

    Returns the newest snapshot of branch, or nothing when the branch does not exist.

    [pure virtual] std::optional<Snapshot> SnapshotStore::write(const QString &branch, const QByteArray &content, const QString &message, const QString &parent, qint64 time)

    Writes content as a snapshot of branch at time (seconds since the epoch) with message, on top of parent (the branch's tip; empty when the branch does not exist yet), and moves the branch to it. Returns the snapshot written, or nothing when the branch was not at parent or the write failed (lastError()).
