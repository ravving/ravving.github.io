    Detailed Description

    Every kit maps its sounds to different keys (the TR909 soundfont has its clap on 50, the LINN9000 on 39), so ravving keeps no note maps by hand: it reads the sample name of every key of the kit's preset and gives each of eight fixed roles (KICK, SNARE, CLAP, TOM, HAT, OPEN, CYMBAL, PERC) the key whose sample name says so. A role the kit does not have (the TR727 has no kick) is left out: its row has no note and plays nothing, rather than another sound under a wrong name. A pattern's hits follow their role, so a kit switch only moves each hit to the new kit's key for the same role.

    A kit is named by its soundfont's path, or by a path and one of its presets, <file>#<bank>:<program>: a General MIDI font's kits sit among its instruments at bank 128 (FluidR3Mono_GM.sf3#128:32 is its Jazz kit) and keep the GM map, so a key whose name says nothing plays its GM role. After the preset, a path may choose a row's key itself: #128:32?CYMBAL=51&HAT=44 is that kit with its ride and hi-hat foot. A plain value type; reading a kit reads the file (SoundFontFile).

    Member Function Documentation

    int DrumKit::bank() const

    Returns the bank of the kit's preset (what FluidSynth selects): the one its path names, else the first preset's.

    QString DrumKit::file() const

    Returns the kit's soundfont file.

    [static] QString DrumKit::fileOf(const QString &path)

    Returns the soundfont file of a kit's path: the path without its #bank:program and key choices.

    [static] DrumKit DrumKit::fromSoundfont(const QString &path)

    Reads the kit at path: a soundfont file, or <file>#<bank>:<program>[?ROLE=key&...] for one of its presets with chosen keys. isValid() is false when the file could not be read or has no such preset.

    bool DrumKit::isValid() const

    Returns whether the kit was read.

    [static] QVariantList DrumKit::listKits(const QString &folder)

    Returns every kit (SF2 or SF3) in folder, as maps with name and path, sorted by name.

    QString DrumKit::name() const

    Returns the kit's display name: the preset's name for a kit picked inside a font, else the file's.

    [static] QString DrumKit::nameFor(const QString &path)

    Returns a kit's display name for path: its file name without extension (a FluidPlug LV2's soundfont: its bundle's name, such as "Black Pearl 5").

    QString DrumKit::path() const

    Returns the kit's path as given, with its #bank:program if it had one.

    int DrumKit::program() const

    Returns the program of the kit's preset, as bank().

    [static] QString DrumKit::roleForGmNote(int note)

    Returns the role a General MIDI drum-kit note (35 to 59) plays (36 KICK, 38 SNARE, 42 HAT...); empty for any other note.

    [static] QStringList DrumKit::roles()

    Returns the fixed roles in row order: KICK, SNARE, CLAP, TOM, HAT, OPEN, CYMBAL, PERC.

    const QList<DrumKit::Row> &DrumKit::rows() const

    Returns the eight rows, in row order.
