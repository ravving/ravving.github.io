    Detailed Description

    The setup program must start on any Zynthbox, before anything ravving needs is installed, so it links Qt only. Its texts live in ravving's catalog (po/, extracted with the app's), and this class reads the compiled GNU gettext file itself: the messages by their context and English text, a message without a translation shown in English. Plural forms are not used by the page.

    The language is ravving's: the one picked in its SETTINGS (the profile's ui/language), else the system's (LANGUAGE, LC_ALL, LC_MESSAGES, LANG), the first one with a catalog; English otherwise.

    Member Function Documentation

    [explicit] Catalog::Catalog(const QStringList &localeDirs, QObject *parent = nullptr)

    Reads the catalog of the page's language from the first of localeDirs (folders laid out as <dir>/<lang>/LC_MESSAGES/ravving.mo) that has it, with the given parent. The first catalog made is the one instance() returns.

    [invokable] QString Catalog::i18n(const QString &text, const QVariant &a1 = {}, const QVariant &a2 = {}, const QVariant &a3 = {}) const

    Returns text translated, with %1, %2 and %3 replaced by a1, a2 and a3 (those given).

    Note: This function can be invoked via the meta-object system and from QML. See Q_INVOKABLE.

    [invokable] QString Catalog::i18nc(const QString &context, const QString &text, const QVariant &a1 = {}, const QVariant &a2 = {}, const QVariant &a3 = {}) const

    Returns text translated in context, with %1, %2 and %3 replaced by a1, a2 and a3 (those given).

    Note: This function can be invoked via the meta-object system and from QML. See Q_INVOKABLE.

    [static] Catalog *Catalog::instance()

    Returns the catalog the free functions i18n() and i18nc() read, or nullptr before one is made.

    QString Catalog::translate(const QString &context, const QString &text) const

    Returns the translation of text in context (empty for none), or text itself when the catalog has none.
