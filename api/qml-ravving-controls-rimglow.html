    RimGlow QML Type

    A surface lit like a TV's LED backlight: its rim's light on the inside, and the light spilling out round it in fading rings. More...

    Import Statement: import Ravving.Controls 1.0
    • List of all members, including inherited members

    Properties

    Detailed Description

    Fills its parent; the spill lies outside the parent's edges, the inner light inside them (declare it after the face it lights). Shared by the project plate while the SONG page is open and a Chip that is on, so the two light up alike. All of it is still: nothing keeps the window drawing.

    Property Documentation

    spill : list<var>

    The rings of light round the rim, from the closest out: how far each reaches (px) and how strong it is (0..1). The plate's reach further than a chip's.
