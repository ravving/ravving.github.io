    AlbumArt::Credits Struct

    struct AlbumArt::Credits

    What a track's cover says about it: who made it and with what. The exporter fills it from the session (Exporter::coverCredits()). More...

    Header: #include <albumart.h>
    • Credits is part of Audio, recording and export.

    Detailed Description

    FieldMeaning
    authorWho made it: the export's artist, else the profile's author; up the spine. Empty: the spine shows the title.
    soundsThe sounds that play in it (a drum kit, a soundfont, a synth's sound), in the box's second line.
    bpmThe tempo; 0 when unknown.
    keyThe key, as "A Natural Minor"; empty when unknown.
    dateThe day it was made, in the sidebar's small print and taglines; invalid when unknown.
