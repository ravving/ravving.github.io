    Detailed Description

    A controller's settings start from its profile (ControllerProfiles, through the ConnectionRegistry: by its label, else the first its connections fit), and what the file keeps in its group, named by its id, goes over them. The file is a readable INI: the scalar fields by their names (ControllerSettings::fieldName()), the drum keys as note=slot and the controls as CONTROL=message. The profile's surface is kept only once the user chose one (so a change of the profile reaches the controller), its knobs never.

    A group an older version kept under one of the controller's connections' names is read while the controller's own group is empty, and goes with the next save. Everything is written through update(): one writer, so nothing one part of ravving keeps is lost by another's save. GUI thread only.
