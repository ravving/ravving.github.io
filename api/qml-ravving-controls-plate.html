    Plate QML Type

    The plate in a screen's header band, its first row. More...

    Import Statement: import Ravving.Controls 1.0
    • List of all members, including inherited members

    Detailed Description

    A recessed dark display (its top edge casting a shadow into it, a lip of light under it) where a screen says what it is on: the dashboard's project (RaveHeader), the track playing (MUSIC PLAYER), the take (RECORDER). What is put inside is the plate's own child (so a child with a negative z, as the project plate's glow rings, still goes behind it).
