    FileRow QML Type

    A row of a browsing dialog's list (FILES, USB, GET MORE): a name over a line of detail, its actions at the right, the device's ring while the keys are on it. More...

    Detailed Description

    A folder row (the browsers' subfolders) wears the accent's tint, says how many it holds in its detail and ends in a › instead of actions: a tap opens it (the owner's clicked). An entry row's actions are the row's children (ActionButtons, a ConfirmButton); a mark ("✓ ON DEVICE") stands before them, and a note is a third line under the detail (what an entry is about).
