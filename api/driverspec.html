    DriverSpec Struct

    How a protocol's driver is added to ControllerDrivers: its id, which controllers it is for (matches), how its ControllerDriver is made (make) and which of a controller's settings remake the device (remakeOn). A driver's own spec() makes one (RoliBlocks::spec(), MackieSurface::spec()); named() and surface() cover the two ways a driver finds its controllers. More...

    Member Function Documentation

    [static] DriverSpec DriverSpec::named(const QString &id, const QString &namePart, const DriverSpec::Make &make)

    Returns the spec of the driver id for the controllers whose id or one of whose connections holds namePart (" BLOCK" for ROLI's), made by make. Never remade for a setting.

    [static] DriverSpec DriverSpec::surface(const QString &id, const DriverSpec::Make &make, const DriverSpec::RemakeOn &remakeOn = {})

    Returns the spec of the driver id for the controllers whose settings name it as their surface (their profile's, or the user's choice: ControllerDrivers::setSurface()), made by make and remade as remakeOn says.
