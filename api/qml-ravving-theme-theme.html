    Detailed Description

    Fixed values the style (Ravving.Style) and ravving's controls read, so a size, a colour or a duration is defined once. One look, set in code: nothing here is read from a theme or a setting.

    Property Documentation

    actionMinWidth : int [read-only]

    controlHeight : int [read-only]

    controlWidth : int [read-only]

    ravving's own controls: their height (every button, chip and field in a row), the smallest width of one wearing a glyph (◀ ▶ − + ✕: square), and of one wearing a word.

    buttonHeight : int [read-only]

    The style's button height: its buttons, switches, check boxes, menu items and text fields stand at least this tall.

    colors : QtObject [read-only]

    ravving's palette, named colour roles: text, textDisabled, accent, textOnAccent, the surfaces (windowSurface, viewSurface, buttonSurface, each with its …Alt), the well where no skin gives one (wellSurface), the header band and its line (headerSurface, headerLine), the dialog card's ink (cardInk, cardDim), link, positive and negative. A new colour becomes a role here, never a hex value in a control.

    displayFamily : string [read-only]

    monospaceFamily : string [read-only]

    The font families beside the application's own (the regular one): the monospaced one for figures that change while watched, the display one for branding.

    ghostButtons : bool [read-only]

    Buttons draw their label in the icon colour over a transparent face (the "ghost" look).

    hasTransientTouchInput : bool [read-only]

    isMobile : bool [read-only]

    tabletMode : bool [read-only]

    The device is a touch panel used as an instrument, not a tablet in tablet mode nor a phone: the controls keep their desktop behaviour (text selection by drag).

    hoverFeedback : bool [read-only]

    No hover feedback: the panel is touched, not pointed at, and a finger leaves a control "hovered" after it lifts, which would keep a hover tint on the last thing tapped.

    humanMoment : int [read-only]

    longDuration : int [read-only]

    shortDuration : int [read-only]

    Animation lengths: a quick change (a press, a hover), a longer one (a slide, a fade), and how long a busy or progress cycle takes to come round.

    iconSizes : QtObject [read-only]

    Icon sizes, in pixels: sizeForLabels (the regular font's line), small, smallMedium, medium, large, huge, enormous.

    radius : int [read-only]

    The corner radius of the style's text fields.

    smallSpacing : int [read-only]

    The small gap between a control's parts (an indicator and its label, an icon and text).

    spacing : int [read-only]

    The spacing between a menu's entries.

    toolTipDelay : int [read-only]

    How long a pointer rests on a control before its tooltip shows.

    type : QtObject [read-only]

    The type scale (B12, theme/tokens.json type.steps): ten fonts, each a family, size, weight, tracking and case in one, set as font: Theme.type.label. Display (Chakra Petch) for names and titles, always in capitals: hero, title, heading, plate; Plex Sans for what is read: lede, body, label; Plex Mono for small capitals and changing numbers: caps, micro (the smallest, nothing smaller), figure.

    unit : real [read-only]

    The base size unit the style's controls are measured in (24 px on the 800 px-high panel).
