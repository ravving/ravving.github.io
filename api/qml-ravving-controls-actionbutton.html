    ActionButton QML Type

    A button that DOES something once and leaves no state behind (LOAD, CLEAR, SAVE, RENAME, −/+, ◀ ▶, PLAY FROM HERE, TRIM, TO PADS…). More...

    Detailed Description

    The squared button, at the standard size.

    ravving's rule (docs/ui-rules.md): a squared ActionButton for an action; a rounded Chip / StripButton for a STATE you can see (an on/off toggle, with its LED; or one choice of a set, without); a ConfirmButton (an ActionButton asking twice) for what cannot be undone; the ✕ CloseButton to leave a dialog or a page.

    Property Documentation

    fontSize : int

    The label's size.

    minimumWidth : int [read-only]

    Its smallest width (docs/ui-rules.md, "Button sizes"): square for a glyph (one or two characters: ◀ ▶ − + ⟳), Theme.actionMinWidth for a word; a longer label grows past it.
