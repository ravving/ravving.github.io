    Detailed Description

    Each tap() is a beat. From the second tap of a run on, tempoTapped() gives the tempo of the mean of the run's last Gaps gaps, rounded to a whole BPM (SyncTimer's tempo is whole). A pause of ResetMs starts over. A gap more than NewTempo (40 %) away from the run's mean changes nothing by itself: when the next gap agrees with it, the two are a new tempo and the run starts from them; when it does not, the off tap was a stray one and the run starts again from the newest tap. So one sloppy tap never moves the tempo, and a new tempo needs no pause. Studio sets the tempo from it, within its range, unless an external clock sets it. GUI thread only.

    [invokable] int TapTempo::tap(double ms)
