    Detailed Description

    A computer is added with its host, user and password (used once to install the device's key there, see ComputerLink); a computer already in the list as the same user@host is set up again instead of added twice. Each has its own group of the settings file (computers/<id>, ids c1, c2...); settings found at the file's top level (a single-computer set-up) are moved into c1 on start. ComputerLink::forget() removes one.

    The links' sent(), notify() and setupFinished() are forwarded (the last with the computer's id), so one connection covers them all. GUI thread only.

    Member Function Documentation

    [explicit] Computers::Computers(QObject *parent = nullptr)

    Reads the computers from the settings, moving top-level settings into c1 first, with the given parent. The last one becomes current.

    [invokable] QObject *Computers::add(const QString &host, const QString &user, const QString &password, int port = 22)

    Adds a computer at host and port for user (or takes the one already there as user@host) and sets it up with password, which is used once and not stored. It becomes current; its setupFinished() says how it went. Returns the ComputerLink.

    Note: This function can be invoked via the meta-object system and from QML. See Q_INVOKABLE.

    [invokable] QObject *Computers::byId(const QString &id) const

    Returns the computer with the id id, or null.

    Note: This function can be invoked via the meta-object system and from QML. See Q_INVOKABLE.

    [invokable] void Computers::checkAll()

    Tries every computer's key again (ComputerLink::check()).

    Note: This function can be invoked via the meta-object system and from QML. See Q_INVOKABLE.

    [signal] void Computers::notify(const QString &text, const QString &color)

    Emitted with a short translated status text and its color (a CSS colour).

    [invokable] void Computers::send(const QString &id, const QStringList &files)

    Copies files to the Downloads folder of computer id (ComputerLink::send()).

    Note: This function can be invoked via the meta-object system and from QML. See Q_INVOKABLE.

    [signal] void Computers::sent(bool ok, int count, const QString &label)

    Emitted when a transfer ended on one of the computers: ok when every file arrived, count files, to label (user@host).

    [signal] void Computers::setupFinished(const QString &id, bool ok, const QString &message)

    Emitted when the set-up of computer id ended, ok when it worked, with a translated message (ComputerLink::setupFinished()).
