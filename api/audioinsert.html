    Detailed Description

    An insert is an LV2 plugin running in jalv (JalvPlugin) or one of ravving's own processors (BeatRepeat). JackWiring places inserts in a signal path (a machine's DRIVE, the master's LIVE FX, the send effects) without knowing which kind they are. Declared in audioinsert.h.

    Member Function Documentation

    [pure virtual] QStringList AudioInsert::inputPorts() const

    Returns the full JACK names of the audio inputs, left then right; a mono insert has one. Empty while the insert is not running.

    [pure virtual] QStringList AudioInsert::outputPorts() const

    Returns the full JACK names of the audio outputs, left then right; a mono insert has one. Empty while the insert is not running.

    [signal] void AudioInsert::started()

    Emitted when the insert's ports are there, after its first start or a restart: the wiring around it must be made again.
