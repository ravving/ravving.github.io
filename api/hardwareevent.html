    Detailed Description

    It works like QML's KeyEvent: a handler that runs accepts the event; a handler that sets event.accepted = false lets it bubble on to the parent items. Created by Ravving for each CUIA command and knob change, and owned by the code that dispatches it.

    Registered in the Ravving QML module as an uncreatable type.

    Member Function Documentation

    HardwareEvent::HardwareEvent(HardwareEvent::Kind kind, const QString &cuia, int knob, int delta, qreal value, int index)

    Constructs an event of kind. cuia is the CUIA command (buttons), knob the knob index (knobs, else -1), delta the detents turned (KnobTurn), value the pot position 0..1 (KnobMove) and index the step or number key (else -1). It starts not accepted.
