    LedDisplay QML Type

    A red seven-segment-style readout (the TEMPO display), with a caption under it (label, as a Knob has). More...

    Detailed Description

    Drag up/down to change the value; as a KnobGroup target it shows a KnobBadge in its corner. While external (another device sets it: a MIDI clock) it shows externalValue under a small EXT, and neither a drag nor a knob changes it.
