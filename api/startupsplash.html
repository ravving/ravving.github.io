    Detailed Description

    show() opens the splash window (qml/Splash.qml: ravving's logo, still) once libravving is up, in a QML engine of its own, so the studio's root objects stay separate. Nothing animates on it while the studio loads, because an animation would redraw every frame and slow the start. The main window shows the same picture over its first frames (Main.qml's SplashLook overlay), so the splash window closes as soon as the startup mark first-frame is reached (startupMark()). Once the audio is wired too (the wired mark), play() is emitted for the overlay to play its style; where nothing is wired (a desktop run) that happens 3 s after the first frame.

    The style plays in the main window rather than the splash window because KWin keeps a full-screen window above any "stay on top" one, so the splash window would be hidden behind it.

    The style is UserProfile::splash, one of styles(). No splash is shown on the offscreen and minimal platforms or while RAVVING_SCREENSHOT_DIR is set.

    [read-only] progress : qreal

    how far the start has come, 0 to 1: each startup mark (startupMark()) moves it by the share of a start that phase took when measured (studio 0.30, backends 0.33, qml 0.70, first-frame 0.78, wired 1). SplashLook brings the party on and speeds it up with it; QML reads it as startup.progress, and the splash window gets it as its progress.

    Member Function Documentation

    [static] QString StartupSplash::defaultStyle()

    Returns the style used when none was chosen or the saved one is unknown: anime.

    [signal] void StartupSplash::play()

    Emitted once when the studio is up (first frame shown and audio wired, or the grace time passed), for the main window's overlay to play the style.

    [signal] void StartupSplash::progressChanged()

    Emitted with each startup mark that moves progress().

    Note: Notifier signal for properties phase and progress.

    [static] StartupSplash *StartupSplash::show(QObject *parent, Leds *leds = nullptr)

    Shows the splash with the saved style and returns it, parented to parent; returns nullptr when the style is off, there is no screen, or the window could not be created. The pick is random unless RAVVING_SPLASH_PICK sets it (for testing a look). With leds (and a strip) the keys light along (SplashLights): still while loading, the light show with the look's show. Blocks for up to 300 ms in a local event loop until the window's first frame is on screen at the screen's size, then marks splash (startupMark()). The splash receives every later startup mark through startupListener().

    [static] QStringList StartupSplash::styles()

    Returns the styles: anime, glow, still, zoom, aru and off.

    Related Non-Members

    std::function<void (const QByteArray &)> &startupListener()

    Returns the one listener startupMark() calls with each phase as it is marked; StartupSplash sets it. Defined inline in startuptimer.h.

    void startupMark(const char *phase)

    Logs the startup phase to the journal as ravving: startup <phase> <ms> ms, milliseconds since the first call (main() makes it before anything else), and passes it to startupListener(). Each phase is logged and passed on once; later calls with the same phase do nothing. Defined inline in startuptimer.h; GUI thread only.
