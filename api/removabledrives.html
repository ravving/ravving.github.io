    Detailed Description

    A Zynthbox runs udisks2 but mounts nothing by itself, so this lists the USB partitions it finds (lsblk, every two seconds), mounts one on request (udisksctl mount: it lands under /media/root/<label>) and ejects it (sync, udisksctl unmount, then power-off so the stick can be pulled).

    On a stick ravving keeps one layout: ravving/<kind> folders, such as ravving/exports for the tracks (with cover and sidecar) and ravving/projects for the .ravv bundles (stickPath(), folder()). Every ravving writes and reads it the same way, so a stick carries a production from one device to another. The external commands run asynchronously except mount(); copies run in a worker thread.

    [invokable] void RemovableDrives::copyFiles(const QStringList &files, const QString &device, const QString &kind)

    [invokable] QString RemovableDrives::folder(const QString &device, const QString &kind)

    Returns the stick's ravving folder of kind (exports, projects, samples...) on the partition device, mounting it first and making the folder; empty when that failed.

    Note: This function can be invoked via the meta-object system and from QML. See Q_INVOKABLE.

    [invokable] void RemovableDrives::format(const QString &device)

    Erases the whole stick the partition device is on and makes it one writable FAT32 partition labelled RAVVING, mounted: a read-only stick or an installer's image becomes usable. Everything on the stick is lost. Only a USB disk of the list is touched, never the system's; formatted() follows.

    Note: This function can be invoked via the meta-object system and from QML. See Q_INVOKABLE.

    [signal] void RemovableDrives::formatted(const QString &label, const QString &device, bool ok, const QString &message)

    Emitted when the stick that was labelled label was formatted (ok), with its new partition device; on failure device is empty and message says why.

    [invokable] QString RemovableDrives::mount(const QString &device)

    Mounts the partition device, blocking for well under a second. Returns its mount point, or an empty string when it failed.

    Note: This function can be invoked via the meta-object system and from QML. See Q_INVOKABLE.

    [invokable] void RemovableDrives::refresh()

    Looks again now; the poll does it every two seconds anyway.

    Note: This function can be invoked via the meta-object system and from QML. See Q_INVOKABLE.

    [static] QString RemovableDrives::stickPath(const QString &mountPoint, const QString &kind)

    Returns where ravving keeps kind on a stick mounted at mountPoint: <mountPoint>/ravving/<kind>. Nothing is made.
