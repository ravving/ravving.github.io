    Detailed Description

    The caption and a 0–100 readout on a line above the Zynthbox style's QQC Slider (so it wears the active SVG theme), in the machine's ink. Stacked, not side by side, so it takes no more width than the slider (the strip's row is full).

    Like Knob it is a KnobGroup target (value, from, to, knobStep, fineStep, knobBadge, knobPending), so a device knob can drive it and its KnobBadge sits over the handle. A page can also put the big knob on it (bigKnob), which shows the big-knob badge while no group has given it a knob of its own.

    Property Documentation

    bigKnob : bool

    The big knob drives this fader now (the page says so).

    fineStep : real

    KnobGroup target API: value change per knob detent and per big-knob (fine) detent, the device knob driving it (-1 none), and whether a fixed pot still awaits pick-up.

    from : real

    The fader's value and range.

    ink : color

    Caption above the fader, at its left (the readout at its right), and their colour (with none given, the skin's ink, when there is one).

    knobBadge : int

    KnobGroup target API: value change per knob detent and per big-knob (fine) detent, the device knob driving it (-1 none), and whether a fixed pot still awaits pick-up.
