    App and hardware input

    CuiaFifo

    Remote-control fifo at /tmp/webconf-writes-to-this-fifo: each line written to it is a command for ravving

    Fonts

    Ravving's three typefaces, built into the binary, published to QML as fonts

    Hardware

    QML type that carries the Hardware attached property, and the dispatcher that walks the focus chain

    HardwareAttached

    Hardware attached object: the device's knobs and buttons for one item, the way Keys gives it the keyboard

    HardwareEvent

    One hardware event (a knob turn, a pot move, a button) delivered to QML through the Hardware attached property

    HardwareKnobs

    Polls the device's four knobs (zyncoder's zynpots) and reports them as relative turns or absolute positions

    HardwareSwitches

    Polls the device's buttons (zyncoder's zynswitches) and puts every press and release on MidiRouter's CUIA queue

    KeyedListModel

    A list model that applies each new list of maps as the fewest row changes, so QML views keep their delegates

    Leds

    Device's button LEDs by button name, published to QML as leds

    MouseWatcher

    Shows the pointer only while a mouse is plugged in

    QmlSourceOverride

    A development aid that serves the Ravving module's QML files from a source tree instead of the copies compiled into the binary

    QrCodeItem

    A QML item that draws a QR code of its text (QrCode { text: share.url })

    Ravving

    App-level state the QML shell binds to, and the entry point of the hardware input; published to QML as ravving

    SceneInspector

    Logs what the running scene holds, for CuiaFifo's items and animations commands

    ScreenshotTour

    Screenshot tour: a development aid that drives the interface through a list of steps, saves a PNG of the window after each, and quits

    StartupSplash

    Startup splash and its lifetime, published to QML as startup (null when none is shown)

    StderrWatch

    Reads everything the process writes to stderr, passes it on to the journal and turns known trouble into issues

    StyleHost

    What the Zynthbox Quick Controls style expects from its host application, published as the zynqtgui context property

    UnixSignals

    Turns SIGTERM and SIGINT into a Qt signal on the main thread, so systemctl stop and Ctrl+C run ravving's exit steps (the lights off) before the process ends

    WsLedStrip

    A strip of WS2812 ("NeoPixel") LEDs on an SPI bus: the button LEDs of the Zynthbox

    ZynthboxBridge

    Loads libzyncoder and libzynthbox, starts the hardware pollers and forwards their events; published to QML as zynthbox

    zb

    Helpers for calling into libzynthbox objects through Qt's meta-object system
