    Detailed Description

    It reads the pdta sub-chunks (phdr, pbag, pgen, inst, ibag, igen, shdr..., SF2 spec 7.2 to 7.10) and the generators of a preset's instrument zones. DrumKit reads its rows from them, and FluidSynthEngine a preset's vibrato rate (a stopped LFO is revived). The constants name the SF2 generators ravving uses (GenFreqVibLfo 24, GenInstrument 41, GenKeyRange 43, GenSampleId 53) and the record sizes of the preset-data sub-chunks, as qsizetype so offsets into a file's bytes are never computed in int. presetData() and presets() are reentrant; presetGenerator() keeps a cache without a lock, so call it from the GUI thread only.

    quint16 SoundFontFile::u16(const QByteArray &data, qsizetype at)

    Returns the little-endian 16-bit value at offset at of data. Inline; the caller checks the bounds.

    QHash<QByteArray, QByteArray> SoundFontFile::presetData(const QString &path)

    Returns the sub-chunks of the pdta LIST of the soundfont at path, by tag; empty when the file cannot be read or has none. Only the preset list is read, found by walking the RIFF chunk headers (the samples before it can be hundreds of megabytes; an odd-sized chunk some SF3 writers leave unpadded is stepped over too); a file whose sizes do not hold together is searched from its last 8 MB, then whole.

    std::optional<int> SoundFontFile::presetGenerator(const QString &path, int bank, int program, quint16 generator)

    Returns what preset bank / program of the soundfont at path sets generator to: the instrument's global zone value (else the first zone's that sets it) plus the preset zone's offset; std::nullopt when neither sets it (the SF2 default applies) or the preset is not in the file. Cached per file, preset and generator.

    QList<SoundFontFile::Preset> SoundFontFile::presets(const QString &path)

    Returns the presets the soundfont at path holds, in its order, without the terminal record; empty when it cannot be read.
