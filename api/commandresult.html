    Related Non-Members

    void runCommand(QObject *context, const QString &program, const QStringList &arguments, const std::function<void (const CommandResult &)> &done = {}, int timeoutMs = 4000)

    Runs program with arguments without blocking the GUI thread; done gets the CommandResult when it ends, on context's thread. A command that hangs (a daemon gone) is killed after timeoutMs milliseconds and ends as a failure; one that is not installed ends as a failure at once. Nothing is called once context is gone. The QProcess is a child of context and deletes itself.
