    Detailed Description

    A small spaced title, an optional warning under it, the keys' hint, the dialog's own actions (its children, e.g. SAVE / DELETE) and a square ✕ that closes it.

    Property Documentation

    actions : alias [default]

    The dialog's own buttons, before the ✕.

    hint : string

    What the device keys do here.

    notice : string

    A line under the title (a question, a warning), "" for none.

    title : string

    The dialog's title, in small spaced capitals.

    Signal Documentation

    closeClicked()

    The ✕ was tapped: the dialog closes itself.

    Note: The corresponding handler is onCloseClicked.
