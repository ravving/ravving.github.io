    EngineWatch Class

    Finds a machine whose engine stays silent while it is sent notes, reloads the engine's channels and reports it as an issue. More...

    Detailed Description

    The studio tells it each note a machine sends that should sound (expect()): live or from its pattern, on a channel of an engine that can reload its channels (SoundEngine::canReload()), whatever the machine's level or mute (a pattern's note is told of at the velocity its gain leaves it, and one its gain silences never reaches the engine and is not told of: Machine::noteGain()). One SilenceWatch per machine judges the notes against what the machine's track is fed (before its fader and mute), read every PollMs while notes wait (the timer stops when none do, so an idle studio costs nothing). When it says Silent the engine reloads the silent notes' channels (SoundEngine::reloadChannels()) and the issue engine-silent-<machine> is a warning; still silent RepairGapMs later, it reloads again and the issue becomes an error. The first note heard after that clears the issue. GUI thread only.
