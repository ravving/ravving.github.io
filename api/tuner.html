    Detailed Description

    • Input: ravving's own JACK client (ravving-tuner, one input) on the dry input jack in use (setSourcePort(): InputRecorder's, before the input effects). The client is activated only while active is set, so it costs the audio graph nothing otherwise. The audio thread only copies into a lock-free ring; a PitchDetector reads it on the GUI thread every 50 ms.
    • Tunings come from data/tunings.json: an instrument, a name and the open strings as MIDI notes from the lowest. reference is A4 in Hz. The tuning, the mode and the reference are device settings, stored in QSettings.
    • Automatic mode: the strings in order; a string held within tolerance for 0.8 s is marked tuned (stringTuned()), and 0.7 s later the next untuned string becomes the target; after the last, allTuned is set. Manual mode: the string set with setString() is the target and stays; it is still marked once held in tune.
    • The reading is smoothed (the frequency is the median of the last five readings, and the note changes only after three consecutive readings agree on a new one): the frequency, the nearest note and its cents, the cents off the target string, whether that is in tune and how far the hold has gone, and the string the note is nearest to (heardString).
