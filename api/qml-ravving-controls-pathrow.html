    PathRow QML Type

    Where a browsing dialog's list is: ↑ UP while inside a folder, then the kind and the folders opened ("SAMPLES / kicks / 909"); the owner's buttons at the right. More...

    Import Statement: import Ravving.Controls 1.0

    Detailed Description

    ↑ UP is a button of its own, not a row of the list: it is always there, whatever the list does; a tap says up. label is the kind's name, path the folders opened, slash separated ("" at the top). What is put inside the row (USB's IMPORT ALL) ends it at the right.

    Property Documentation
