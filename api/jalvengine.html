    Detailed Description

    MIDI goes in, audio comes out, and its controls are set by LV2 port symbol (the machine's sound controls, setControl()). A mono instrument's one output feeds both sides of the track.

    kits.json engine object: {"type": "jalv", "uri": plugin URI, "controls": {symbol: value}}.
