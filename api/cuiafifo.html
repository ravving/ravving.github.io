    Detailed Description

    The path is the one webconf writes to, so webconf and scripts drive ravving through it. The fifo is created when missing and opened read-write and non-blocking, so it never reports end-of-file between writers; a QSocketNotifier reads it on the GUI thread and each complete line becomes one signal. Of webconf's commands only the CUIA ones are handled (not its json and "sounds" commands).

    LineSignal
    cuia/NAME, or cuia/NAME/track/slot/valuecuiaReceived() with NAME in upper case, as if the device had sent it.
    call|OBJECT|METHOD|ARG|ARG...callReceived(): a method of a backend object (a machine by its key, or studio, input, take). Fields are separated by "|", so paths keep their slashes.
    get|OBJECT|PROPERTYgetReceived(): the property's value goes to the log.
    set|OBJECT|PROPERTY|VALUEsetReceived(); VALUE may contain "|".
    shot|PATHshotReceived(): the window grabbed to a PNG.
    items|PATTERNitemsReceived(): the geometry of every item whose QML type contains PATTERN, to the log.
    animationsanimationsReceived(): every running animation and repeating Timer, to the log.
    
 echo cuia/SWITCH_PLAY_RELEASED > /tmp/webconf-writes-to-this-fifo
 echo "call|pads|loadSample|0|/zynthian/zynthian-my-data/samples/x.wav" > /tmp/webconf-writes-to-this-fifo

    Any other non-empty line is logged as unknown. The receiver (Ravving) interprets the commands; this class only parses lines.

    Member Function Documentation

    [explicit] CuiaFifo::CuiaFifo(QObject *parent = nullptr)

    Creates the fifo when missing, opens it and starts reading it, with the given parent. When it cannot be opened a warning is logged and no signal is ever emitted.

    [signal] void CuiaFifo::animationsReceived()

    Emitted for an animations line: log what keeps the window drawing frames.

    [signal] void CuiaFifo::callReceived(const QString &object, const QString &method, const QStringList &arguments)

    Emitted for a call| line: object names the backend object, method the method to invoke and arguments holds the remaining fields as written. The receiver converts them to the method's parameter types; trailing default arguments may be left out.

    [signal] void CuiaFifo::cuiaReceived(const QString &cuia)

    Emitted for a cuia/ line; cuia is the command in upper case, such as "SWITCH_PLAY_RELEASED".

    [signal] void CuiaFifo::getReceived(const QString &object, const QString &property)

    Emitted for a get| line: log property of the backend object object.

    [signal] void CuiaFifo::itemsReceived(const QString &pattern)

    Emitted for an items| line: log the geometry of the items whose QML type name contains pattern.

    [signal] void CuiaFifo::setReceived(const QString &object, const QString &property, const QString &value)

    Emitted for a set| line: set property of the backend object object to value, as written (the receiver converts it to the property's type).

    [signal] void CuiaFifo::shotReceived(const QString &path)

    Emitted for a shot| line: grab the window to the PNG file path. Works on any platform plugin, the offscreen one included.
