    Detailed Description

    A skin is a screen's colours: its chassis, its ink, its accent, the well its work areas sit in (Rave.machineSkins, Rave.songSkin…). A page sets it at its root, and the controls under it read it from their own attached Skin, as a Qt Quick Controls style's attached properties are read:

    
 QQC.Pane {
     Skin.skin: Rave.machineSkins.bass
     Chip { onColor: Skin.accent }   // the bass's accent, with no colour passed down
 }

    A child sets its own to differ (a part drawn in another skin); with none set anywhere, present is false and the colours are invalid, so a control keeps its own default: ink: Skin.present ? Skin.ink : "white". It is a QQuickAttachedPropertyPropagator: the skin travels down the visual tree. A popup takes the skin of the item it belongs to (its parent, or the item that declares it when it sits on the window's overlay, centred on the window), not its window's, so the popups a screen declares are drawn in its skin.
