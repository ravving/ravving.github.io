    Detailed Description

    A skin file has the preset files' envelope (PresetExchange), so it goes to and from a stick's ravving/presets/skins like a pattern preset:

    
 {"ravving": "preset", "type": "skin",
  "skin": {"name": "CEL", "about": "faded 1990s cel paint…",
           "machines": {"drums1": {"plateColor": "#…", "dark": true, "chassisTop": "#…", …}, …}}}

    The machines are Rave.machineSkins' keys (drums1 … pads) and the colours its skins' keys; a machine or colour a skin leaves out keeps ravving's own. The set's key is the file's name without .json. The shipped sets are in the data folder's skins/ (data/skins in the source); the user's own in the library's skins/ (userFolder()), read after them, so one of the same key wins. Both folders are watched: a file copied in shows up without a restart.

    Member Function Documentation

    [explicit] SkinFiles::SkinFiles(const QString &dataDir, QObject *parent = nullptr)

    Reads the shipped sets from dataDir's skins/ and the user's from userFolder() (made if missing), and watches both folders and every file read, with the given parent. GUI thread only.

    [static] QVariantList SkinFiles::allSkins()

    Returns every set that reads as a skin, shipped and the user's own: maps with key, name and own, by key; an own file of a shipped set's key stands for it.

    [static] QVariantMap SkinFiles::document(const QVariantMap &skin)

    Returns the preset document a skin file holds for skin: {"ravving": "preset", "type": "skin", "skin": skin}.

    [static] QString SkinFiles::fileOf(const QString &key)

    Returns the file of the set key: the user's own if there is one, else the shipped one; an empty string when neither exists.

    [static] QString SkinFiles::importSkin(const QVariantMap &skin)

    Writes skin into userFolder() as a skin file, synced, under a name no shipped or own set has ("NIGHT" → "NIGHT 2"). Returns the name it got, or an empty string for a skin without machines or a file that cannot be written. The watcher then reloads the sets.

    [static] QString SkinFiles::keyOf(const QString &name)

    Returns the set key and file name a skin called name gets: lower case, every run of other characters than letters and digits a dash ("Night Bus" → night-bus).

    [static] QVariantMap SkinFiles::readFile(const QString &path)

    Returns the skin (name, about, machines) of the skin file at path, or an empty map, with a warning, for a file that is not one or has no machines.

    [static] QString SkinFiles::userFolder()

    Returns the user's skins folder: the library's skins/.
