    Detailed Description

    The pages map to the five number keys (Page): 1 drums, 2 chords, 3 bass, 4 lead, 5 sampler.

    Every hardware event (a CUIA command from ZynthboxBridge, a knob from HardwareKnobs, a keyboard shortcut through simulateCuia()) becomes a HardwareEvent that Hardware::dispatch() delivers to the focused item and its parents. A number key no item accepts switches the page here (pageButton()), so the pages are always reachable.

    Some keys are handled before any dispatch:

    • ALT is a modifier (altHeld): while it is held the big knob emits masterTurned() and knobs 1 to 3 go to altKnobTarget;
    • ALT + MODE emits deckToggleRequested(); ALT + UP emits headerRequested(); ALT + 1 emits songRequested();
    • ALT + step keys 1 to 8 emit altStepPressed() and altStepReleased(), ALT + step keys 9 to 16 emit altSectionPressed(); the release of a step key taken this way is consumed even after ALT is released;
    • X and Y emit sectionStepRequested();
    • the video recorder may take RECORD and STOP (VideoRecorder::takesKey()).

    Every key press and knob move is also tracked for heldKeys and named by keyShown(). Enable QT_LOGGING_RULES="ravving.cuia.debug=true" to log every event with the focus chain it travelled.

    Member Function Documentation

    [explicit] Ravving::Ravving(QObject *parent = nullptr)

    Constructs the app state with the drums page open, with the given parent.

    [signal] void Ravving::altSectionPressed(int index)

    Emitted when one of step keys 9 to 16 goes down with ALT held, to pick section index (0 to 7).

    [signal] void Ravving::altStepPressed(int index)

    Emitted when one of step keys 1 to 8 goes down with ALT held, to toggle live-effect pad index (0 to 7, LiveFx::pads()).

    [signal] void Ravving::altStepReleased(int index)

    Emitted when a step key 1 to 8 pressed with ALT comes up; index is the live-effect pad (0 to 7), so momentary pads can end.

    [signal] void Ravving::deckToggleRequested()

    Emitted on the release of ALT + MODE, to switch the header between the live-effect pads and the section keys.

    [slot] void Ravving::handleCuia(const QString &cuia)

    Handles the CUIA command cuia from the bridge (device buttons, MIDI-mapped controllers): tracks the key, applies the keys handled before dispatch (see the class description), turns KNOBn_UP / KNOBn_DOWN into knob turns, and dispatches the rest as a HardwareEvent. A number key no item accepts opens its page.

    [slot] void Ravving::handleKnobMove(int knob, qreal value)

    Handles fixed pot knob (0 to 2) settling at value (0..1): delivered to altKnobTarget while ALT is held, else dispatched to the focus chain as a HardwareEvent.

    [slot] void Ravving::handleKnobTurn(int knob, int delta)

    Handles a turn of the endless knob (0 to 2 the small knobs, 3 the big one) by delta detents: masterTurned() for ALT + the big knob, altKnobTarget for ALT + the others, else a HardwareEvent dispatched to the focus chain.

    [signal] void Ravving::headerRequested()

    Emitted for ALT + UP, to move the focus to the app header.

    [signal] void Ravving::keyShown(const QString &name)

    Emitted when a device key was pressed or a knob moved, with its translated display name ("ALT + MODE", "STEP 3", "BIG KNOB ▲"). Repeats of the same name within 400 ms are dropped, and a fixed pot is named only after it moved 3 % or more.

    [signal] void Ravving::masterTurned(int delta)

    Emitted for ALT + the big knob, to move the master volume by delta detents (positive up).

    [invokable] void Ravving::pageButton(int page)

    Opens page as its number key does. Pressing the key of the page already open cycles that page's machines: the three drum machines on the drums page, the two samplers on the sampler page.

    Note: This function can be invoked via the meta-object system and from QML. See Q_INVOKABLE.

    [signal] void Ravving::sectionStepRequested(int delta)

    Emitted when X (delta -1) or Y (delta +1) is released, to pick the section before or after the current one.

    [invokable] void Ravving::setLogRules(const QString &rules)

    Replaces the logging filter rules with rules while running, several rules separated by ";" (call|ravving|setLogRules|ravving.cuia.debug=true over the fifo).

    Note: This function can be invoked via the meta-object system and from QML. See Q_INVOKABLE.

    void Ravving::setVideoRecorder(VideoRecorder *video)

    Gives the key handling the video recorder video, which may take RECORD and STOP before anything else sees them (VideoRecorder::takesKey()).

    void Ravving::setWindow(QQuickWindow *window)

    Sets window as the window whose focus chain receives the hardware events, and counts its frames for framesSwapped.

    [invokable] void Ravving::simulateCuia(const QString &cuia)

    Handles the CUIA command cuia as if the device had sent it (keyboard shortcuts, tests, the remote-control fifo).

    Note: This function can be invoked via the meta-object system and from QML. See Q_INVOKABLE.

    [invokable] void Ravving::simulateKnob(int knob, int delta)

    Handles a turn of knob (0 to 3) by delta detents as if the device had sent it.

    Note: This function can be invoked via the meta-object system and from QML. See Q_INVOKABLE.

    [signal] void Ravving::songRequested()

    Emitted on the release of ALT + 1, to toggle the song view.
