    zb Namespace

    Helpers for calling into libzynthbox objects through Qt's meta-object system. More...

    Detailed Description

    libzynthbox is opened at run time without its headers (ZynthboxBridge), so its objects are plain QObjects to ravving and every call goes through QMetaObject. These helpers keep each call to one line and log a failed call by name (ravving: libzynthbox call failed) instead of letting it fail silently. Argument types must match the method's declared ones (int, QString, QVariant, QObject *...). Calls are direct: call them on the thread the object lives on. Declared in zbcall.h.

    Function Documentation

    template <typename... Args> bool zb::call(QObject *object, const char *method, Args &&... args)

    Calls method on object with args (Q_ARG values) and discards its result. Returns false, and logs a warning, when object is null or the call failed.

    bool zb::callWithIntegers(QObject *object, const char *method, const QList<qint64> &values, int *returned = nullptr)

    Calls method on object when its parameters are integers or enums libzynthbox declares, which ravving cannot name without the headers (such as PlayfieldManager::setClipPlaystate(int, int, int, PlaybackState, PlayfieldStatePosition, qint64)). The first method named method with as many parameters as values (at most 10) is called; each value is passed under that method's own parameter type: an enum is an int in memory, and qint64 parameters get 64 bits. When returned is not null, the method's int or enum result is stored there. Returns false, with a warning, when no such method exists or the call failed.

    template <typename R, typename... Args> R zb::get(QObject *object, const char *method, Args &&... args)

    Calls method on object with args and returns its result of type R; a default-constructed R, with a warning logged, when object is null or the call failed.

    QList<QObject *> zb::objectList(QObject *object, const char *property)

    Returns the QObjects held by the list-valued property of object (such as Plugin's synthPassthroughClients); an empty list when object is null.
