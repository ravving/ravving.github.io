    Detailed Description

    An offered file (offer()) is served at a random path (128 bits) until stop() or for 15 minutes at most, so a phone on the same network can download it from a URL shown as a QR code; nothing else can guess the path. The server listens on port 8098, or the next free one up to 8107, on every interface; the URL is built on the Wi-Fi address (else any other network's).

    It is built on QTcpServer, since the Qt HttpServer module is not on the Zynthbox image. GET and HEAD are answered, anything else gets a 404; the response has Content-Type, Content-Length and Content-Disposition (an attachment, with the UTF-8 name) and honours Range: bytes=... with a 206 (iOS Safari requests ranges for media, and browsers resume downloads with one). A file is streamed in 64 kB chunks as the socket drains, never read whole. Each connection is closed after its response.

    After setHelpFolder() the server listens permanently and serves GET /help/<file> from the installed site/ folder (/help/ is its index.html; nothing above the folder is reachable).

    openBrowse() creates a random path /b/<32 hex>/ under which FileBrowser's kinds and entries are served as small HTML pages, with a download link per file. Files are served from the paths FileBrowser lists, looked up by kind and name, never taken from the URL. The browse path expires 15 minutes after the last request, or at closeBrowse(). GUI thread only.

    See also setHelpFolder().

    [signal] void FileShare::notify(const QString &text, const QString &color)

    Emitted with a short translated status text and its color (a CSS colour).

    [invokable] QString FileShare::offer(const QString &path)

    Serves the one file at path until stop() or for 15 minutes, replacing any file offered, and returns its URL. Returns an empty string, with error set, when the file cannot be read, no port is free or there is no network.

    Note: This function can be invoked via the meta-object system and from QML. See Q_INVOKABLE.

    [invokable] QString FileShare::openBrowse()

    Serves the browse pages under a new random path until 15 minutes pass with no request, or closeBrowse(), and returns the URL (the existing one, when already browsing). Returns an empty string with no network or no free port.

    Note: This function can be invoked via the meta-object system and from QML. See Q_INVOKABLE.

    [invokable] void FileShare::refresh()

    Reads the device's network address again.

    Note: This function can be invoked via the meta-object system and from QML. See Q_INVOKABLE.

    void FileShare::setBrowser(FileBrowser *browser)

    Sets the library the browse pages list, browser (FileBrowser).

    void FileShare::setHelpFolder(const QString &dir)

    Serves the folder dir (the installed site/) at /help/ from now on, listening permanently; an empty dir stops serving it.

    See also helpFolder().

    [invokable] void FileShare::stop()

    Stops offering the file; connections still streaming it are closed. The help and browse pages stay up.

    Note: This function can be invoked via the meta-object system and from QML. See Q_INVOKABLE.
