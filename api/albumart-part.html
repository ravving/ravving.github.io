    enum Kind { Title, Print, Box, Star, Tagline, Foot }

    Detailed Description

    FieldMeaning
    kindWhat it is: Title (a line of the title), Print (a block of small print), Box (the box with the icon), Star, Tagline, Foot (the strip with RAVV between the tempo's figures).
    rectWhere it lands, inside the sidebar's column.
    textIts text: the line, the small print, the tagline, or the foot's figures (empty when the tempo is unknown).
    pixelsIts text's size in pixels.
    fontIts face: the display family for the title's lines and the foot's figures, the text face's bold for the author's and the tempo's taglines, the mono for the small print and the date.
