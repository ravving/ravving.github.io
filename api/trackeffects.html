    Detailed Description

    • EQ: the passthrough's equaliser; LOW, MID and HIGH are its low shelf (250 Hz), mid peak (1 kHz) and high shelf (5 kHz), ±12 dB with the centre flat;
    • COMPRESSOR: the passthrough's compressor; THRESH -40 to 0 dB, RATIO 1:1 to 20:1, MAKEUP 0 to 24 dB;
    • SIDECHAIN: the same compressor keyed from the sidechain source (attach()); DEPTH sets how deep (threshold and ratio together), RELEASE how fast it recovers (40 to 500 ms). With COMPRESSOR on as well, MAKEUP still applies;
    • PAN: the passthrough's pan (pan());
    • REVERB and DELAY: sends into the studio's GlobalEffects; MIX is the send level (the reverb reaching +6 dB at 100 %, the delay unity), and the shared knobs are GlobalEffects'. setEchoThrow() raises the delay send to at least a given level;
    • DRIVE: a saturator first in the chain (its distortion feeds the rest): the machine's own Calf Saturator (DriveUri, attachDrive()), between its engine and its track only while DRIVE is on (driveSwitched(); JackWiring moves it in and out), started the first time it is switched on. AMOUNT is how hard it saturates (input gain up to +36 dB and the saturation itself), with the output turned down to match, so DRIVE changes the tone rather than the level; TONE darkens it (a low-pass after it, from 1.2 kHz at 0 to wide open at 100 %).

    The sends follow the machine's level (setSendLevel()). Without a passthrough (a desktop run) everything is kept and nothing sounds. GUI thread only.

    Member Function Documentation

    [explicit] TrackEffects::TrackEffects(GlobalEffects *global, QObject *parent = nullptr)

    Constructs the effects of a machine whose sends go to global, the studio's send effects (where the shared knobs live), with the given parent.

    void TrackEffects::attach(QObject *lane, const QString &sidechainSource)

    Attaches the effects to the track: lane is its JackPassthrough, and sidechainSource what SIDECHAIN keys from, in libzynthbox's audio-source terms (such as synthSlot:0:dry0, the first track's synth). Everything is written to the passthrough.

    void TrackEffects::attachDrive(JalvPlugin *drive)

    Gives DRIVE its plugin, drive (a JalvPlugin of DriveUri, not started yet). The plugin starts out of the path; driveSwitched(true) follows at once when DRIVE is already on.

    [signal] void TrackEffects::driveSwitched(bool on)

    Emitted when DRIVE went on (on) or off: its plugin goes into the machine's signal path, or out.

    double TrackEffects::pan() const

    Returns the stereo position, -1 to +1; centre while PAN is off.

    See also setPan().

    void TrackEffects::restore(const QVariantMap &state)

    Takes the saved state, replacing the current one; what it lacks goes back to the defaults (EQ on, every knob at its default).

    void TrackEffects::setEchoThrow(double level)

    Raises the delay send to at least level (0..1), whether DELAY is on or not; LiveFx's echo uses it. Not saved.

    [invokable] void TrackEffects::setEnabled(const QString &effect, bool on)

    Switches effect on when on is true, or off.

    Note: This function can be invoked via the meta-object system and from QML. See Q_INVOKABLE.

    See also enabled().

    void TrackEffects::setPan(double pan)

    Sets the stereo position to pan, -1 to +1, switching PAN on when off centre.

    See also pan().

    void TrackEffects::setSendLevel(double gain)

    Sets the machine's level as a raw gain: the sends are scaled by it too, so the reverb and the delay follow the level as the dry sound does (post-fader), and a gain of 0 silences them.

    [invokable] void TrackEffects::setValue(const QString &effect, const QString &knob, double value)

    Sets knob of effect to value (0..1); a shared knob is set on GlobalEffects.

    Note: This function can be invoked via the meta-object system and from QML. See Q_INVOKABLE.

    See also value().

    QVariantMap TrackEffects::state() const

    Returns what the project keeps: enabled and values.

    [invokable] double TrackEffects::value(const QString &effect, const QString &knob) const

    Returns the value (0..1) of knob of effect; a shared knob's comes from GlobalEffects.

    Note: This function can be invoked via the meta-object system and from QML. See Q_INVOKABLE.

    See also setValue().

    [signal] void TrackEffects::valueSet(const QString &effect, const QString &knob, double value)

    Emitted when the machine's own knob of effect was set to value (0..1), by the user or by automation.
