    LearnedMixers Class

    The plain controllers with MIXER controls learned (SETTINGS · MIDI): a LearnedMixer for each one plugged in, linked to the instruments' mix (ControllerMixers, studio.mixers) while it has any, its lights sent through the MidiTransport. More...

    Detailed Description

    It follows the ConnectionRegistry and MidiInput: a controller plugged in or its settings changed (a control learned or forgotten, its lights turned off) makes, updates or lets go of its mixer; a message learned as a MIXER control goes to it (MidiInput::mixerControl()). One mixer per controller, however many connections it has. GUI thread only.
