    RoliBlocks Class

    Detailed Description

    The BLOCKS protocol: System Exclusive, 00 21 10 77 then the block's topology index (bit 6 set on the way back), a 7-bit packed bit stream of messages (each a 7-bit type then its fields, low bits first) and a checksum. The host probes the blocks (00 21 10 78 3F, answered with a serial dump; without it the blocks answer nothing), asks for the topology (the blocks' serials, indices, batteries, firmware), puts each block in API mode and pings the master every 400 ms (the others every 1.7 s); without the pings a block leaves API mode after five seconds, searches for a host and, in time, powers off. In API mode the blocks report their buttons and config changes as messages. The note grid's root is config item 5 (transpose), its scale 22, its octave 4. A Live Block's SCALE (button 2) steps the grid through the project's scale, its pentatonic and chromatic, the project's key unchanged; its − and + (8 and 9) ask for the octave below or above. The octave is a ControllerOctave: linked to ravving's, or (unlinked) the blocks' own.

    Facts: each block's serial, type, battery and firmware. State: connecting (the topology asked, four times at most), ready (the master acknowledged), lost (no answer).
