    MackieControl::Event Struct

    struct MackieControl::Event

    A message from a Mackie Control surface, as decode() reads it: its kind, the channel strip it came from (strip), the fader's position or the V-Pot's CC (value), the first note of a button's eight (row) and whether it went down (pressed). More...

    Header: #include <mackiecontrol.h>

    Member Type Documentation

    enum Event::Kind

    What a message from the surface is.

    ConstantValueDescription
    MackieControl::Event::Other0not one of the channel strips' (a transport or cursor key, for the learned keys)
    MackieControl::Event::Fader1a fader moved: value is its 14-bit position
    MackieControl::Event::VPot2a V-Pot turned: value is the CC as sent (RelativeEncoder decodes it)
    MackieControl::Event::StripButton3a button of a channel strip: row is its row's first note (RecordArm, Solo, Mute, Select, VPotPress or FaderTouch), pressed whether it went down
