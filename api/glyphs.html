    Detailed Description

    Each glyph is a 32 × 32 grid: an SVG with one path in currentColor, crisp-edged, on a transparent background. A glyph is known by its file's name without .svg (b10-synth); names() lists them and contains() says whether a name is one of them, so a name saved by another version (a glyph since removed) can be told apart and ignored.

    image() draws one in an ink of the caller's, scaled by a whole number, without antialiasing: every grid pixel becomes an exact square of pixels. The outlines are read once and kept; the functions are thread-safe (the exporter draws album art from its worker thread). GlyphProvider serves the same drawing to QML.

    The same drawing serves the UI icons (assets/icons): iconSets() lists the sets, icon() draws one on a square of any size, and IconProvider serves them to QML.

    Variable Documentation

    const int Glyphs::GridSize

    This variable holds the glyphs' grid, 32 pixels square: image() returns a whole multiple of it.

    Function Documentation

    bool Glyphs::contains(const QString &name)

    Returns whether name is one of the built-in glyphs.

    void Glyphs::forgetIcons()

    Forgets every icon read so far, built-in or a pack's, so the next one drawn is read again (IconPacks, once a pack changed).

    bool Glyphs::hasIcon(const QString &set, const QString &name)

    Returns whether the icon set set (or, missing from it, the full set) has an icon name.

    QImage Glyphs::icon(const QString &set, const QString &name, const QColor &ink = QColor(), int pixels = 0)

    Returns the UI icon name of the set set (candy, block, hairline) drawn in ink (near-black when invalid) on a transparent square of pixels: the icon's grid at the largest whole scale that fits, centred on whole pixels, so it stays crisp at any size (at least one grid). An icon the set lacks is drawn from the full set (candy); a null image when neither has it.

    The sets live in assets/icons/<set>/<name>.svg: one path in currentColor on a square viewBox, whose side is the set's grid (12, 8 or 16); an icon pack's in its folder under packFolder(), the same way.

    QStringList Glyphs::iconSets()

    Returns the UI icon sets: the built-in ones (the folders of assets/icons), sorted, then the icon packs' (setPackFolder()).

    QImage Glyphs::image(const QString &name, const QColor &ink = QColor(), int scale = 1)

    Returns the glyph name drawn in ink (near-black when invalid) at scale times its 32-pixel grid (at least 1), on a transparent background, without antialiasing; a null image when there is no such glyph.

    QStringList Glyphs::names()

    Returns the names of the built-in glyphs, sorted (their files' names without .svg).

    QString Glyphs::packFolder()

    Returns the icon packs' folder (setPackFolder()), or an empty string.

    See also setPackFolder().

    void Glyphs::setPackFolder(const QString &folder)

    Sets the icon packs' folder: one folder per pack, one SVG per icon, as the built-in sets are (IconPacks writes them there). A pack is drawn by its folder's name; one named as a built-in set is never read.

    See also packFolder().
