    Detailed Description

    Each glyph is a 32 × 32 grid: an SVG with one path in currentColor, crisp-edged, on a transparent background. A glyph is known by its file's name without .svg (b10-synth); names() lists them and contains() says whether a name is one of them, so a name saved by another version (a glyph since removed) can be told apart and ignored.

    image() draws one in an ink of the caller's, scaled by a whole number, without antialiasing: every grid pixel becomes an exact square of pixels. The outlines are read once and kept; the functions are thread-safe (the exporter draws album art from its worker thread). GlyphProvider serves the same drawing to QML.

    Variable Documentation

    const int Glyphs::GridSize

    This variable holds the glyphs' grid, 32 pixels square: image() returns a whole multiple of it.

    Function Documentation

    bool Glyphs::contains(const QString &name)

    Returns whether name is one of the built-in glyphs.

    QImage Glyphs::image(const QString &name, const QColor &ink = QColor(), int scale = 1)

    Returns the glyph name drawn in ink (near-black when invalid) at scale times its 32-pixel grid (at least 1), on a transparent background, without antialiasing; a null image when there is no such glyph.

    QStringList Glyphs::names()

    Returns the names of the built-in glyphs, sorted (their files' names without .svg).
