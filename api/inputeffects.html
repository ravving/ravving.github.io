    Detailed Description

    InputRecorder wires the chain (chain()). The presets are data (data/input-fx.json): each a chain of plugins with fixed controls and three knobs, a knob moving one or more ports across a range (linear or log). Only the preset in use runs: its plugins start when it is selected and stop when another is, since every running jalv costs the audio graph each period whether wired or not; and it runs only while the input is in use (setActive()). The knob values are kept per preset for the session. Delays marked bpm follow the studio's tempo. No preset (an empty name) is the plain input. GUI thread only.

    InputEffects::InputEffects(const QString &presetsFile, ZynthboxBridge *bridge, QObject *parent = nullptr)

    QList<AudioInsert *> InputEffects::chain() const

    Returns the plugins the input runs through now, in order; empty without a preset, while inactive or on a desktop run.

    [signal] void InputEffects::chainChanged()

    Emitted when the chain changed (another preset, or a plugin restarted): it is wired again.

    [invokable] QStringList InputEffects::presetsFor(const QString &mode) const

    Returns the presets made for the input mode (mic, guitar or line: a preset's modes in input-fx.json; a preset without is for all), in order.

    Note: This function can be invoked via the meta-object system and from QML. See Q_INVOKABLE.

    void InputEffects::setActive(bool active)

    Sets whether the input is in use (active). The preset's plugins run only then and stop otherwise; the preset stays selected.

    void InputEffects::setBpm(int bpm)

    Sets the studio's tempo, bpm, for the delays that follow it.

    [invokable] void InputEffects::setKnob(int index, qreal value)

    Turns knob index (0 to 2) of the preset in use to value (0..1) and sends it to its ports.

    Note: This function can be invoked via the meta-object system and from QML. See Q_INVOKABLE.

    void InputEffects::setMode(const QString &mode)

    Sets the input's mode; a preset not made for it is switched off.
