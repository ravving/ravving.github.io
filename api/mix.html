    Detailed Description

    One mute and one solo per machine, by its key (drums1, chords, pads…). A machine is silenced when it is muted, when another machine is soloed and it is not, or when it is the sampler not playing (the SLOT SAMPLER and the PAD SAMPLER take turns: activeSampler()). The machine played LIVE (liveMachine) and left out only by another's solo is still heard live: its patterns are silent, what is played on it is not (isHeardLive()). The studio hands each machine its verdicts (Machine::muted, Machine::heardLive) and saves the mutes and solos with the session; the screens, the device's keys and the control surfaces all change them here. A key that is not one of the machines' is left out: it is neither kept nor saved. GUI thread only.

    [invokable] bool Mix::isHeardLive(const QString &key) const

    Returns whether the machine key is silenced but still heard live: it is the liveMachine and is left out only by another machine's solo (not muted, not the sampler resting). Its patterns stay silent; what is played on it is heard.

    [invokable] bool Mix::isSilenced(const QString &key) const

    Returns whether the machine key is silent: muted, left out by another machine's solo, or the sampler not playing. Played LIVE and left out only by a solo, it is still heard live (isHeardLive()).

    Note: This function can be invoked via the meta-object system and from QML. See Q_INVOKABLE.
