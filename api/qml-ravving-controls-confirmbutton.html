    Detailed Description

    The first tap arms it (it says AGAIN? and an ArmBar runs out along its bottom in armColor), a second tap within duration says confirmed; otherwise it disarms by itself. An ActionButton (squared: it is an action).

    
 ConfirmButton { label: "DELETE"; onConfirmed: recordings.remove(path) }

    Method Documentation

    needsConfirm()

    Whether a tap now has to be confirmed: true by default. A type or an instance replaces it to confirm only when something would be lost (the pattern toolbar's −: a bar with notes); when it returns false, the first tap confirms at once.
