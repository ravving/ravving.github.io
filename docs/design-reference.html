    The design reference

    easyrave's page, machine by machine, and what ravving takes from it.

    Findings from easyrave.com's page source (fetched 2026-10-04 into ~/Downloads/theme_refs/rave/site/index.html, 1.2 MB, everything inlined).

    What easyrave is

    • A commercial product. It has accounts and licences ("free = 3 songs, license = unlimited") and online saves through easyrave-api.ezamboni96.workers.dev.
    • No licence is published for the code or the assets. No MIT/GPL header, no copyright line. That means all rights reserved by default.
    • All sound comes from its own Web Audio code. There are no third-party audio libraries (no Tone.js, no WASM synths). The only third-party code is MediaPipe, loaded from a CDN for the CAM feature.

    How each machine makes sound

    Machine How
    909 / 808 drums Synthesised. bd909, bd808, snare, clap, hat, tom, ride, crash: oscillators with pitch envelopes plus filtered noise and waveshapers. No samples.
    LinnBeats Samples: 10 WAVs (kick snare sstick clap tamb conga chh ohh cowb ride), embedded as base64 (LINN_EMBED) or fetched from linn/*.wav. No provenance given.
    303 bass Oscillator → resonant biquad, with accent, slide and tie per step. Includes a genBassline generator (in key, weighted toward the root).
    POLY-6 chords Oscillator voices. Chords are stacked in thirds from the current scale, with per-degree "chord sets".
    THERE LEAD One glide voice, a 2-octave ribbon quantised to the scale, LFO vibrato.
    SAMPLE KING 8 slots of user audio (mic recording or dropped WAV/MP3), cutoff, bit crusher.
    Master An AudioWorklet glue compressor + limiter (ERMaster), and a crusher worklet (ERCrush: bit-depth reduction + sample-and-hold).
    Extras The DROP builder (4-bar riser into an impact), NO/ONLY KICK, SING/autotune (YIN pitch + TD-PSOLA), voice → 303 pattern, WAV/MP3 export.

    Can we borrow it?

    Code: no. It's unlicensed, commercial JavaScript. Copying it, translated or not, would copy its expression. Ravving reimplements behaviour. Reading what a feature does to design ours is fine; porting their functions line by line is not.

    Samples: no. The Linn WAVs come with no licence or provenance (they're probably LinnDrum ROM material), so we can't ship them. Drum kits need licence-clean sources: our own recordings or renders, or CC0/permissive packs.

    Artwork: no. Nameplates and finishes are reference only (this rule was already set for the Rave themes). Ravving draws its own in QML.

    Ideas, techniques and musical facts: yes. These aren't copyrightable, and we implement them ourselves: - Analog-drum synthesis recipes: a sine kick with a fast pitch drop and a long tail, noise snares and hats. These are standard techniques. DrumSynth (ZBP_SYNTH_00015) already does this kind of synthesis on the device, and its kits can be programmed to match. - Diatonic chords stacked from the scale, per-degree chord sets: music theory, already in Rave.chordName. - An in-key random bassline weighted to the root: already in BassPage.randomBassline. - The DROP structure (riser, cut, impact), kill-kick, stutter: performance ideas we build on libzynthbox (pattern performance clone, mutes, master filter). - A bit crusher (bit reduction + sample-and-hold): a textbook algorithm. Ravving still needs an implementation, because the device has no crusher among its 56 FX (see the mapping). - Pitch tracking for SING (YIN) and pitch correction (PSOLA): published algorithms with open implementations (e.g. aubio, GPL) that we could use instead.

    Fonts: yes. Oswald, IBM Plex Mono and Baloo 2 are OFL. We can bundle them if we want the exact type.

    Colours: yes, as reference. Per-machine colour values are facts. Rave.machines uses them, as the Rave themes already do.

    What it means for the engines

    easyrave's sounds can't come with us, so ravving uses the device's engines (proposal in the ravving skill's mapping.md, still awaiting approval): - Drums: DrumSynth kits programmed after the 909/808 recipes (synthesis, licence-clean), or SamplerSynth with clean one-shot kits. - Bass: Nekobi (a TB-303 model). Chords: Obxd. Lead: Calf Monosynth. Sampler: SamplerSynth. - Crusher: to be added (an LV2, or a stage in libzynthbox).

    If any of easyrave's sounds or code turn out to be essential, asking its author for permission is the way to get them.
