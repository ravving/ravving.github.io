    Get ravving

    Install ravving from the store in the Zynthbox app, start it, and go back to Zynthbox when you like.

    ravving comes from the store inside the Zynthbox app on your MIKO. It takes a couple of minutes, and you can always go back to Zynthbox.

    What you need

    • A MIKO running Zynthbox.
    • An internet connection, over Wi‑Fi or a cable.

    Install it from the store

    1. Press MENU to open the main menu.
    2. Tap Apps, or press 2.
    3. Tap Get New Apps. The store opens.
    4. Find ravving and tap Install.
    5. Press BACK. ravving now shows up in Apps.

    Or download it

    Prefer to set it up by hand? The same AppImage is on the releases page, and Packaging shows how to put it in the Apps list. It opens the same setup page.

    Start it

    In Apps, tap ravving. A setup page opens with four choices:

    Choice What it does
    TRY IT Starts ravving now. Zynthbox comes back at the next boot.
    MAKE IT THE DEFAULT Starts ravving every time the MIKO boots.
    ZYNTHBOX AT BOOT AGAIN Zynthbox starts at boot again. ravving stays installed.
    REMOVE RAVVING Takes ravving off the MIKO. Tap it twice.

    Pick TRY IT, the orange one, the first time. The two ways back to Zynthbox wait at the bottom. The RIGHT NOW line shows what's installed, what starts at boot and what runs now. While it switches to ravving, ARU throws a little party until ravving starts.

    Sometimes the page lists things your MIKO is missing. Tap INSTALL WHAT IS MISSING while it's online, wait for the message at the bottom, then pick your choice. If it asks you to restart, do that before you play over Bluetooth.

    Go back to Zynthbox

    From ravving, open MENU and press ZYNTHBOX in the power row. Removing ravving keeps your projects, takes and recordings.

    Update it

    When a new version is out, open the store again and tap Update on ravving. Then tap ravving in Apps and pick TRY IT or MAKE IT THE DEFAULT to install the new version.
