    Using ravving / docs/scripting-projects.md

    Building a project by script

    The remote-control fifo: samples, patterns, sounds and a whole project from a shell script.

    Everything a finger does on the device, a script can do through the remote-control fifo (docs/testing.md): load samples, write patterns, pick sounds, set the key and the tempo, save the result as a project. tools/examples/five-am/ (the 5AM demo: sections and the song by script, build.py writing the lines, run.sh sending them) and tools/examples/lofi-say-it.sh are complete ones (a third, "Autumn Leaves", is kept outside the repo in ~/Coding/ravving-projects/autumn-leaves/: its theme is transcribed from the user's own sheet, a generator in Python writing the fifo lines), the lo-fi hip hop project built on the changes of "Say It (Over and Over Again)"; copy it for the next one. This page is the recipe and what we learned writing it.

    The loop

    FIFO=/tmp/webconf-writes-to-this-fifo
send() { timeout 2 sh -c "echo \"$1\" > $FIFO"; sleep 0.2; }
call() { local line="call"; for a in "$@"; do line="$line|$a"; done; send "$line"; }
setp() { send "set|$1|$2|$3"; }
get()  { send "get|$1|$2"; journalctl --user -u ravving --since '-5s' --no-pager | grep 'fifo get' | tail -1 | sed 's/.*= //'; }

    A script runs on the device (copy it there, as the example does with itself); every call is one line on the fifo and takes about a fifth of a second, so a full project is a few hundred lines and a couple of minutes. tools/device.sh call|set|get do the same one at a time from the laptop.

    The recipe, in order

    Step Calls
    keep what is there, start clean get studio.projects dirty, call studio.projects saveAs NAME; call studio.projects newProject
    tempo, swing, key set studio bpm 74, set studio swing 0.58 (and set studio swingEighths true for jazz: the off-beat 8ths swing, not the 16ths; the header's SWING 8 / 16, tapped), call header setKey ROOT SCALE (root 0–11 from C, scale an index into Rave.scales: 0 natural minor, 1 major, 2 Dorian…). NEW resets the key to C minor: set it before writing anything in a key
    drums call drumsN clear, call drumsN toggleStep ROW STEP, toggleAccent STEP; rows by get drumsN rows; call drumsN saveAsPreset keeps the beat as "My Beat N"
    chords set chords bars 8 (the most a pattern holds), set chords viewBar B, then per step call chords setStepNotes STEP "48,52,55,58" (MIDI notes; a note outside the key makes the voicing chromatic). A run of the same voicing on consecutive steps is one held chord; an empty step ends it. Diatonic shortcuts: setChord STEP DEGREE, or SLOTS: assignSlot SLOT DEGREE + cycleSlotBars SLOT. saveAsPreset keeps a chart as "My Progression N" (a longer form = several presets to switch between)
    bass, lead set bass bars 8, set bass viewBar B, call bass setNote STEP NOTE (MIDI; C2 = 36 for the bass, C4 = 60 for the lead, see kits.json baseNote), setNoteLength STEP STEPS (a note lasts one step unless set: a half note is 8, up to 64, into the next bars), toggleAccent STEP, toggleSlide STEP; any note is accepted, in the key or not, and a preset keeps it exactly (the chart's ALTER and HOLD lanes)
    drum kits call drums1 loadKit PATH: a kit file, or a preset inside a soundfont with chosen rows (…/FluidR3Mono_GM.sf3#128:32?CYMBAL=51&HAT=44, the Jazz kit with its ride and hi-hat foot; docs/engines.md); call drumsN setRowLevel ROW 0..1
    sounds call bass chooseSoundSource Upright (names from get bass soundSources), call chords loadSoundPreset NAME for TAL's factory sounds, call bass.sound setValue CARD KNOB 0..1 for the synth's own SOUND MODIFIERS
    pads call pads clearPad N, call pads loadSample N PATH [start length], call pads chopRegions N COUNT FIRSTPAD, set pads selectedPad N + call pads setValue MIX VOLUME 0.95, set pads bars 8, set pads viewBar B + toggleStep PAD STEP; a long one-shot (a 16 s intro) needs a loop long enough not to retrigger it: 8 bars at 74 BPM is 26 s
    SAMPLE KING call sampler loadSample SLOT PATH; set ravving samplerMachine 1 puts the pads on key 5
    save call studio.projects saveAs NAME (a name typed in the dialog would do the same); get studio.projects current to check
    sections and the song the section on screen is what the calls above edit; call studio.sections rename s1 DROP, duplicate s1 (a copy, placed after the section ON SCREEN, which it becomes), setBars ID 1–8, set MACHINE paused true (it rests in this section), move FROM TO (the list), removeFromSong 0 / appendToSong ID / setRepeats INDEX N (the song), set studio.sections mode 1 (SONG), pick ID (the one on screen when saved)

    Things that bit

    • A loop in the shell that reads a file line by line and calls tools/device.sh loses all but the first line: the ssh inside reads the loop's stdin. Send the lines from one script on the device (run.sh) or use ssh -n.

    • Soundfont programs: a soundfont's presets are not always at program 0. ACBass.sf3 has its one bass at bank 0 program 3; read the phdr chunk (a few lines of Python) before trusting a number. General MIDI sets (FluidR3Mono_GM.sf3) follow the GM numbers.

    • Solos survive: a machine stays silent while another is soloed, by script too. Check the header before concluding an engine is broken.
    • Hearing it from the laptop: tools/meter.py on TrackPassthrough:Channel<track+1>-lane1-dryOutLeft gives RMS and brightness per machine; compare before and after a change.
    • Jazz swings the 8ths: PatternModel's swing moves the odd 16ths only, so ravving swings 8ths itself through each note's delay (Machine::setEighthSwing). Measured on milo at 100 BPM, full swing: the ride's off-beat 448–453 ms after the beat, 149 ms before the next (75 / 25), against 300 / 300 straight.
    • A melody needs lengths: a bass or lead note is one step unless setNoteLength says more (a sax's whole note held over the bar line is 19 steps); the roll draws the tail and a long press on a cell stretches the row's note before it up to there.
    • The melody of a published tune is someone else's: chord changes are fine to use, the written melody is not something to copy into a project.
