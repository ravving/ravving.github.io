    Using ravving / guide/send-to-phone.md

    Send a file to your phone

    A QR code on the screen, the phone's camera, and the file is in its Downloads: no app, no pairing.

    Get a track, a video or a project onto your phone: no app, no pairing and no account. It works with any phone, iPhone included.

    Before you start

    The phone and your MIKO must be on the same Wi-Fi. The dialog tells you if the MIKO isn't on a network.

    Send it

    1. Press MENU and tap FILES.
    2. Pick a kind on the left, like TRACKS or VIDEOS.
    3. Tap SEND… beside the file.
    4. Tap PHONE · QR CODE. A QR code appears.
    5. Point the phone's camera at it, and open the link.

    Safari or Chrome saves the file to the phone's Downloads, or Files on an iPhone.

    Watch it arrive

    The dialog shows WAITING FOR THE PHONE, then SENDING with how far it's got, then DOWNLOADED ✓. A message tells you when the whole file has arrived.

    The link is also shown in words, if you'd rather type it on a laptop.

    Good to know

    • The link lasts while the dialog is open, for up to 15 minutes. Closing the dialog ends it.
    • One file at a time. Given several, it sends the first and says so.
    • SEND… is everywhere: in FILES, after a video, in the music player, and in the presets and sound dialogs.

    Straight to your pocket. Now go play it to someone!

    Browse everything from the phone

    PHONE · BROWSE, at the top of FILES, shows a QR code that opens your whole library as web pages. Each file has a DOWNLOAD button.
