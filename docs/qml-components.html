    QML components

    The shared base types, the pages and their parts.

    The QML components in qml/: the shared base types, the pages and their parts. They follow the UI rules.

    Studio machines are shown by MachinePanel (a MachineModule backed by a Machine: level, pan, ❚❚, effects, sound, REC/takes, STEP cursor, LIVE pad and keyboard bookkeeping), extended by DrumMachinePanel (step grid; pads = rows, key 9 = accent), MonoMachinePanel (mono PianoRoll with pattern: machine; in LIVE all 16 step keys play the scale from the root upwards and ▲ ▼ shift the octave (with STEP on, playing or not, they walk the rows, each heard: previewSelection, and SELECT writes the row: writeSelection / selectionKey, shared in MachinePanel); with showRibbon the lead's Ribbon: its notes go through the same LIVE path, a slide starts the next note before ending the last so the engine glides, drag up = vibrato) and ChordMachinePanel (the nameplate shows the loaded TAL sound's title, POLY-6 for its own; a tap opens the sound picker, a double tap rebuilds its own sound from TAL's start-up sound, the engine's controls and the default knobs; CHORDS / NOTES / SLOTS tabs: ChordRoll, a poly PianoRoll on the same steps, ChordSlots; ◀ ▶ switch them while the editor has the focus (moveView, viewCount); the step keys and ▲ ▼ work on the view on screen; CHORD SET, chord keys played as pads that also fill an armed slot; LIVE follows the tab: on CHORDS / SLOTS pads 1–7 = the degrees' chords, on NOTES all 16 pads play single scale notes (note keys), ▲ ▼ the octave while LIVE (the rows with STEP on; SELECT writes the selected chord or note); ▲ ▼ = octave while LIVE) and SamplerMachinePanel (SampleScreen with the slot's waveform and trim handles, a KnobGroup itself: a tap on it or ▲ from the grid's top row gives knob 1 to the start handle and knob 2 to the end, ▼ gives the knobs back to the rows, LOAD with hold-to-hear previews, ▶, CLEAR, REVERSE, ● REC and INPUT (InputPopup), PITCH; the step grid over the bank's slots; BANK A–D chips and ◀ ▶; pads 1–8 = slots, key 9 = accent; knobs 1–3 = the selected row's mute, solo, level). MachinePage is the page around any of them: it forwards the step keys, ▲ ▼, the header hand-off and an external keyboard to its panel (BassPage, LeadPage, ChordsPage only declare their panel).

    All of qml/ is one QML module, Ravving, built by qt_add_qml_module into the binary (qmlcachegen bytecode, typed bindings compiled to C++) and loaded with loadFromModule("Ravving", "Main"); Hardware and HardwareEvent join it through QML_ELEMENT. Every file imports Ravving; there are no relative imports. For development, RAVVING_QML_DIR makes QmlSourceOverride (a URL interceptor) serve the .qml files from a source tree instead, so QML edits need only a restart.

    Component Role
    Rave (singleton) machine finishes (colours), instruments strip, scales, chord sets, music helpers
    Session (singleton) global state: key, scale, tempo, swing, transport clock, live FX, mute/solo; the views instead of the page (mixView, songView, playerView, one at a time); sectionWaiting / sectionBlink for a section waiting for its bar; the modal layers up (overlays, inputBlocked)
    RaveHeader the top bar shared by all pages; the ROOT and SCALE pickers without captions; the project's name on an engraved plate between SCALE and EDIT (200 px at most, a long name loses its middle; "•" while unsaved); a faint vertical meter of the master's level beside the MASTER dial (always drawn, so the dial never moves); SAVE asks the project's name the first time (NamePopup) and otherwise wants a second press within three seconds (SAVE AGAIN), SAVE AS NEW always asks; PROJECT ▾ has NEW, SAVE AS NEW, EXPORT (exportRequested → Main.qml's ExportPopup), IMPORT (a ChoicePopup of the .ravv bundles found: studio.exporter.importable(), imported and opened unless the session is unsaved) and DELETE
    NamePopup a name asked of the user: one text field with Qt's on-screen keyboard under it (as WifiPopup), OK / CANCEL, SELECT keeps, BACK cancels
    ExportPopup EXPORT: file name, title, artist, album / mixtape, genre, composer, comment, the cover drawn as typed (image://albumart), FORMAT (WAV 24-bit / FLAC / OGG / MP3), BARS × LOOPS + TAIL with the length; EXPORT TRACK (progress shown, CANCEL) and EXPORT .RAVV; shrinks over the on-screen keyboard and scrolls the field into view; ▲ ▼ fields, ◀ ▶ format, knobs 1–3 bars / loops / tail, SELECT exports, BACK closes
    SettingsPopup the profile: USER and AUTHOR, saved as typed
    MusicPlayerPage the MUSIC PLAYER, a full-screen view over the dashboard (Session.playerView, the control center's DASHBOARD / MUSIC PLAYER switch): left the library (TRACKS sorted by NEWEST / TITLE / ARTIST / ALBUM / LONGEST, ALBUMS and ARTISTS grids opening as lists with PLAY ALL / QUEUE ALL), a tap plays now, + queues; right the cover, the track, a position bar (tap to seek), ⏮ ▶ / ❚❚ ■ ⏭ REPEAT, VOLUME, and the QUEUE (tap plays, ✕ drops, CLEAR). Keys 1 2 3 or ◀ ▶ the views, ▲ ▼ the cursor, SELECT plays, PLAY pauses, STOP, big knob volume, knob 1 position, MENU the control center, BACK leaves. Opening it stops the transport, leaving it stops the player
    InstrumentChip, GroupLabel, LedDisplay header parts; a chip draws its machine's track level as a slim bar along its bottom (the mixer's colours), only while the machine sounds, from the header's meters (studio.meters() read ten times a second; the pads' second track counts too)
    Machine (sound sources) soundSources / soundSource / chooseSoundSource(): kits.json sources after the machine's own engine (sourceName); engineConfig() is the chosen one, saved as soundSource in the state; the studio restarts the engine on a change (Studio::restartEngine: JackWiring::removeSynth forgets the old ports, SoundEngine::stop ends its process, a new engine is started and wired with the same DRIVE insert). soundControlsApply hides the SOUND MODIFIERS on another source
    MachinePanel (STEP entry) ◀ ▶ in STEP entry while stopped move the entry cursor a step (moveCursor, wrapping in the pattern) on every panel, instead of switching views or banks; keys held together join one step (Machine::writeWithPrevious: the second key goes where the first went, the cursor advances once)
    MachineModule a machine panel: strip, SOUND MODIFIERS, the editor, SOUND EFFECTS. The editor keeps the height it has with both sections closed and scrolls under an open one (a Flickable; a line with dots in the accent along an edge says content continues beyond it) instead of being squashed
    Nameplate, FxChain, PatternToolbar machine panel parts
    StepGrid drum/slot rows × 16 steps (+ ACC); drums, sampler and the PAD SAMPLER's lane
    PianoRoll notes × 16 steps, mono (a MonoMachine: bass, lead) or poly (a ChordMachine's NOTES view: noteSets, toggleNote), ACCENT/SLIDE lanes. Two fingers pinch to zoom (rows kept 18–56 px tall, so the range follows the scale and the height) and drag to scroll; a scroll past an octave shifts the owner's octave (octaveScrolled), so OCT − / + shows what is on screen. ▲ ▼ select a note row (currentNote; a tap or a note played live selects too) and a step key writes that note. heldNotes lights the rows played live; a held note without a row shows as an edge marker ("▲ G4" / "▼ E2") or, outside the scale, a lit line between its neighbours with its name Gestures: a one-finger drag scrolls the rows (DragHandler, the gesture locked to its first axis; past 8 semitones octaveScrolled shifts the owner's octave) or pages the bars sideways (one bar per 120 px, the content following the finger), two fingers pinch to zoom and scroll; a tap toggles a cell. The row count is set by the zoom (rowCount), so scrolling never resizes the rows or the ACC / SLIDE lanes (fixed 20 px)
    WaveCycler the wave switch: LEDs per choice, the waveform drawn (SAW SQR TRI SIN), its name; tap = next, one knob detent = one choice
    ChordRoll scale degrees × 16 steps on a ChordMachine; runs joined; custom voicings ★ on their lowest degree; a selected degree row (▲ ▼, step keys), held degrees lit
    ChordSlots the SLOTS view: four cards (chord, numeral, bars); tap arms, hold empties, the bars button cycles 1/2/4/8
    Ribbon touch ribbon over two octaves from the lead's base note, snapped to the scale; note and vibrato (drag up)
    KeyCap, Chip, RaveKnob the controls: drum key, LED pill toggle, labelled dial (a QQC Dial for the touch handling, drawn by DialFace: the ring, the body and the pointer all in Qt Quick Shapes on the curve renderer, in one frame, so nothing drifts by a sub-pixel (a Rectangle body beside the Shape ring read as off-centre on the cards); crisp from 26 px up; groove, accent value arc from the start or from the centre for ranges around zero, body, pointer)
    KnobGroup, KnobBadge a focusable group the device knobs drive; the knob indicator
    RaveComboBox a drop-down (ROOT, SCALE, CHORD SETS) whose list opens as a dialog centred on the screen (the dialog card, a title, 48 px rows) that the device works while open: arrows / big knob move, SELECT picks and closes, BACK closes; the focus goes back where it was
    ControlCenter, ControlCard, LevelSlider, Glyph the menu drawer's control center: cards (a glyph, title, detail; toggle cards lamp-lit while on), the iOS-style pill slider (relative drag, a KnobGroup target), vector line icons
    MachineStrip a machine's strip (nameplate, role, PAN, VOL, REC, ❚❚, STEP and a hairline on a machine's page (showStepModes, stepModeEdited), LIVE, S, M; a KnobGroup for PAN and VOL), the top of every MachineModule and the MIXER's rows; level/pan/paused come in, edits go out (levelEdited…)
    MixerPage the MIXER: every machine folded to its MachineStrip on its own finish, one under another, a slim meter of its track (Studio::meters(), 20 times a second while on screen) under each; ▲ ▼ / step keys pick a machine (its strip takes knobs 1–2), SELECT mutes, ALT + SELECT solos, a nameplate opens the page. Session.mixView is its switch: ✱, the header's EDIT / MIX, the control center
    SongPage SONG (studio.sections): the StackLayout's seventh view, under the header as the MIXER (Session.songView, the project plate opens and closes it). SECTIONS at a finger's size: square keys wearing their number, their name under, a dot per sounding machine, the one on screen filled in its colour (blinking while it waits for the bar: Session.sectionBlink, its timer running only then), eight a row (the first row is ALT + step keys 9–16), ＋ a copy of the one on screen; tap picks, double tap renames (NamePopup), hold and drag moves, × deletes (second tap). A row for the section on screen: RENAME, NEW, COLOUR, LENGTH (AUTO), MOVE, ADD TO SONG. The SONG as a strip of blocks as wide as bars × repeats, a row for the block picked: MOVE, REPEATS, REMOVE. Keys: ◀ ▶ walk, ▲ ▼ between, SELECT picks, step keys pick, ALT + ◀ ▶ move, knob 1 the length, knob 2 the repeats. Idle it draws nothing (0 frames/s measured)
    RavePopup, ModalDim, DialogHeader the dialogs' base (centred, modal, focus taken and given back) and the dark layer behind dialogs, drop-down lists and the menu
    ChoicePopup a grid picker (kits, presets, samples) with the same hardware; names wrap to two lines, subtitles elide in the middle; previewable: holding an item previews it until let go
    InputPopup, InputMeter INPUT: MIC / GUITAR / LINE, GAIN, MONITOR and its LEVEL, ● REC, and EFFECTS (OFF or a preset, its three knobs); the knobs work on one row, ▲ ▼ pick INPUT or EFFECTS, ◀ ▶ the mode or the preset (+ big knob for fine gain); the input's peak meter (−60…0 dBFS, yellow from −18, red from −6, held peak, CLIP)
    SampleScreen the sampler slot's screen: libzynthbox's WaveFormItem (made at run time), trim handles, darkened trimmed-out parts, a take's time and meter while recording
    PadSamplerPanel the PAD SAMPLER (MPC-style): PadGrid + the pad's SampleScreen, tools (LOAD, ● REC with SMART stop, CLEAR, COPY, ERASE, 16 LVL, CHOP, AUTO CHOP), Pad Play chips, the live PAD FX row, one tab card (TRIM · MIX · AMP ENV · TUNE · PLAY · FILTER · FLT ENV) on knobs 1–3, the lane (a StepGrid of the selected pad + ACC); ◀ ▶ tabs, ▲ ▼ lane → pads → strip; LIVE = the 16 step keys are the pads
    PadGrid a pad that sounds beams (its colour pulsing over it, the border lit: the machine's playing); the MPC's 4 × 4 pads (13–16 top, 1–4 bottom): number, name, 16 hit dots, pad colour, mute tint, selection, held flash, latched-loop ring; tap / hold / long press
    PadState the PAD SAMPLER in QML only (the backend's interface to come): 16 pads with params[tab][knob] 0..1 and Pad Play flags, the bar's steps, the lane single-row view, the tabs and switch choices
    WaveEditorPopup the wave editor both samplers share: the sample large with its trim, CHOP by REGIONS 4/8/16 (big knob), THRESHOLD (the machine's detectTransients, knob = threshold) or MANUAL (taps on the wave), the cuts drawn and numbered; APPLY / SELECT → the owner's applyChop (pieces onto the pads from pad 1, or the bank's slots from slot 1); NORMALISE / TRIM → trimToNewFile. Both machines expose the same three methods and transientsDetected
    RavePage page base: a FocusScope receiving the hardware

    Pages combine these and hold only page-specific logic: the bassline generator, the bank switching, the chord cursor. Generic controls (buttons, combo boxes, sliders, tabs) come from the Zynthbox Quick Controls style, so they follow the active SVG theme; the dials are ravving's own (DialFace), since the theme's SVG dial breaks up at the small sizes the machines use. The machine-specific parts (key caps, nameplates, grids) are drawn in QML from each machine's finish in Rave.machines.
