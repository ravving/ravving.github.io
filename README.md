# ravving.github.io

The ravving page: the instructions, the features and every hardware shortcut of
[ravving](https://github.com/ravving/ravving), the groovebox mod for the Zynthbox MIKO.

Its source is the `site/` folder of that repository; `tools/publish-site.sh` there pushes it
here, and the workflow deploys what is here to GitHub Pages on every push. Nothing is edited
here by hand.
