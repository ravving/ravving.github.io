# ravving.github.io

The ravving page: the instructions, the features and every hardware shortcut of
[ravving](https://github.com/ravving/ravving), the groovebox mod for the Zynthbox MIKO.

Its source is the `site/` folder of that repository; the workflow here deploys it to GitHub
Pages (daily, and when ravving's `tools/publish-site.sh` asks). Nothing is edited here.
