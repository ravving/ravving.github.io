    セッションを撮影する

    LIVE REC：音と同期した画面やカメラの映像、または音声だけを、あなたの声も重ねて。

    演奏をビデオで録画します：画面か USB カメラを、音と同期して。音だけを録音することもできます。録音を始めても音楽は止まりません。

    LIVE REC を始める

    1. MENU を押して LIVE REC をタップします。
    2. WHAT で録るものを選びます：
      • VIDEO：画面か USB カメラを音付きで、VIDEOS に MP4 として。
      • AUDIO ONLY：音だけを、TRACKS に WAV として。
    3. MIC を入れるかどうかと、声の種類を選びます：VOICE-OVER（話す間は音楽が下がる）か SINGING（音楽はそのまま）。
    4. START をタップします。

    ダイアログが確認になっているので、うっかりタッチで録画が始まることはありません。

    録画中

    プレートが REC IN 3 とカウントダウンし、その後 ● REC 00:04 と時間を表示します。メニューは先に閉じるので映りません。

    ビデオでは、押したキーが画面下に表示されるので、見る人に何を弾いたかが伝わります。

    止める

    STOP を押すと、録画が終わり、音楽も止まります。

    終わったあともライブ録音はオンのまま待機します。どのページからでも RECORD で次のテイクへ。オフにするには 3 秒以内にもう一度 STOP（お知らせが出ます）、またはメニューの LIVE REC カードをもう一度タップ。

    終わったら

    VIDEO SAVED ダイアログに、ファイル、長さ、サイズが表示されます。

    • DELETE：3 秒以内に 2 回タップします。
    • RENAME：好きな名前を付けます。
    • SEND…：USB メモリー、パソコン、スマホへ。

    音声の録音には METADATA… もあります：書き出した曲と同じように、タグを付け、ジャケットを描き、WAV、FLAC、OGG、MP3 で保存します。

    一緒に歌おう！ MIC を入れると、声の下で音楽が下がります。

    音楽に合わせて話す、または歌う

    MIC を入れて VOICE-OVER を選ぶと、話している間は音楽が下がり、止めると戻ります。声はドライで近い音に。SINGING では音楽はそのままで、声に少しのルーム、拍に合ったエコー、プレートがかかります。MIC TOO HOT が出たら、設定 → LIVE REC で GAIN を下げてください。

    MIC を入れてライブ録音がオンの間、入力は録音専用です。レコーダーページとサンプラーの INPUT はライブ録音を抜けるまで待ち、レコーダーページの設定は録音に影響しません。

    設定

    MENU → 設定 → LIVE REC には QUALITY、録音が始まる前の TIMER、SOURCE（画面か USB カメラ）があります。録音用マイクの INPUT と GAIN、VOICE（VOICE-OVER か SINGING）、EFFECTS、音楽をどれだけ下げるかもここに。次回のために保存されます。
