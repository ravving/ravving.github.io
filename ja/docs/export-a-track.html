    再生 / guide/export-a-track.md

    曲を書き出して聴く

    タグとジャケット付きの WAV、FLAC、OGG、MP3。それからミュージックプレーヤー、または共有用の .ravv バンドル。

    プロジェクトを曲のファイルにします：タグとジャケット付きの WAV、FLAC、OGG、MP3。それからミュージックプレーヤーで聴いたり、どこかへ送ったり。

    EXPORT を開く

    ヘッダーの PROJECT ▾ を開き、EXPORT をタップします。

    名前とタグを付ける

    • FILE NAME と TITLE。
    • ARTIST と COMPOSER は、MENU → SETTINGS で設定したプロフィールの作者名から始まります。
    • ALBUM / MIXTAPE と GENRE には、前回入力したものが出ます。
    • カバーは ravving のアートワークからランダムに選ばれ、ステッカーが貼られていることもよくあります。
    • タイトルはたいてい昔の CD のような黒いサイドバーに入り、作った人と流れる音が小さく添えられます。アートの上に載ることもあります。カバーをタップすると別のものに、下の SIDEBAR か CORNER で見た目を選べます。

    形式と保存先を選ぶ

    • FORMAT：WAV 24-BIT、FLAC LOSSLESS、OGG、MP3。
    • USB：DEVICE ONLY、または挿しているメモリーへのコピー。
    • COMPUTER：書き出しが終わったら、パソコンにも送れます。

    長さを選ぶ

    • WHAT: LOOP は表示中のセクションを BARS × LOOPS だけ再生します。ノブ 1 と 2 で設定します。
    • WHAT: SONG は曲全体を最初から最後まで録音します。
    • TAIL は、エコーが消えるまでの数秒を最後に足します。ノブ 3 で設定します。

    ダイアログに曲の長さが表示されます。

    書き出す

    EXPORT TRACK をタップします。ravving がプロジェクトを最初の拍から再生して録音するので、静かにしていてください：スピーカーの音がミックスです。バーで進み具合がわかり、CANCEL で中止できます。

    終わるとダイアログが閉じます。曲はライブラリの書き出しフォルダーに、ジャケットと詳細と一緒に入ります。

    初リリース！ 送る前にちゃんとしたタイトルを付けましょう。

    聴いてみる

    MENU → MUSIC PLAYER を開きます。新しい曲は TRACKS の一番上にあります。

    • ▶ で曲を再生し、+ でキューに追加します。
    • SEND… で USB メモリー、パソコン、スマホに送ります。
    • 大きなノブで音量、ノブ 1 で曲の位置を動かします。
    • BACK でプレーヤーを閉じます。

    プロジェクトごと持ち出す

    EXPORT .RAVV でバンドルを保存します：使っているサンプルをすべて含むプロジェクトです。別の ravving で PROJECT ▾ → IMPORT から開くと、まったく同じように鳴ります。

    もっと

    • 書き出しとミュージックプレーヤー：曲に保存される内容と、出力の音量。
    • ミュージックプレーヤー：すべてのキー。
