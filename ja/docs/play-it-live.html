    ライブで演奏する

    拍に合わせてパートを切り替え、LIVE FX パッドを押し、上に重ねて弾き、セットを録音します。

    曲にパートがそろいました。さあ演奏しましょう。拍に合わせてパートを切り替え、LIVE FX パッドでミックスを揺さぶり、上に重ねて弾き、セット全体を録音します。

    拍に合わせてパートを切り替える

    音楽が鳴っている間に別のセクションを選ぶと、次の小節線でぴったり切り替わります。音が抜けたり重なったりはしません。

    • 大ノブの横の X と Y で、どのページからでも前と次のセクションへ。
    • ヘッダーにセクションキーがある間は、ALT + ステップキー 1–16 でセクション 1–16 を選べます。
    • ヘッダーか SONG ページでセクションキーをタップ。

    待っている間はセクションのキーが点滅し、切り替わるとヘッダーのプレートがその色でさっと光ります。切り替わる前に X か Y をもう一度押すと、選択をさらに先へ進められます。

    パートの終わりを待つ

    鳴っているパートの小節を最後まで弾き切るには、SONG ページを開いて SWITCH を SECTION に。選んだパートは、鳴っているパートが一巡し終わるのを待ちます。もう一つの BAR は次の小節で切り替えます。

    最大 3 つ先までパートを予約することもできます。それぞれ 1 回鳴ってから次に移り、最後のパートはループし続けます。

    LIVE FX パッドを出す

    ヘッダーは最初セクションキーを表示しています。ALT + MODE を押すか、プロジェクトのプレートを長押しすると、LIVE FX パッドに入れ替わります。もう一度でセクションに戻ります。

    1. ALT を押したままに。ステップキーがオレンジに点灯し、パッドにキー番号が出ます。
    2. ステップキー 1–8 でヘッダーの 8 個のパッド。
    3. ステップキー 9–16 で、ALT を押している間に出るもう 8 個。

    画面のパッドをタップしても使えます。ALT + ▼ で次のバンクへ。MAIN、次に MORE、全部で 30 個のパッドです。

    まず試したいパッド

    • DROP をキーで押したまま：キックが消え、ミックスが上へスイープ。離すとドロップ。
    • STUTTER を押したまま：今の 16 分音符を繰り返します。上でドラッグすると繰り返しが短く。
    • LOOP 4、LOOP 8 を押したまま：今の拍か 8 分音符を繰り返します。
    • NO KICK：タップですべてのキックを消し、もう一度で戻します。
    • LO PASS、HI PASS：もう一度タップするまで、下か上へのフィルタースイープ。
    • ECHO を押したまま：ミックスがエコーに送られ、離すと余韻を残して消えます。

    画面では、押している間だけ効くパッドもあれば、タップでオンになるもの、0.5 秒押すとオンのままになるもの（DROP など）もあります。全パッドは LIVE FX の表に。

    上に重ねて弾く

    マシンのページで MODE を押すと、LIVE でステップキーが弾けるものになります。

    • ドラム：キー 1–8 で各行を鳴らし、キー 9 を押したままにするとアクセント。
    • ベースとリード：16 個のキーにスケール。▲ ▼ でオクターブを移動。
    • コード：キーの 7 つのコード。

    MODE は STEP + LIVE、次に OFF へ進み、ステップキーはまたグリッドに書き込みます。どれがオンかは MODE のライトでわかります。

    マシンをソロにする

    マシンの S を長押しすると、そのマシンだけが鳴ります。ほかのソロは外れます。もう一度 S をタップするとバンドが戻ります。

    セットを録音する

    どのページでも ALT + ● を押すと、スピーカーから出る音すべてが WAV で録音されます。RECORD のライトが赤くなり、ヘッダーに ● REC と時間が出ます。止めるにはもう一度 ALT + ●。

    セットは MENU → MUSIC PLAYER にあり、再生も送信もできます。映像も撮るならセッションを撮影するへ。

    もっと

    • LIVE FX：全パッド、それぞれの動き、SETTINGS で決める自分の MAIN バンク。
    • セクションと曲：予約、BAR か SECTION、マシンごとの LOOP と ONCE。
