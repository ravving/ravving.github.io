    ravving を入手

    Zynthbox アプリのストアから ravving をインストールして起動し、いつでも Zynthbox に戻れます。

    ravving は MIKO の Zynthbox アプリ内のストアから入手します。数分で終わり、いつでも Zynthbox に戻れます。

    必要なもの

    • Zynthbox で動く MIKO。
    • Wi‑Fi かケーブルでのインターネット接続。

    ストアからインストール

    1. MENU を押してメインメニューを開きます。
    2. Apps をタップするか、2 を押します。
    3. Get New Apps をタップすると、ストアが開きます。
    4. ravving を探して Install をタップします。
    5. BACK を押します。ravving が Apps に表示されます。

    またはダウンロード

    手動で入れたい場合は、同じ AppImage が リリースページにあり、 パッケージングに Apps 一覧への入れ方があります。同じセットアップページが開きます。

    起動する

    Apps で ravving をタップすると、4 つの選択肢があるセットアップページが開きます：

    選択肢 内容
    TRY IT 今すぐ ravving を起動します。次の起動時には Zynthbox に戻ります。
    MAKE IT THE DEFAULT MIKO を起動するたびに ravving が立ち上がります。
    ZYNTHBOX AT BOOT AGAIN 起動時に再び Zynthbox が立ち上がります。ravving はインストールされたままです。
    REMOVE RAVVING MIKO から ravving を削除します。2 回タップ。

    最初はオレンジの TRY IT を選びます。Zynthbox に戻る 2 つの方法は下にあります。 RIGHT NOW の行には、インストール済みのもの、起動時に立ち上がるもの、いま動いているものが表示されます。 ravving に切り替わる間、起動するまで ARU が小さなパーティーを開きます。

    ページに MIKO に足りないものが表示されることがあります。インターネットにつながっている状態で 足りないものをインストール をタップし、下のメッセージを待ってから選んでください。再起動を求められたら、Bluetooth で鳴らす前に再起動してください。

    Zynthbox に戻る

    ravving で MENU を開き、電源の列の ZYNTHBOX を押します。ravving を削除しても、プロジェクト、テイク、録音は残ります。

    アップデートする

    新しいバージョンが出たら、もう一度ストアを開いて ravving の Update をタップします。それから Apps で ravving をタップし、TRY IT か MAKE IT THE DEFAULT を選ぶと新しいバージョンがインストールされます。
