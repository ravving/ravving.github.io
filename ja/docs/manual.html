    マニュアル

    5 つのページとそこで鳴るもの、ショートカット、元に戻す、音源、プリセット、テンプレート、セクションとソング、書き出し、ライブ録音、ファイル、USB メモリー、Bluetooth、レコーダー、お知らせセンター。

    これは暫定版のマニュアルです。各ページ、キー、ダイアログの働きを説明します。スクリーンショット付きのわかりやすいガイドも準備中です。

    5 つのページ

    やあ！5 つのキー、5 つのページ、8 台のマシン。さあ、音を出そう。

    左にある 5 つの数字キーが、それぞれページを開きます：

    キー ページ 鳴るもの（ネームプレートに表示）
    1 ドラム 1 · 2 · 3（もう一度 1 を押すと切り替え） それぞれにドラムキット：最初は Roland TR909、Roland TR808、LINN9000。本体のドラムマシンフォルダーにある好きなキットも使えます
    2 コード TAL NoiseMaker とそのファクトリーサウンド、またはサウンドフォントの楽器（Rhodes、ヴィブラフォン、オルガン、ストリングス…）
    3 ベース DISTRHO Nekobi（303 風のベース）、またはサウンドフォントのベース（ウッド、アコースティック、指弾き、フレットレス、シンセ）
    4 リード Calf Monosynth、またはサウンドフォントの楽器（Rhodes、ヴィブラフォン、ギター、サックス、フルート…）
    5 SAMPLE KING · PAD SAMPLER（もう一度 5 を押すと切り替え） 8 スロットのサンプルバンクが 4 つ、または MPC スタイルの 16 パッド

    5 つのページは上部バーを共有します：キーとスケール、トランスポート、テンポとスウィング、LIVE FX、楽器、マスターボリューム。

    どのマシンも同じ部品でできています：

    • ミックスストリップ
    • MODS（音を形づくるノブ）
    • パターンエディター
    • SOUND EFFECTS のチェーン

    ソングは小節の頭で切り替わるセクションでできていて、セッション全体はプロジェクトに保存されます。

    インストール

    ravving は Zynthbox Store の Apps カテゴリーから AppImage として入手します。AppImage は Zynthbox の上にセットアップページを開き、4 つの選択肢を出します：TRY IT、MAKE IT THE DEFAULT、ZYNTHBOX AT BOOT AGAIN、REMOVE RAVVING。ravving を削除しても、プロジェクト、テイク、録音は残ります。

    演奏と編集

    いつも使うショートカット

    押すキー 動作
    ALT + ▲ どこからでもヘッダーへ移動
    ALT + ステップキー 1–8 LIVE FX のオン・オフ：DROP、NO KICK、ONLY KICK、CRUSH、LO PASS、HI PASS、STUTTER、LOOP
    ALT + ノブ 1–3 PHASER、ECHO、HEAVY
    ALT + 大ノブ マスターボリューム
    MODE 画面の楽器が OFF → LIVE → STEP + LIVE → OFF と切り替わる
    停止中に STOP パニック：鳴り続けている音をすべて止める
    マシンの S を長押し そのマシンだけをソロにする

    ALT を押している間、ステップキーがオレンジに光り、LIVE FX のパッドにキー番号が表示されます。

    ライブで演奏する

    MODE で LIVE をオンにすると、ステップキーが演奏できる鍵盤になります：

    • ベース、リード、コードの NOTES タブ：スケールが 16 個のキーに並びます。▲ ▼ でオクターブを変えます。
    • コードの CHORDS と SLOTS タブ：キーの 7 つのコードが並びます。

    ステップごとに音を書く

    STEP 入力は、演奏した音をカーソルの位置に書き込みます。

    • ◀ ▶ でカーソルを 1 ステップ動かします。
    • 同時に押したキーは同じステップに入るので、コードは 1 列にまとまります。
    • 停止中は SELECT で選んだ行をカーソル位置に書き込みます：音符、または CHORDS ではコード。
    • LIVE と STEP が両方オンのときは、▲ ▼ でオクターブではなく行を移動します。行に来るたびに音が鳴るので、先に耳で音を探せます。

    グリッドに触れる

    • 1 本指で横にドラッグすると小節をめくります。ピアノロールでは行を上下にもドラッグでき、8 半音を超えるとオクターブが変わります。
    • 2 本指でピンチしてズーム。
    • タップは今までどおり音符のオン・オフ。

    ポインターはマウスをつないでいるときだけ表示されます。

    プロジェクトの保存と読み込み

    • 最初の SAVE ではプロジェクト名を尋ね、画面キーボードが表示されます。
    • 2 回目以降の保存は上書きです。3 秒以内に SAVE を 2 回押します（AGAIN? と確認します）。
    • SAVED は保存後に変更がないという意味で、次に編集するとボタンが戻ります。
    • SAVE AS NEW は新しい名前を尋ねます。

    PROJECT ▾ にプロジェクトとデモが並びます。タップすると開きます。未保存の変更があるときは、もう一度タップして確定します。長押しか ★ でお気に入りになります。

    下の列はいつも開いているプロジェクトに働きます：NEW、TEMPLATES、IMPORT、次に SAVE AS NEW、そして EXPORT。

    元に戻す

    ヘッダーの ↶ ↷ はプロジェクト全体を前後に戻します。マシンのページでは ALT + ◀ ▶ でも同じです。複数のマシンを一度に変えた操作は 1 ステップとして数えます：CLEAR ALL や、ベースとリードを両方動かしたキーの変更など。

    マシンのツールバーにある ↶ ↷ は、そのマシンの変更だけを戻します。

    戻るもの：

    • パターンとスロット。
    • 構成：中身ごと削除したセクション、名前の変更、色、長さ、ソングの編集。

    戻らないもの：音色、ミックス、プロジェクトの設定。セクションを選ぶことも 1 ステップにはなりません。詳しくは元に戻す・やり直すへ。

    LOCK：うっかりタップで演奏中の内容を変えない

    LOCK はどのパターンツールバーでも最初のボタンです。オンの間、ノートグリッドには何も書き込まれません。セルのタップ、ステップキー、STEP 入力、SELECT の移動、ノートのノブはすべて受け付けず、LOCK が点滅して理由を知らせます。スクロール、ページ送り、試聴はできます。

    • PLAY で LOCK がオンになり、STOP でオフに戻ります。
    • 再生中に LOCK をタップすると編集できます。停止後もロック解除のままです。
    • 停止中に LOCK をタップするとグリッドをロックします。その後もロックされたままです。

    LOCK はすべてのページで共通で、テイク（●）は録音できます。

    思いきりヘドバンしよう。再生中は LOCK がビートを守ってくれる。

    SELECT：書いた音符を後から動かす

    SELECT はベース、リード、コードのパターンツールバーの ♭♯ の隣にあります。オンの間、グリッドをタップすると音符を書く代わりに選択します。もう一度タップで選択解除。伸ばした音の尾をタップすると、その音符が選ばれます。

    • ▲ ▼ で選んだ音符をすべてキーの 1 音ぶん上下に動かします。♭♯ がオンなら半音ずつ。長さ、アクセント、スライドも一緒に動きます。
    • 1 回の移動が元に戻す 1 ステップです。
    • コードのページでは、CHORDS ビューでコードを選んで 1 度ずつ動かします。NOTES ビューでは単音を選びます。伸ばしたコードは常にまとめて動きます。
    • SELECT を長押しすると全小節の音符（またはコード）をすべて選び、パターン全体を一度に動かせます。
    • SELECT をオフにすると選択が解除されます。

    1 つの音符を形づくる

    ベースとリードでは SELECT で音符を選び、ノブ 1–3 を回してまとめて変えます。グリッド右上の表示に、最初に選んだ音符の値がノブのバッジ付きで出ます。

    ノブ 設定 範囲 1 クリック
    1 LENGTH（明るいセル） 1 ステップから 4 小節 ステップ
    2 VELOCITY 1–127 4
    3 NUDGE（スウィングが置いた位置から） 半ステップ前から半ステップ後まで 1 ステップの 16 分の 1
    • セルの長押しでも音符の長さを設定できます。
    • ACCENT レーンのセルはベロシティに応じて塗られ、アクセント付きは明るい赤になります。そこをタップすると今までどおりアクセントが切り替わります：フル、または通常のベロシティに戻る。
    • Q をオフにした LIVE テイクは、ヒットごとに nudge を記録します。
    • これらの設定は音符と一緒に動き、1 クリックが元に戻す 1 ステップで、プロジェクトと保存したパターンプリセットに残ります。

    大ノブは音量のままで、フォーカスのあるダイヤルのグループは自分のノブを持ち続けます。

    SLOTS：コード単位で書く

    コードのページでは、SLOTS でコードを 1 つずつ組み立てられます：

    1. スロットをタップします。
    2. コードキーを弾きます。次のスロットが自動で待機します。
    3. 各スロットの長さを 1、2、4、8 小節から選びます。スロットの合計はパターンの 8 小節を超えません。「n / 8 BARS」の表示が数えます。

    スロットがコードのパターンを書き、PLAY で順番に鳴らします。いま鳴っているスロットが光ります。＋ で 4 つずつ最大 8 つまで増やし、− で減らします。

    CHORDS や NOTES ビューでパターンを変えると、ビューに PATTERN CHANGED と出てスロットが暗くなります。そのあとスロットを編集すると、パターンがスロットから作り直されます。元に戻すで編集を取り戻せます。

    ヘッダーと MIXER

    上部のヘッダーはすべてのページで共通です。ページのストリップから ▲ で移動し、◀ ▶ でグループを渡り、▼ か BACK でページに戻ります。

    キーとスケール

    左の ROOT と SCALE でプロジェクトのキーを決めます。メロディーのマシンはすべてそれに従い、ベース、リード、コードはそのキーで鳴り、キーを変えるとフレーズも一緒に動きます。スケール外の音には専用の設定があります（下の「スケール外の音」）。

    テンポとスウィング

    • BPM：テンポ。TEMPO グループにフォーカスがあるとき、ノブ 1 で設定します。ほかの機器が ravving のクロックを送っているときは、その機器のテンポを表示し、ここでは変えられません。
    • SWING：ノブ 2 で 50 %（イーブン）から 75 %（いちばん強いシャッフル）まで。ラベルをタップすると 8 分（SWING 8、ジャズ向け）と 16 分（SWING 16、ハウスやヒップホップ向け）を切り替えます。

    テンプレートとデモは、プロジェクトを始めるときに両方を設定します。

    LIVE FX

    演奏しながらミックス全体を変える 8 つのパッド。ヘッダーでタップするか、ALT を押しながらステップキー 1–8 を押します。

    パッド できること
    DROP 押している間はキックが消え、ハイパスがスイープで上がります。離すと両方戻ります。
    NO KICK、ONLY KICK キックをすべて消す、またはキック以外をすべて消す。片方をオンにするともう片方はオフになります。
    CRUSH ミックスをビットクラッシャーに通します。
    LO PASS、HI PASS フィルタースイープ：300 Hz まで下げる、または 950 Hz まで上げる。
    STUTTER 押している間、いまの 16 分音符を繰り返します。
    LOOP 押している間、いまの拍を繰り返します。

    NO KICK、ONLY KICK、LO PASS、HI PASS はタップでオン、もう一度タップでオフ。DROP と CRUSH は押している間だけ効き、0.5 秒押し続けると次にタップするまでオンのままです。CRUSH、STUTTER、LOOP の上でドラッグすると効き具合が変わります：ビット数を減らす、または繰り返しを短く・長くする。

    PHASER、ECHO、HEAVY はパッドの隣にあります。ALT を押しながらノブ 1–3 を回すと、どこからでも設定できます。

    ミックス全体を録音

    ALT + ● で、どのページからでもスピーカーから出ている音をすべて WAV として録音に保存します。RECORD のライトが赤くなります。もう一度 ALT + ● で停止。ファイルはミュージックプレーヤーにあります。

    録音は一度に 1 つだけです。これが動いている間、レコーダーではテイクを録れません。

    ミキサー

    ✱ で MIXER を開きます：すべての楽器を一度に、メーター付きのストリップで表示します。✱ か BACK で戻り、数字キーでそのページへ。

    • ストリップを選ぶには ◀ ▶ かステップキー。ステップのライトがストリップを示し、ミュートは暗く、選んだものは白です。
    • ノブ 1 でレベル、ノブ 2 でパン、大ノブで細かいレベル。
    • SELECT でミュート、ALT + SELECT でソロ。
    • ネームプレートをタップするとその楽器のページを開きます。

    SAMPLE KING

    ページ 5 には 2 つのサンプラーがあります。もう一度 5 を押すと SAMPLE KING と PAD SAMPLER が切り替わり、ravving は使った方を覚えています。

    SAMPLE KING には 8 スロットのバンクが 4 つ（A〜D）あり、バンクごとにパターンがあります。画面に出ているバンクが鳴ります。

    音を入れる

    スロット（グリッドの行）を選び、LOAD をタップしてサンプルを選びます。

    または録音します：● REC で本体の入力をそのままスロットに録音し、もう一度 ● で停止。テイクは最後の音のかたまりに合わせてトリミングされてスロットに入ります。INPUT でつないだ機器、ゲイン、モニターを設定します。

    形を整える

    • 波形の開始と終了のハンドルをドラッグします。波形にフォーカスがあるときはノブ 1 と 2 でも動かせます。
    • PITCH は上下 12 半音まで。
    • REVERSE で逆再生。

    スロットはワンショットで鳴り、もう一度鳴らすと前の音を止めます。

    チョップして演奏する

    • チョップ。CHOP と AUTO CHOP で波形エディターを開き、切った断片をバンクのスロットに並べます（波形エディターを参照）。
    • 鳴らす。ステップグリッドの各行がスロットで、下にアクセントの行があります。ノブ 1–3 で選んだ行のミュート、ソロ、レベルを設定します。ドラムと同じです。
    • ライブで鳴らす。LIVE をオンにするとステップキー 1–8 でスロットを鳴らし、キー 9 を押しながらでアクセント。MIDI キーボードでも鳴らせます。

    PAD SAMPLER

    4 つのバンク（A〜D）に 16 パッド、MPC のような配置です。画面でパッドを選ぶと、そのサンプル、ツール、設定がパッドの横に出て、16 ステップが下に並びます。

    音を入れる

    LOAD でパッドのサンプルを選びます。● REC で入力をパッドに録音します。SMART がオンなら、音が静かになると自動で止まります。どちらの場合も、最後の音のかたまりにトリミングされてパッドに入ります。

    • COPY でパッドを別のパッドにコピー。
    • CLEAR で空にします。
    • ERASE でパッドのヒットをパターンから消します。

    パッドの鳴り方

    • NOTE ON は押している間だけ鳴らします。オフならタップでサンプル全体を鳴らします（ワンショット）。
    • LOOP でループポイントから繰り返します。
    • REVERSE で逆再生。
    • MUTE で消音し、UNMUTE ALL ですべてのパッドを戻します。

    パッドを調整する

    タブごとに 3 つの設定がノブ 1–3 に割り当てられ、◀ ▶ でタブを切り替えます：

    タブ 設定
    TRIM 開始と終了
    MIX 音量とパン
    AMP ENV アタックとディケイ
    TUNE 半音、次に微調整
    PLAY モノかポリ、ミュートグループ
    FILTER タイプ、カットオフ、レゾナンス

    パッドをライブで演奏する

    LIVE をオンにすると 16 個のステップキーが 16 パッドになります。タップでパッドを鳴らし、0.5 秒押し続けるとラッチして、もう一度タップするまでループします。STOP でラッチしたループをすべて止めます。

    PAD FX：パッドが鳴っている間に ECHO、TAPE STOP、SCRATCH、STUTTER、SKIP、REVERSE を押すとエフェクトがかかります。離すと元に戻ります。

    16 LEVELS

    16 LVL をオンにすると、16 パッドすべてが選んでいたパッドを鳴らし、TYPE で振り分けます：

    • VELOCITY：弱から強へ。
    • TUNE：パッドごとに半音。
    • SCALE：プロジェクトのスケールを上へ。

    キットの MODS が、すべてのパッドの音量とチューニングを設定します。

    波形エディター

    2 つのサンプラーで共通です。CHOP はサンプルを 3 通りの方法で切ります：

    • REGIONS：等分に切る。
    • THRESHOLD：あるレベルより大きいヒットで切る。
    • MANUAL：波形をタップして切れ目を追加し、切れ目をタップして削除。

    AUTO CHOP はヒットで切った状態でエディターを開きます。エディターでは：

    • ◀ ▶ でチョップの種類を変え、大ノブで分割数かしきい値を設定します。
    • NORMALISE でサンプルを最大レベルまで上げます。
    • TRIM で両端の無音を削ります。
    • APPLY で断片をバンクのスロットかパッドに送ります。

    取り消しとやり直し

    プロジェクトの履歴は 1 つです。ヘッダーの ↶ ↷（マシンのページでは ALT + ◀ ▶）で前後に移動し、トーストが各ステップの名前を出します（「UNDO · CHORDS + BASS」）。パターンツールバーにあるマシン自身の ↶ ↷ は、履歴のどこにあってもそのマシンの最後の変更だけを戻します。

    • 元に戻るもの：各マシンの音符、ステップ、コード、スロット、アクセント、スライド、長さ、オートメーション、ライブのタイミング、そして構成：どのセクションがあるか、その順番、名前、色、長さ、ソング。削除したセクションは中身ごと元の場所に戻ります。
    • 戻らないもの：音色、ミックス、エフェクト、プロジェクトの設定（テンポ、スウィング、キー）。セクションを選ぶことも 1 ステップにはなりません。
    • 1 ステップ：複数のマシンを一度に変える操作は 1 ステップです。CLEAR ALL や、ベースとリードを動かすキーの変更など。続けて素早く行った変更（ノブを回す、ハンドルをドラッグする）や、録音したテイク全体も 1 ステップです。
    • 履歴は直近の 100 ステップを保持し、プロジェクトを開いたり新しく始めたりするとリセットされます。

    音源

    ベース、リード、コードは専用シンセの音でなくてもかまいません。ネームプレートをタップすると、そのマシンの音色が開きます：

    • まず専用のエンジン：BASS は 303、LEAD は Calf Monosynth、CHORDS は TAL NoiseMaker とそのファクトリーサウンド。
    • 次にサウンドフォントの楽器。本体のサウンドフォントを FluidSynth で鳴らします：ウッドベースなどのベース、Rhodes、ヴィブラフォン、オルガン、ストリングス、サックス、フルートなど。

    選ぶとエンジンが入れ替わります。サウンドフォントの音色には専用の MODS があります：FILTER、ENVELOPE、MOTION。選択はプロジェクトに保存されます。

    ジャズなどのためのアコースティック音色

    マシン 音色
    コード Grand piano（Fazioli）、Upright piano（Kawai）、Jazz guitar
    リード Alto sax、Tenor sax、Grand piano
    ベース Upright

    ドラムマシンのキット選択には ACOUSTIC グループもあります。FluidR3 サウンドフォントの General MIDI キットです：Jazz と Brush（ライドとハイハットのフットを行に入れたもの、またはクラッシュ入り）、Standard、Room。

    ジャズらしく聴かせるコツがあと 2 つ：

    • ベースやリードの音符は 1 ステップより長くできます。セルを長押しすると、その行の音符がそこまで伸びます。
    • ヘッダーのスウィングのラベルをタップすると、8 分（SWING 8）と 16 分（SWING 16）を切り替えます。

    CHORDS のパッドとテクスチャ

    CHORDS にはイメージ付属のパッド系サウンドフォントもあり、選択画面で名前ごとにまとまっています：

    • Strings：Ensemble、Fat、Digital、Rise、Bowed、Piano。
    • Organ：Phaser、Pipe 16+8+4、House、Extreme。
    • Alien（「Ambients & Drones」のフォントから）：The Thing、Strange voices、Crystal voice、Glassy、Winds、Chaos、The Pulse。

    伸ばして重ねるポリフォニックなマシンに合います：ボイシングが続く間コードが鳴り続け、キーがベースやリードと音程をそろえます。

    音色の選択画面は GROUP チップでリストをまとめ、★ でお気に入り（星か ALT + SELECT）、SORT で一覧順か A–Z。グループと並び順は楽器ごとに記憶されます。

    音色付きのパターンプリセット

    パターンツールバーの PRESET を開きます。SAVE CURRENT AS NEW は、パターンとマシンの音色（ソースまたはファクトリーサウンドと MODS）を一緒に保存します。ドラムではキットとキットの MODS を保存します。

    パックごとに独自のグルーヴと、そのために作られた音色が付いてくる。

    保存するときは 2 つのスイッチで中身を決めます。ダイアログを開くたびに両方オンになっています：

    • WITH ITS SOUND：鳴っているソースまたはキット。
    • WITH ITS MODS：設定した MODS。誰も回していないノブは含まれません。

    両方オフなら、パターンだけを保存します。

    音色付きのプリセットは、ジャンルの下に ♪ と音色名が、MODS があれば「+ MODS」が表示されます。

    プリセットを読み込む

    プリセットダイアログ上部の 3 つのスイッチで、プリセットが持ち込むものを決めます：

    • WITH ITS SOUND（初期値はオフ）は、マシンをプリセットの音色に切り替えます。
    • WITH ITS MODS（初期値はオフ）は、プリセットの MODS のうち指定された部分だけを設定します。MODS のないプリセットはあなたの設定をそのままにします。
    • WITH ITS BARS（初期値はオン）は、プリセット自身の小節数を持ち込みます。オフなら、プリセットを最初の小節からいまの小節数に重ねます：短いプリセットは繰り返し、長いものは切ります。

    SOUND をオンにすると MODS もオンになります。音色は MODS と一緒に聴くものだからです。そのあと MODS だけをオフにもできます。MODS だけオンなら、プリセットの MODS をいま鳴っている音色に適用します。すべてオフならパターンだけを読み込みます。選択は記憶されます。

    SOUND と MODS はハイライトされたプリセットに従います：音色のないプリセットでは WITH ITS SOUND が、MODS のないプリセットでは WITH ITS MODS が薄くなり、それを持つプリセットでまた点灯します。

    プリセットの音色に含まれるもの

    本体にプリセットのソースやキットがなければ、音色のその部分はそのままです。サンプラーのプリセットは音色を持ちません。音はバンクの中にあるからです。ravving 付属のプリセットも音色を持ちません。USB メモリーにコピーしたプリセットは、ファイルの中に音色を持っています。

    プリセットを探す

    プリセットダイアログは音色の選択画面と同じように使えます：

    • ジャンルごとの GROUP チップと、SORT：一覧順か A–Z。
    • ★ お気に入り：プリセットを長押しするか、角の ★ をタップするか、ALT + SELECT。お気に入りは楽器ごとにプリセット名で記憶されるので、USB メモリーのプリセットと本体にコピーした同じプリセットは ★ を共有します。

    前回見たグループでは画面のプリセットが隠れてしまう場合、ダイアログは ALL で開きます。

    テンプレート

    テンプレートはプロジェクトの始め方です：テンポ、スウィング、キー（ルートとスケール）、LIVE FX のノブ（PHASER、ECHO、HEAVY）。

    1. PROJECT ▾ → NEW の隣の TEMPLATES を開きます。
    2. SOURCE を選びます：本体、または USB メモリー（ravving/presets/templates/ フォルダーから直接読み込み）。
    3. テンプレートを選ぶと、その設定で新しいプロジェクトが始まります。未保存の変更があれば、NEW と同じく先に確認します。

    SAVE TEMPLATE でいまのセッションの設定を本体にテンプレートとして保存し、DELETE で削除します。USB ダイアログの PRESETS でテンプレートを双方向にコピーできます。どのジャンルパックにもテンプレートが付き、キーごとに用意したパックもあります。

    新しいプロジェクトはまっさらから

    NEW は、テンプレートの有無にかかわらず、すべてのページを初期状態に戻します：

    • 各マシンに空のパターン（プリセットなし）
    • 各マシンの専用エンジンと、初期値の音色、ミックス、MODS、SOUND EFFECTS
    • テンポ 120、スウィングなし（イーブン）、キーは C ナチュラルマイナー
    • LIVE、STEP、AUTO、LOCK はオフ
    • セクションは「A」の 1 つ
    • LIVE FX は休止状態

    テンプレートはその上にテンポ、スウィング、キー、LIVE FX のノブを加えるだけです。デモのパターンはプロジェクトかプリセット経由でしか戻りません。

    デモ

    ravving にはデモプロジェクトがいくつか付いています（PROJECT ▾ → DEMOS）。イメージ付属のサウンドフォントだけを使うので、どの MIKO でも同じ音で鳴ります。

    デモはほかのプロジェクトと同じように開けます。SAVE で変更をデモの名前の自分のプロジェクトとして保存します。デモそのものは変わらず、削除もできません。

    セクションとソング

    ソングはひとつのループ以上のものです。セクションはすべてのマシンのパターンをまとめて持ち（イントロ、ヴァース、ブリッジ）、どのマシンが休むかも決めます。音色、エフェクト、レベル、テンポ、キーはプロジェクト全体のものなので、セクションを変えてもエンジンは再起動しません。

    セクションはライブです：画面のセクションが編集対象で、別のセクションを選んでも編集はそのセクションに残ります。最大 16 個まで作れ、プロジェクトに保存されます。

    セクションを選ぶ

    • ALT + ステップキー 9–16 でどのページからでもセクション 1–8 を選べます。ALT を押している間、セクションの色で光ります。ALT + 1–8 は LIVE FX のパッドのままです。
    • 大ノブの横にある X と Y で、どのページやダイアログからでも前後のセクションへ移動し、端まで行くと反対側に戻ります。切り替わる前にもう一度押すと、キューに追加せず選択をさらに進めます。セクションが 1 つだけなら、SONG ページで追加するようメッセージが出ます。
    • SONG ページ（下）にはセクションごとのキーがあります。

    再生中は、選んだセクションが次の小節の頭でぴったり切り替わります：音が抜けたり重なったりせず、パートが変わらないマシンはそのまま鳴り続けます。停止中はすぐに切り替わります。

    切り替えのタイミング：BAR か SECTION

    SONG ページの SWITCH 設定はプロジェクトに保存されます：

    • BAR：選んだセクションが次の小節から始まります。
    • SECTION：鳴っているセクションが 1 周し終えるのを待ち、その小節の頭で切り替えます。その間キーが点滅し、鳴っているキーは点灯したままです。待っているセクションをもう一度選ぶとキャンセル、停止すると即座に切り替わります。1 小節のセクションは毎小節で終わります。

    切り替えは必ず小節の頭で起こり、小節の途中では起こりません。

    セクションをキューに入れる

    LOOP では選択を3 つまで並べられます。それぞれ 1 周鳴って次に移り、最後のものがループし続けます。

    • キーにはキューの順番が表示されます：点滅する 1 が次です。
    • キューにあるキーをもう一度選ぶと、キューから外れます。
    • 鳴っているセクションを選ぶと、ほかのセクションのあとにもう一度キューに入ります：4 が鳴っているなら、2、3、そして 4 の順に鳴ります。
    • 4 つ目の選択は QUEUE FULL で断られます。
    • 停止すると最初のものが入り、残りは消えます。

    SONG では待機できる選択は 1 つだけで、新しく選ぶと置き換わります。

    マシンごとの LOOP か ONCE

    各マシンのストリップには ❚❚ の隣に LOOP | ONCE ボタンがあり、❚❚ と同じくセクションごとに保存されます。

    セクションの長さは最も長いパターン、または LENGTH で設定した長さです。短いパターンは初期設定で LOOP します：4 小節のリードの下で 2 小節のドラムが 2 回鳴ります。ONCE なら自分の小節を 1 回鳴らし、セクションが再び始まるまで休みます。

    休みは小節の頭ちょうどから始まり、鳴っている音は自然に消えます。休んでいる間は再生位置が表示されず、ライブで弾いた音は聞こえますが書き込まれません。

    いまどこにいるか

    • プレート：ヘッダーのプロジェクトプレートに、画面のセクションが番号付きの四角いキーとしてその色で表示されます。小節の頭を待つ間は点滅します。タップで SONG ページを開きます。
    • セクションが変わると、プレートがその色で流れ、楽器ページの枠が一度光ります。
    • セクションキーは、ここでも SONG ページでも、セクションの進み具合で満ちていきます。

    ヘッダーにセクションキー

    プロジェクトプレートを長押しするか ALT + MODE を押すと、ヘッダーの LIVE FX パッドがセクションキーに入れ替わります。もう一度でパッドに戻ります。ALT を押している間 MODE はオレンジに光り、MODE だけなら入力モードの切り替えのままです。

    • キーをタップして選びます（再生中は次の小節で）。▶ が鳴っているキーを示し、進み具合で満ちていきます。
    • キーを上にスワイプするとそのセクションを削除します。指についてきて、高さの半分を超えると飛んでいきます。最後のセクションは削除できません。
    • 入りきらないときは横にスワイプします。ストリップは、現在のセクションやソングが到達したセクションまで自動でスライドします。
    • ＋ はストリップの最後に固定されています。

    キーがヘッダーにあるときは ALT + 1–16 でセクション 1–16 を選びます。ヘッダーのセクショングループにフォーカスがある間（◀ ▶ で移動）は、ステップキーだけで選べます。

    ソングページ

    どこからでも ALT + 1 で開き、もう一度押すと戻ります。MIXER と同じくヘッダーの下に表示されます。数字キーでも抜けられ、元のページが同じドラムマシンのまま戻ります。

    セクションは番号と名前の付いた四角いキーで、1 列に 8 つ並びます。1 列目は ALT キーに対応します。各キーには、そこで鳴るマシンごとに点が付きます。

    • タップでセクションを選び、ダブルタップで名前を変え、長押ししてドラッグで移動。
    • × は 2 回目のタップで削除します。
    • ＋ で画面のセクションをコピー（A が A′ になります）。

    新しいセクションは、空（NEW）でもコピー（＋）でも、ソングの最後に加わり画面に表示されます。

    セクションの上の列には RENAME、NEW（空のセクション）、COLOUR、LENGTH（1–8 小節、または最長パターンに合わせる AUTO）、MOVE、ADD TO SONG があります。

    ソングはブロックの列で、各ブロックの幅は小節数×リピート数です。ブロックを選んで移動、リピート（×1〜×16）の設定、削除ができます。

    ▲ ▼ セクションキーとソングの間を移動
    SELECT かステップキー 選択

    ソング全体を再生する

    SONG ページの LOOP | SONG で、PLAY が鳴らすものを決めます：画面のセクションをループするか、ソングを最初から最後まで。

    • SONG では各パートが時間どおりに準備され、ソングは終わりの小節の頭で止まります。鳴っているブロックに進み具合が出て、プレートにパートが「6/9」のように表示されます。
    • 楽器のページはソングに従います。再生中はいつもどおりノートグリッドがロックされます（LOCK を参照）。ロックを外して編集すると、鳴っているセクションに入ります。
    • ▶ PLAY FROM HERE で好きなブロックからソングを始めます。
    • ソング再生中に手でセクションを選ぶと、そのセクションの最初のパートへジャンプします。ソングで使っていないセクションなら LOOP に戻ります。

    全部を録るには EXPORT → WHAT：SONG でソング全体を余韻付きで 1 テイクに録ります。LOOP なら BARS × LOOPS を録ります。

    言語

    ravving は英語、スペイン語、日本語に対応し、それぞれのミュージシャンの言葉を使います：BATERÍA、BOMBO、COMPÁS、ドラム、キック、小節。

    MENU → SETTINGS → LANGUAGE で選びます。初期値の SYSTEM は本体の言語に従います。画面はすぐに切り替わります。

    本体に印刷されたキー（MENU、ALT、SELECT…）とマシンの名前は印刷どおりのままです。ウェブページにもスペイン語と日本語のページがあり、上部バーで切り替えられます。開発者向けドキュメントは英語です。

    書き出しとミュージックプレーヤー

    PROJECT ▾ → EXPORT でプロジェクトを本体の外へ、ライブラリの exports/ フォルダーに書き出します。2 種類あります。

    トラック

    スピーカーから聞こえるとおりの曲全体。ravving はプロジェクトを最初の拍から BARS × LOOPS 小節ぶん鳴らし、エコーのための TAIL を加えて、サンプル単位で正確に切って録音します。

    • 形式：24 ビット WAV、FLAC、OGG Vorbis、MP3。
    • タグ：タイトル、アーティスト、アルバムまたはミックステープ、ジャンル、作曲者、コメント、日付、BPM。
    • カバー画像：タイトルとアーティストから描き、MADE WITH RAVVING を添えます。
    • JSON ファイル：同じ情報を横に保存します。

    マスターのレベルはそのまま保ちます。フルスケールを超える曲は −0.1 dBFS まで下げ、JSON ファイルにそう記します。

    ARTIST と COMPOSER はプロフィールの作者（MENU → SETTINGS：USER と AUTHOR）から始まります。前回入力した ALBUM と GENRE がまた候補に出ます。

    バンドル

    使っているサンプルをすべて含めたプロジェクトの .ravv zip で、ほかの ravving でもまったく同じに鳴ります。PROJECT ▾ → IMPORT で exports/ と、転送が届くライブラリのメインフォルダーにあるバンドルが並び、プロジェクトに戻せます。

    スケール外の音

    MENU → SETTINGS → INTERACTIONS に NOTES OUTSIDE THE SCALE があり、初期値はオンです。キー外の音を弾いたとき（MIDI キーボードなどで、リード、ベース、コードの NOTES で）の動作を決めます：

    • オン：音が鳴って記録され、ピアノロールの専用の行に入ります。
    • オフ：そこでは消音され、記録されません。

    ドラム、サンプラー、度数で弾くコードはこの設定に関係しません。

    ビデオ録画とコンピューター接続

    コントロールセンターの LIVE REC カードでセッションを録画します。

    録画を始める

    1. LIVE REC をタップします。ダイアログで WHAT（何を録るか）を聞かれます：
      • VIDEO：画面か USB カメラの映像とマスターの音。ライブラリの videos/ フォルダーに MP4 で保存します。
      • AUDIO ONLY：音だけ。書き出しフォルダーの TRACKS に 24 ビット WAV で保存します。
    2. MIC を入れるかどうかを選びます。
    3. START をタップします。ダイアログが確認を兼ねるので、うっかりタップで録画が始まることはありません。

    LIVE REC がオンの間は、どのページからでも本体の RECORD キーで録画を始め、STOP で終えます。音楽は鳴り続けます。新しいプロジェクトにすると LIVE REC はオフになります。

    ビデオの設定

    SETTINGS · VIDEO には次があります：

    • QUALITY：3 段階。どれも音に負担をかけません。
    • TIMER：録画開始前のカウントダウン。
    • SOURCE：画面か USB カメラ。
    • MIC：レコーダーの入力をビデオの音に加えます。
    • VOICE：ボイスオーバーのミックス（下を参照）。

    録画中のものにも反映されます。

    音楽に声を重ねる

    MIC を入れると、ravving は声を音楽の上にミックスします：

    一緒に歌おう。声が入ると音楽が下がり、止めると戻ってくる。

    • 話している間は音楽が声の下に下がります：DUCK は −6、−12、−18 dB で、初期値は −12。
    • 声は +6 か +12 dB 上がり、ローカットとプレゼンスの持ち上げで聞き取りやすくなります。
    • ravving は声とスピーカーからマイクに回り込む音を聞き分けるので、ビート自身で音楽が下がることはありません。
    • リミッターがミックスのクリップを防ぎます。

    VIDEO をオンにした時点から、マイクの LEVEL が SETTINGS とプロジェクトプレートに表示されます。MIC TOO HOT はピークが −6 dBFS を超えているという意味なので、レコーダーの GAIN を下げます。レコーダーが GUITAR か LINE なら、入力はそのままミックスされます。

    録画が終わったら

    VIDEO SAVED か LIVE REC SAVED に次があります：

    • DELETE（左）。3 秒以内にもう一度タップで確定。
    • RENAME。拡張子はそのままです。
    • SEND…：USB メモリー、コンピューター、スマホへ。
    • METADATA…（音声の録音のみ）。ファイルに対して書き出しダイアログを開き、タグ付け、カバーの作成、WAV・FLAC・OGG・MP3 での保存ができます。

    同じ SEND… はミュージックプレーヤーの曲、FILES、プリセットのダイアログにもあります。書き出しダイアログでは、新しい曲やバンドルを書き出しながらコンピューターへ送ることもできます。

    コンピューター

    SETTINGS · COMPUTERS には、ネットワーク上のノート PC やパソコンを何台でも登録できます。

    1. ADD A COMPUTER をタップします。
    2. ホスト名、ユーザー名、パスワードを入力します。パスワードは一度だけ、本体の鍵をそのコンピューターにインストールするのに使います。
    3. 送ったファイルはそのコンピューターのダウンロードフォルダーに届きます。

    各コンピューターに CHANGE（設定し直す）、TEST、FORGET があります。

    スマホに送る

    どの SEND… ボタンにも、USB メモリーとコンピューターの横に 3 つ目の送り先 PHONE · QR CODE があります。SEND… は FILES、VIDEO SAVED、ミュージックプレーヤー、プリセットのダイアログ、音色の選択画面にあります。iPhone を含むどのスマホでも、ペアリングもアプリもアカウントも不要です。

    1. スマホが本体と同じ Wi-Fi にあることを確認します。本体がネットワークにつながっていなければダイアログが知らせます。
    2. PHONE · QR CODE をタップすると QR コードが出ます。
    3. スマホのカメラを向けてリンクを開きます。
    4. Safari か Chrome がファイルをスマホのダウンロード（iPhone ではファイル App）に保存します。

    ダイアログには WAITING FOR THE PHONE、SENDING n %、DOWNLOADED ✓ と表示され、ファイル全体が届くとメッセージで知らせます。入力したい人のために、リンクも文字で表示されます。

    • リンクはダイアログが開いている間、最大 15 分間使えます。ダイアログを閉じると終わります。
    • 送れるのは 1 回に 1 ファイルです。複数渡すと最初のものを送り、その旨を伝えます。

    スマホで見る ravving のページ

    同じサーバーで ravving のページ（説明、機能、すべてのショートカット）も見られます。本体にはブラウザーがないので、SETTINGS → HELP → OPEN でスマホ用の QR コード、またはノート PC 用のアドレスとして表示します。

    QR コードは公開ページ https://ravving.github.io/ を指し、どこからでも開けます。インターネットのない Wi-Fi 用に、本体のアドレス（http://<device>:8098/help/）がその下にあります。

    ファイル

    コントロールセンターの FILES カードには、ライブラリのすべてが種類ごとに新しい順で並びます：プロジェクト、テンプレート、プリセット、サンプル、テイク、レコーダーのテイク、録音、曲、バンドル、サウンドフォント、MIDI ファイル、ビデオ、受信したファイル。

    各ファイルに SEND…（USB メモリー、コンピューター、スマホ）と DELETE があります。ファイルを本体から出したり削除したりできるのは FILES だけです。PROJECT ダイアログは開く・保存・書き出しを、USB ページは USB メモリーからの取り込みを担当します。

    スマホから見る

    FILES の上にある PHONE · BROWSE で QR コードを表示し、同じ Wi-Fi のスマホやノート PC でライブラリをウェブページとして開けます：

    • 種類ごとのファイル数
    • 種類ごとのファイルと、その詳細、サイズ、日付
    • ファイルごとの DOWNLOAD ボタン

    プロジェクトなどフォルダーのものは「本体上」と表示されます。リンクは、スマホから 15 分間何も要求がなくなるまで、ダイアログを閉じても開いたままです。その後はスマホにリンクの期限切れが表示されます。

    USB メモリー

    USB メモリーを挿すと、ravving が必要なときにマウントします。終わったら EJECT（書き出しダイアログか USB ページ）を押し、安全になってから抜きます。

    USB メモリーに保存する

    • 書き出し：USB メモリーは書き出しダイアログに USB の行として表示されます。曲やバンドルはいつもどおり本体に保存され、USB メモリーの ravving/exports/ か ravving/projects/ フォルダーにもコピーされます。
    • 保存したプロジェクト：FILES から送ります。SEND… が USB メモリー用のバンドルにまとめます。
    • USB メモリーからプロジェクトを開く：PROJECT ▾ → IMPORT に、本体のものと並んで、挿しているすべての USB メモリーのバンドルが表示されます。

    USB ページ

    ドロワーの USB カードで USB ページを開きます。2 つの面があります：

    • ON USB は USB メモリーの中身を種類ごとに表示します：SAMPLES、SOUNDFONTS、PROJECTS、TRACKS、MIDI FILES。IMPORT をタップすると本体にコピーし、✓ ON DEVICE と表示されます。
    • FROM DEVICE はライブラリを表示し、各ファイルに TO USB があります。

    フォルダーパスの横の IMPORT ALL で、画面のフォルダーの新しいファイルを一度にすべてコピーします。サンプルパック丸ごとでもワンタップで、進行状況と STOP ボタンが出ます。

    取り込んだファイルの行き先：

    種類 場所
    サンプル samples/imported/<stick>/（USB メモリーのフォルダー構成のまま）
    サウンドフォント soundfonts/
    MIDI ファイル midi/
    曲 exports/（ミュージックプレーヤーが見つける場所）
    プロジェクト バンドルとして取り込み

    本体のキーでは：◀ ▶ で種類、ALT + ◀ ▶ で面を切り替え、▲ ▼ でファイルを選び、SELECT でコピー。EJECT はヘッダーにあります。

    USB メモリーのパターンプリセット

    パターンツールバーの PRESET を開きます。USB メモリーを挿していると SOURCE の行が出ます：DEVICE、または USB · とメモリーの名前。メモリーを選ぶと、そのマシン用のプリセットが表示され、コピーせずにそのまま鳴らせます。元に戻す 1 ステップでパターンが戻ります。

    ダイアログはいまのパターンの出どころで開き、そのプリセットに印が付きます。

    USB メモリーのサウンドフォント

    取り込んだサウンドフォントはすぐに使えます：

    • ドラムキットらしければ、キット選択の IMPORTED に入ります。
    • 中のプリセットはそれぞれコード、ベース、リードの音色になり、「フォント名 · プリセット名」として、フォントごとにまとめて表示されます。

    複数の USB メモリー、またはロックされたもの

    USB メモリーやパーティションが複数あると、USB カードがそれぞれの名前を出し、どれを開くか尋ねます。

    読み取り専用の USB メモリー（ロックされたもの、インストーラーのイメージ）はその旨を表示します。何もコピーされず、ページに FORMAT が出ます。FORMAT はメモリー全体を消去し、RAVVING という名前の書き込み可能な FAT32 パーティション 1 つにします。EJECT と FORMAT は、3 秒以内にもう一度押す必要があります。

    Bluetooth

    MENU → BLUETOOTH にデバイスが並びます：接続中のもの、ペアリング済みのもの、範囲内のものの順です。ペアリング済みで未接続のデバイスには「paired · not connected」と表示されます。

    デバイスを探してペアリングする

    1. Bluetooth をオンにします。
    2. SCAN をタップします。スピーカー、ヘッドホン、スマホ、コンピューターを短時間で探します。
    3. デバイスをタップして行を開き、PAIR をタップします。
    4. ravving が上部で尋ねたら、パスキーを確認するか PIN を入力します。

    スピーカーが鳴っている間は SCAN が自動で始まりません。本体の共有の無線でスキャンすると Bluetooth の音が途切れるからです。VISIBLE にすると 3 分間スマホから本体が見つかり、ファイルを送ってもらえます。

    デバイスの行でできること

    • CONNECT / DISCONNECT。
    • SEND… で書き出した曲やバンドルを送ります。進行状況は下に出ます。
    • PLAY THROUGH でスタジオの音をすべてスピーカーやヘッドホンに送ります。DEVICE OUTPUT で戻します。同じ選択はドロワーの AUDIO OUTPUT カードにも、ジャックや HDMI と並んであります。
    • SBC-XQ でこのデバイスの音質を選びます：オンなら SBC-XQ（データ量が多く音がきめ細かい）、オフなら通常の SBC（接続が弱くても安定）。設定していないデバイスは SETTINGS に従います。SBC-XQ でスピーカーの音が割れるなら、そのスピーカーだけオフにします。
    • FORGET でペアリングを解除します。

    スマホから送られたファイルはライブラリの incoming/ フォルダーに届きます。バンドルは PROJECT ▾ → IMPORT に、曲はミュージックプレーヤーの「Received」に表示されます。

    デバイスがつながらないとき

    スリープ中、起動中、スマホとつながっているスピーカーには、約 35 秒の間にあと 3 回呼びかけます。その間、行には「waking…」と表示され、DISCONNECT で試行をやめます。それでも応答がなければ、ravving は NOT ANSWERING: FREE IT FROM A PHONE, OR TURN IT OFF AND ON と表示します。

    スピーカーがうとうと？ravving はあきらめる前にあと 3 回呼びかけるよ。

    オーディオデバイスは一度に 1 台

    鳴らせるスピーカーやヘッドホンは一度に 1 台だけです。鳴っている間に 2 台目をつなぐと音がそちらに移り、1 台目は切断されます。

    Bluetooth がオンになると、ほかに何も鳴っていなければ、ravving は前回選んだ出力に一度だけ再接続します。

    音楽を送っている Bluetooth 出力が無音になったら、ravving が自動でもう一度音を送ります。それでも音が戻らなければ、お知らせセンターが知らせます。

    MIKO に入っている Zynthbox は Bluetooth に少し設定が必要ですが、ravving のセットアップが行います。

    ミュージックプレーヤー

    MENU → MUSIC PLAYER は、書き出した曲と ● の録音のためのフルスクリーンのプレーヤーです。DASHBOARD で戻ります。

    • 左：TRACKS、ALBUMS、ARTISTS。
    • 右：カバー、トランスポート、再生位置、音量、その下に QUEUE。
    キー できること
    1, 2, 3 ビューの切り替え
    ▲ ▼ 曲を選ぶ
    選択 再生
    PLAY 一時停止
    STOP 停止
    大ノブ 音量
    ノブ 1 曲の再生位置
    BACK 閉じる

    プレーヤーを開くとビートが止まり、閉じるとプレーヤーが止まります。

    オーディオ出力

    MENU → AUDIO OUTPUT でスタジオの音の出力先を選びます：

    • 本体のジャック（初期値）
    • HDMI
    • BLUETOOTH ダイアログでつないだ Bluetooth スピーカーやヘッドホン

    音は 1 か所からだけ、途切れずに出ます。ダイアログを開いている間、機器をつなぐとリストが更新されます。ミュージックプレーヤーも選んだ出力に従います。

    選択は記憶されます

    出力がなくなると（ヘッドホンの電源を切ったときなど）、音はジャックに戻ります。再起動や再接続で出力が戻ればすぐに切り替わります。Bluetooth の出力では、Bluetooth がオンになったときに再接続できるよう ravving がアドレスを覚えておきます。ジャックを選ぶと記憶は消えます。

    音量と音質

    • ドロワーの OUTPUT スライダー（ノブ 2）でレベルを設定します：ジャックではアンプのレベル、それ以外は出力自体のレベル。
    • ドロワーの BRIGHTNESS スライダー（ノブ 1）で画面の明るさを設定します。画面が真っ暗なのは、たいていこれが最小になっているだけです。
    • SBC-XQ：ペアリングしたスピーカーやヘッドホンには、BLUETOOTH ダイアログにそれぞれ SBC-XQ のチップがあります。オフなら通常の SBC で鳴り、接続が弱くても安定します。個別に選んでいないデバイスは SETTINGS に従います。

    音楽を送っている出力が 6 秒間無音なら、ravving は一度だけ音を送り直します。それでも無音なら、お知らせセンターが知らせます。

    レコーダー

    MENU → RECORDER は、入力から演奏をそのまま録音するフルスクリーンのページです。ビートは鳴り続けるので、その上にテイクを録れます。

    入力を設定する

    • 入力：MIC、GUITAR、LINE のタブ。
    • MONITOR とその LEVEL で自分の音を聞きます。
    • GAIN：メーターとジャックのライト付き。
    • ● REC：入力レベルのグラフの横。

    KEEP TAKES IN でテイクの保存先を決めます：

    • SAMPLES（samples/recordings）：サンプラーのブラウザーが見つける場所
    • TRACKS（ライブラリの recordings）：ミュージックプレーヤーが見つける場所

    テイクは入ってきたとおりに保存します：圧縮もトリミングも SMART での停止もなし。

    入力用のエフェクト

    EFFECTS の列には入力用のエフェクトがあります。GUITAR ではアンプとペダル：AMP、OVERDRIVE、FUZZ、TUBE、WAH、HOT AMP。

    録音

    右には両方の場所の RECORDINGS が新しい順に並びます。それぞれに次があります：

    • ▶ PLAY。
    • TRIM と NORMALISE：横に新しい録音を作ります。
    • TO SAMPLE KING / TO PADS：スロットかパッドへ。
    • CHOP…：波形エディター経由で SAMPLE KING のバンクかパッドへ。
    • TO TRACKS / TO SAMPLES、RENAME、DELETE（2 回）。

    チューナー

    GUITAR のページにはチューナー（TUNER）があります。エフェクトの前の入力を聴いて、音名と何セントずれているかを ±50 の目盛りで表示します。チューニングの弦がボタンになっています。

    • AUTO は低い弦から順に進みます。3 セント以内を 0.8 秒保つと ✓ が付いて次の弦に移り、ALL STRINGS IN TUNE まで続きます。
    • MANUAL はタップした弦にとどまります。
    • TUNING でチューニングを選び、A4 で基準音（430–450 Hz）を設定します。
    楽器 チューニング
    ギター スタンダード、半音下げと全音下げ、ドロップ D と C、DADGAD、オープン D・G・E・C
    ベース 4 弦と 5 弦、ドロップ D
    ウクレレ GCEA、バリトン

    チューナーは画面に表示している間だけ動きます。

    問題センター

    メニューの ISSUES カード（MUSIC PLAYER、SETTINGS、USB カードの隣）は、いま本体で起きている問題を、わかりやすい言葉と対処法で知らせます。

    • ALL GOOD：問題なし。
    • それ以外は問題の数を、いちばん深刻なものの色で表示します。

    タップすると深刻な順に一覧が出ます。それぞれに詳細と提案があり、役立つときは RESTART RAVVING などのボタンも付きます。新しいエラーや警告はメッセージでも表示されます。

    見ているもの：

    • サウンドエンジンがない、またはエンジンが起動できなかった
    • 現れなかったオーディオ接続や、音切れ
    • 本体のキーが反応しなくなった
    • ミュージックプレーヤーが再生できない
    • Bluetooth が使えない、または音が出ない出力
    • 失敗した書き出し、マウントできない USB メモリー、ほぼいっぱいのストレージ

    ファイルの保存場所

    ravving は自分のフォルダーだけを使います：本体のサンプルライブラリを読み、書き込むのは次の場所だけです：

    ルート 本体上 内容
    config ~/.config/ravving 設定（入力の設定、UI の選択）
    state ~/.local/state/ravving ライブセッション（session.json、シーケンス）。パージで削除
    cache ~/.cache/ravving 作り直せるもの：逆再生サンプル、生のテイク、LV2 ポートのキャッシュ
    library /zynthian/zynthian-my-data/ravving ユーザーの作品（再インストールしても残る）：projects/、presets/、samples/（テイクは samples/takes/、レコーダーのものは samples/recordings/、取り込んだバンドルのサンプルは samples/imported/）、recordings/（マスターとレコーダーの TRACKS）、exports/

    デスクトップではライブラリは ~/.local/share/ravving です。
