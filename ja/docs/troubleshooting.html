    再生 / guide/troubleshooting.md

    困ったときは

    音が出ない、画面が暗い、Bluetooth、USB メモリー、録音：確認すること、すること。

    まずメニューの ISSUES カードを見ましょう。ALL GOOD か、問題の数が一番深刻なものの色で表示されます。タップすると深刻な順に一覧が出て、それぞれに対処法と、役立つときは RESTART RAVVING などのボタンがあります。

    よくあるものを、気づいた症状ごとにまとめました。

    音が出ない

    • マシンがミュート、ソロの対象外、または一時停止になっていない？ストリップの S、M、❚❚ を見るか、✱ で MIXER を開きます。
    • マスターが下がっていない？どこからでも ALT + 大きなノブで調整できます。
    • 音はどこへ出ている？MENU → AUDIO OUTPUT でジャック、HDMI、Bluetooth 機器を選びます。音は 1 か所からしか出ません。
    • それでも鳴らない？起動できなかったエンジンや、現れなかったオーディオ接続が ISSUES に表示されます。

    画面が真っ暗、またはとても暗い

    MENU を開いて ノブ 1 を回します。BRIGHTNESS スライダーです。

    タップしてもパターンが変わらない

    再生中は LOCK がノートのグリッドへの書き込みを止め、点滅して理由を知らせます。それでも編集するにはパターンのツールバーの LOCK をタップするか、STOP を押します。

    Bluetooth

    スピーカーやヘッドホンがつながらない

    スリープ中、起動中、またはスマホとつながっている機器には、約 35 秒のあいだにさらに 3 回呼びかけます。その間、行には「waking…」と表示されます。

    NOT ANSWERING と表示されたら、スマホとの接続を切るか電源を入れ直して、もう一度接続します。

    同時に鳴るのは 1 台だけ

    別のスピーカーが鳴っているときに 2 台目をつなぐと、音は新しい方に移り、最初の 1 台は切断されます。

    音がザラつく

    BLUETOOTH ダイアログを開き、そのスピーカーの SBC-XQ をオフにします。機器ごとにボタンがあるので、他のヘッドホンは高音質のままです。

    音が止まった

    ravving が自動でもう一度音を送ります。それでも戻らなければ、ISSUES に出力から音が出ていないと表示されます。

    USB メモリー

    • メモリーやパーティションが複数？USB カードがそれぞれの名前を出し、どれを開くか尋ねます。
    • 読み取り専用と表示される？ロックされたメモリーか、インストーラーのイメージです。何もコピーされません。そのページの FORMAT で、メモリー全体を消して書き込み可能な RAVVING ドライブにできます。FORMAT と EJECT はどちらももう一度押す必要があります。
    • マウントできない？ISSUES に表示されます。

    録音

    • MIC TOO HOT（ライブ録音）：マイクのピークが −6 dBFS を超えています。設定 → ライブ録音 で GAIN を下げてください。レコーダーページの GAIN はライブ録音には届きません。
    • 声の下で音楽が下がらない：設定 → ライブ録音 で INPUT を MIC に、VOICE を VOICE-OVER に、DUCK を NO DUCK 以外にしてください。GUITAR や LINE の入力はそのまま混ざります。
    • レコーダーのテイクやサンプラーの録音が大きすぎる：レコーダーページか、サンプラーの INPUT で GAIN を下げてください。

    それでも解決しない？

    ISSUES の RESTART RAVVING をタップします。ravving 自体が起動しないときは、MIKO の電源を入れ直します。
